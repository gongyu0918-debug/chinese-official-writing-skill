# 草稿检查脚本使用

用户提供已有草稿、要求审核/复核/审校/检查稿件，或明确要求交付前风险扫描时读取本页；它是可选择的检查增强，不替代文种路由。

## 调用

以本次已读 `SKILL.md` 所在目录定位脚本，使用草稿绝对路径并保留引号：

```text
python "<Skill绝对目录>/scripts/prose_lint.py" --delivery-mode draft-body "<草稿绝对路径>"
```

需要重复事项和格式噪点时追加 `--structure --format`。输入可为 `.txt`、`.md` 或 `.docx`。

## 解释与处理

扫描完成后，Agent 逐项对照风险位置与正文、主文种、事实状态和用户修改范围：确认的问题直接修改或在正文外提示；依据不足、与本轮无关或属于文种判断的项保留原文并说明处理理由。脚本保持检查职责，不自动改写正文，也不替代文种完整性判断；文种功能、办理要素、事实和状态仍按首叶、`handling-elements.md`、`final-review-layers.md` 和对应审查页判断。技术失败标记扫描未完成，转人工复核；返回码只表示扫描状态，不代表正文质量。修改后需要质量保证时，按用户授权重新扫描。

用户明确要求交付门禁时才读取 `delivery-review-gate.md` 并调用 `review_gate.py`；普通写稿不启用门禁。
