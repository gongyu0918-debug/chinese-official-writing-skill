# 草稿检查脚本使用

按任务扫描被审稿件或拟交付文本。将文本保存为临时文件，或通过标准输入传入脚本。输入支持 `.txt`、`.md`、`.docx`。

## 调用

以本次已读 `SKILL.md` 所在目录定位脚本，使用草稿绝对路径并保留引号：

```text
python "<Skill绝对目录>/scripts/prose_lint.py" --delivery-mode draft-body "<草稿绝对路径>"
```

成稿扫描追加 `--structure --format` 检查重复事项和格式噪点。按正在扫描的文本选择模式：

| 扫描文本 | `--delivery-mode` |
| --- | --- |
| 稿件正文，包括审核任务收到的原稿、修改后的稿件 | `draft-body` |
| 稿件正文和独立的文后提示 | `gap-note-allowed` |
| 审稿意见本身 | `review-only` |

审核原稿时保留原文件，扫描结果作为审稿依据；用户要求改稿时将已确认的问题改入新稿。标准输入将文件路径换成 `-`。

## 解释与处理

1. 对照风险位置、材料、主文种和修改范围，修正已确认的问题；合理用语或引用经核对后保留。
2. 修改后核对受影响内容的事实、状态、主体、否定范围和文种要素，再复扫变动文本。改动影响篇幅时复测字数。
3. 最终发送采用已检查文本，临时增加的开场或说明也纳入检查。同一提示经核对需要保留时，完成判断即可。

读取失败或运行失败时检查文件路径和格式，仍无法执行则如实说明本次检查范围。
