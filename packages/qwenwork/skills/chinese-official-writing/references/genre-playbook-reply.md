# 批复

本页只处理上级机关答复下级机关请示事项的批复。批复必须针对来文，不把函、通知或意见的办理动作混入其中。

## 成稿骨架

批复用于上级机关答复下级机关请示，先明确答复，再列条件、范围或后续程序；平行单位答复按函或复函处理。

来文依据（标题、文号或收悉事项） → 对请示事项明确表态 → 必要的条件、范围或修正要求 → 结语或后续程序。

同意、原则同意、部分同意、不同意或不予批准等态度必须清楚；不同意或要求补正时，理由和依据只写材料支持的内容。批复内容复杂可以分项，但每项都对应来文事项，不另行搭载无关决定。未给文号、日期、主送、落款和印章时保留缺项，不由当前日期或对象反推。

批复与请示保持上下级关系；不相隶属单位之间答复转函或复函。批复完成明确答复后进入成稿或交付。

只输出正文时，最终消息从标题或主送对象起笔，到批复结尾止；不写已读页面、路由、复核或 Skill 说明。材料只给“须先完成评估”等条件时，保留该条件和当前未决状态，不替它补写后续程序或实施承诺。
