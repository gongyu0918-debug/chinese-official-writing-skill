# 算力技术需求、SLA 与验收

## 适用

任务要写可度量、可检查的 GPU/服务器、模型服务或技术服务要求时使用。

## 技术条款

按材料需要写资源类型和数量、GPU 或等效性能、CPU/内存/存储/网络、推理/训练/微调/并发、资源调度、配额、监控、日志、告警、部署和升级。

## 服务与安全

按合同或任务要求写可用性、响应与恢复、排队控制、资源隔离、维护窗口、迁移和版本切换。明确数据类型、权限、密钥、日志、访问范围和审计位置；没有具体区域、等级或阈值时保留待核状态。

## 验收

验收项目应与需求一一对应：资源规格、性能或并发测试、模型服务可用性、日志审计、安全配置、部署材料和运维文档。用“应支持”“应提供”等可检查表述，不把拟议条款写成已完成结果。

## 结束

技术需求、SLA 和验收条款完成后停止。成本路径比较回算力可研叶，响应文件和预算边界回采购叶。
