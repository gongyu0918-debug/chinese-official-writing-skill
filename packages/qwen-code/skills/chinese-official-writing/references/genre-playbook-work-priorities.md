# 工作要点

本页处理年度、阶段或专项工作要点，以明确未来一段时期的工作方向和重点任务为主。已有工作用于说明基础、需求或任务衔接，正文围绕将要开展的工作组织。

## 组织正文

工作期间与总体方向 → 按领域或目标归并的重点任务 → 相应措施及落实要求。责任、时间节点、协同机制和评价方式按材料或用户模板落位；任务较少时直接分项，内容较多时再分层组织。

- 每项先点明要做的事项，再交代对象、重点及必要的推进方式；同一目标下的相近动作可以合并，不用近义标题重复拆项。
- 结合已有任务、工作基础和现实需要，说明目的、重点、先后衔接及有依据的一般推进方向或条件性预期，使任务具体可理解。具体部门、程序、数量、期限、资源和评价机制采用材料或用户明确授权的内容。
- 保持材料中的既定安排、拟议方向和待评估事项各自状态。任务可用直接动词或自然的将来时表述；总体建议状态已经明确时不必每句重复，但不能把其中尚未决定的具体事项写成已经确定。
- 每项责任与其任务对应，协同、运维和合同责任以已知主体关系为准。目标与预期作用用于说明方向，实际成效仍需事实支持。
- 标题和顺序服从用户模板；没有独立作用的背景、保障或总结段可省略，不为满足目录补会议、台账、督办或考核安排。

需要说明任务依据或衔接关系时，读取 `argument-chains.md`。完成任务覆盖、职责对应、节点及拟议状态核对后，按共性写作页复核并交付。
