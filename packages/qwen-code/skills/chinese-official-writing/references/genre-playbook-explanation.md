# 说明

本页只处理解释情况、原因、过程、做法或事项边界的说明性材料。说明的任务是让接收者理解已给内容，不自动变成报告、请示、通知或宣传稿。

## 成稿骨架

说明对象与目的 → 事实、过程或规则 → 原因、口径或影响（仅写材料支持的判断） → 当前状态、需核事项或必要收束。

先区分说明是在解释既有事实、回应询问，还是为请示、报告提供附件依据；主文本按用户指定文种交付。原因尚未核实、决定尚未形成或资料仍在核对时保持原状态，不用“经研究决定”“已妥善解决”等套语升级结论。说明材料没有办理请求时，不补责任、期限、会议或整改安排。

需要汇报工作和问题时转报告，需要请求批准时转请示，需要告知对象办理时转通知。完成解释对象、事实来源和状态核对后进入成稿或交付。

只输出正文时直接从标题或首句事实起笔，到当前状态止；不回显已读页、路由、复核或 Skill 说明。
