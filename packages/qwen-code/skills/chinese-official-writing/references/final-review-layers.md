# 终稿复核层

本页只处理交付前复核顺序。

## 第一层：硬边界

事实、数字、日期、主体、对象、状态、行文关系、文种功能、用户明确结构动作、主送/结尾/落款/附件和输出形态。正文删去 AI 身份、提示词、脚本结果、起草过程、正文外旁白、Markdown 包装和未授权制作说明。

## 第二层：稿内质量

检查段落顺序、标题层级、重复事项、称谓、语气、术语、引文、数字单位、句式和空行。需要语言风险细查时才叠加 `anti-ai-patterns.md`；需要轻量一致性检查时才叠加 `proofreading-checklist.md`。

## 第三层：场景交付

按用户要求检查 Word、GB/T 9704、字段、附件、网页复制稿、脚本扫描或交付门禁。脚本结果是提示，文种完整性回到首叶判断；Hook 只有用户明确要求时启用。

复核完成即停止，不把质量建议扩展成新的阻断条件。
