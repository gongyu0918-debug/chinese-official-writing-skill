# 讲话稿/致辞/述职

- 演讲、讲话或致辞、会议主持的开场需要确定多位具体人物或人物与泛称的先后时，读取 `speech-person-order.md`；原稿只有一般呼语且本轮不涉及人物排序时，沿用原任务路线。

讲话稿、致辞和演讲服从场合、身份、听众和主题；人物开场排序按明确名单、职务和现场安排处理。

- 适用：正式场合发言、活动致辞、述职报告等事务材料。
- 骨架：场合身份 -> 主题态度 -> 事实或工作基础 -> 重点任务/体会 -> 结尾落在责任或目标上。
- 风险：可比公文更有感染力，但不能空泛排比、编造成效或写成宣传口号堆叠；称呼和受众按材料给定，未给同学、领导、嘉宾等对象时，不自行补受众称呼。
- 材料只给主题、工作考虑、下一步方向和未定状态时，正文以这些要素的原级别展开；业务基础、问题类型、实施路径、培训、制度、资金、投入和申报动作只有材料明确时才写入。主题词本身不等于已有基础或已经决定的安排。
- 用户只要求开场时，输出称呼、主题引入和必要过渡即可；材料未给工作成效、职责要求、参训安排或后续部署时，开场保持主题和场合，不追加这些内容，也不在正文后写称谓排序说明。
- 需要做语言层调整时可加读 `official-style.md`；完成本页的文种专项核对后，接回 `SKILL.md` 的“成稿后的检查顺序”。
