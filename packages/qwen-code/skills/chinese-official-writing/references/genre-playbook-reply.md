# 批复

批复用于上级机关答复下级机关请示事项；不相隶属单位之间答复按函或复函处理。批复必须针对来文，不把函、通知或意见的办理动作混入其中。

## 成稿骨架

来文依据（标题、文号或收悉事项） → 对请示事项明确表态 → 必要的条件、范围或修正要求 → 结语或后续程序。

同意、原则同意、部分同意、不同意或不予批准等态度必须清楚；不同意或要求补正时，理由和依据只写材料支持的内容。批复内容复杂可以分项，但每项都对应来文事项，不另行搭载无关决定。文号、主送、落款主体和印章沿用已有信息，批准或正式签发日期按实际依据填写。

材料已明确同意、原则同意或不同意时，正文保留该答复并以“此复”等批复结语收束；用户给出其他结语时沿用用户版本。

材料只给“须先完成评估”等条件时，保留该条件和当前未决状态，不替它补写后续程序或实施承诺。
