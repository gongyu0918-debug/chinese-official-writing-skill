# 采购审查

本页只处理采购清单、采购方案、评审材料和审查意见。公开采购公告另读 `genre-playbook-procurement-announcement.md`；不得补造品牌、型号、供应商或评审结论。

## 采购事项共同边界

采购审查回答采购需求、响应规则和审查发现；采购公告另按公开发布功能组织。

- 采购审查优先核对品名、规格、数量、预算或单价、供应商/报价依据、验收和归档要求；已给的信息按审查功能组织，未给事项按 `information-selection.md` 处理，不写成正文里的流程承诺。
- 采购需求不等于现有能力不足、效率提升、业务范围不变或影响结论；用户只给预算时写“预算为”，不包装成“经测算”。

## 审查材料

- 适用：审查意见、初步设计或项目材料审查。
- 骨架：依据、发现、风险、整改要求和结论。
- 风险：字段式审查材料只改用户指定字段，其他字段按原行、原字段名和原值保留，拆行时不保留原分号为行尾噪声。
- 需要办理要素或功能反查时，结合 `handling-elements.md` 和 `genre-checklist.md` 的对应部分。
