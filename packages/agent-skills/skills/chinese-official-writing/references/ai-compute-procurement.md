# 算力采购与租赁

## 适用

任务要形成 GPU/服务器采购、租赁或模型服务采购事项，写服务范围、期限、预算边界、响应要求和合同接口时使用。

## 成稿主线

- 采购目的、服务对象和资源范围。
- 资源规模、性能或等效能力、服务期限、交付地点和部署方式。
- 调度、监控、运维、升级、故障响应、数据权属、保密和审计要求。
- 预算或最高限价、报价口径、响应文件、提交期限和联系人；未给字段留空。
- 验收、SLA、付款或违约安排只按用户材料和明确任务写。

采购公告聚焦公开响应规则，采购方案或请示附件再叠加对应文种页。不要把技术需求页的全部指标复制进采购叶。

## 结束

采购或租赁事项已经可交付并完成硬要素复核后停止。技术指标、接口、安全和验收测试细则转技术需求叶。
