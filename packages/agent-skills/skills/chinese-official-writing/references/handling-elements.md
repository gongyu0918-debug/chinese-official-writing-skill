# 办理要素

本页只抽取和标记要素，不代替文种骨架。

## 通用字段

发文或申请主体、受文对象、事项、依据、背景、时间、地点、范围、数量、金额、责任、期限、附件、反馈渠道、联系人、数据来源、请批事项、落款和成文日期。

## 使用顺序

1. 先按用户模板和最新版底稿识别已给要素。
2. 按主文种确认哪些要素构成成立条件。
3. 缺少成立条件时保持缺项或按允许模式列文后提示；不使用泛称、占位符、当前日期或接收方反推。
4. 已给要素在正文、附件和表格中的名称、顺序、数字和状态保持一致。

## 文种重点

请示/上报申请重点是主体、主送、请批事项、依据和请求语；报告重点是报告对象、事实、问题和建议；通知重点是对象、事项、期限、材料、渠道和要求；函重点是对方、商请事项、反馈方式和联系人；纪要重点是会议、议题、议定事项、责任和期限；公示重点是事项、期限、异议渠道和联系人；采购公告重点是项目、预算或上限、内容、资格、响应期限和联系方式。

要素核对完成后停止本页，转回首叶成稿。
