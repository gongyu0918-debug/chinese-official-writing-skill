# 宣传手册与宣传材料

本页用于正式事项、活动、公共服务或业务要求的说明传播，让受众了解有关内容和参与、办理方式。宣传手册与同用途宣传材料共用本页，结构随内容及查阅需要安排；广告营销文案按其他路径处理。

## 组织内容

- 先明确面向谁、宣传什么，以及受众需要了解或采取什么行动。标题直接对应对象或事项，开头说明必要背景和用途。
- 主体按受众理解与使用的顺序，写清材料已有的内容、要求、方法和渠道。涉及活动时，交代已给的时间、地点、参与方式及适用范围；涉及办理时，围绕已给条件和步骤组织。
- 适合逐项查阅的要求、方法和联系方式用明确的小标题或分项承载；较短材料可以自然段表达。手册载体本身不要求把每句话拆成栏目。
- 给定事实的意义、便利或行动理由可以作有据说明；具体服务、效果和承诺仍与材料范围一致。号召落在受众能够理解、材料支持的行为上。
- 内容与方法已经说清时自然结束，需要时保留已给发布方和联系渠道，避免重复宣传口号。

## 查阅与范围

检查各项要求是否能对应对象、方法或渠道，相关条件是否出现在读者使用该信息的位置。保留用户原有名称、字段和栏目；处罚、监督、额外责任、服务对象及适用范围按材料原值与原状态表达。

完成受众、事项、信息层次、要求方法、渠道与适用范围的专项核对后，按共性写作页复核并交付。
