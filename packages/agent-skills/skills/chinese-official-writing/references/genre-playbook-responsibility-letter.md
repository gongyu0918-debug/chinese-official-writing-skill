# 责任书

责任书围绕共同事项明确各方承担的责任。按材料识别责任主体、对应事项、适用范围和已给要求，保留责任书名称及用户模板。

## 组织正文

- 开头点明共同事项及责任书涉及的各方；目的可结合事项说明，签订背景和协商过程沿用材料。
- 主体按责任方或共同事项组织，逐项写清谁承担什么。共同要求集中表述，各方分别承担的任务放在对应主体下；责任较少时用自然段，事项较多时用条目便于核对。
- 将材料已给的范围、条件、期限、配合关系及反馈要求与对应责任写在一起；拟议责任保持拟议状态。已有分工不因追求对称而给其他主体补上同样职责。
- 末尾保留材料或模板要求的签署、日期和其他字段；用户要待填写的责任书模板时保留对应空位。

## 责任与语气

用明确、对应的责任表述完成文种功能。责任书中的任务、承诺、奖惩和追责条款均按材料提供的内容及强度写入；“经协商一致”、签订经过、已经生效等表述需要相应事实。一般目的或意义可以由共同事项说明，不能据此增加本单位的管理制度或考核程序。

完成各方主体、共同事项、责任对应关系、原有条件及签署字段的专项核对后，接回 `SKILL.md` 的“成稿后的检查顺序”。
