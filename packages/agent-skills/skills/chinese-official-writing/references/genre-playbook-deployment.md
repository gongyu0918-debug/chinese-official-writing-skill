# 部署安排

本页处理已经确定需要组织实施、传达部署或安排协同的事务型稿件，不承担决定、决议或一般通知的权威功能。

## 成稿骨架

部署背景或依据 → 目标和任务 → 对象、责任与协同 → 进度、节点、保障和反馈 → 监督或收束。

责任、期限、会议、台账、验收和督办只在材料或用户授权支持时写入；拟部署、建议安排和已确定安排保持不同状态。若只是告知已发生事实，转通知或新闻消息；若需要作出权威决定，转决定性文种页。

部署稿面向明确的执行对象，任务、责任和节点按同一主体绑定；跨单位协同时保留商洽和协同语气，材料没有授权或决定依据时不升级为命令式要求。正文至少交代要做的事项及其对象，依据、期限、反馈和保障按材料给出的范围补充；缺少其中一项时保持现有信息，不用空泛要求填位。
