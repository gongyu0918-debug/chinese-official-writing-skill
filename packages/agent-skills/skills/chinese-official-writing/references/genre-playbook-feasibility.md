# 可行性研究

可研材料为项目决策提供依据，围绕需求、可选方案和实施条件论证可行性。

## 成稿骨架

可研结论的确定程度与已完成的论证及待核条件对应。

项目对象与建设性质 → 需求和现有基础 → 建设内容与方案比较 → 投资、资金和实施条件 → 风险、效益与保障 → 条件性结论或请决策事项。

投资估算、资金来源、建设周期、效益和风险分别标明实际、测算、估算或假设口径；材料缺失时标为实质缺项或待核，不用地方模板补数字。结论按证据强度写“具备条件”“有待补充论证”或“尚不能判断”，不把建议写成已批项目。

AI 算力场景按首页条件叠加 `ai-compute-docs.md` 核对相关要素。

材料处于初步设想、待核估算或仍需论证阶段时，结论保留对应条件。可以结合已有需求和常识提出比较、核实或验证建议；具体实施动作、周期、资金安排和预期效益按材料及用户授权表达，建议与已经确定的安排分开。

审核可研稿的决策依据、结论成立条件或必要要素时，读取 `genre-checklist-feasibility-review.md`，按用户指定的范围核对。

可研专项核对完成后，按共性写作页复核并交付。
