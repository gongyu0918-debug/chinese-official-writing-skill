# 轻量任务选择

以下两类任务可减少额外读页和结构展开：

- 用户要简短稿件，或材料较少、事项单一：保留对应主文种页，按 `short-draft-naturalness.md` 组织短稿。
- 用户只改标题、字段、标点、一个事实或指定段落：修改范围限于点名位置及必要衔接；结构动作读 `structure-editing.md`，字段动作读 `field-editing.md`。

这两类条件分别成立即可。明确字数下限、多材料合稿或专项论证按实际完整性需求组织；正式版式按用户要求处理。

材料多少决定可展开的内容，稿件用途决定主文种。简短稿件同样保留主文种必要要素；已经读过的对应短稿或修改规则可直接应用。

完成草稿或本轮修改，进入首页的编号检查步骤，按本轮范围核对。
