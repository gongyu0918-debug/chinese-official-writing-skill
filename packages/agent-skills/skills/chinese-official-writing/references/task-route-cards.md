# 轻量任务路由卡

本页是交付模式叠加页，不是独立文种页。短路命中后仍读取唯一主文种叶；它只减少共性伴读和篇幅动作，不删除请批事项、对象、事实、状态或文种收束。

本页只判断任务能否走短路径，不承载任何一个文种的完整骨架。

短路径的格式动作是“保留文种功能，压平长稿层级”：章节可以并入自然段，小标题可以省略，单段通常用一两句话承载一个事项；对象、请批、事实、状态、期限和必要收束仍按主文种页保留。

## 进入条件

同时满足以下条件时进入本页：

- 材料少或单一，用户要短稿、限字稿或只按给定事实写。
- 本轮是一次局部修改，动作集中在标题、字段、日期、标点、段落或一个明确事实。
- 任务不要求完整文种骨架、长文、多材料合稿、专项论证、正式版式或综合审稿。

文种已经明确且对应专页能直接覆盖时，跳过本页，直接进入专页。

## 三条短路径

### 材料稀疏

适用于情况说明、短报告、简短通报等只需承接已给事实的任务。

- 先写已给事实及其直接关系，保留进行中、待核对、建议和未形成结论等状态。
- 总量和问题量按原口径表达，不从差额推出范围性结论。
- 文本在事实和必要承接处收束，不为补齐章节增加责任、流程、期限、验收或治理安排。

### 短通知

适用于提醒、告知、提交要求和简单安排。

- 保留已给对象、事项、时间、地点、渠道、联系人、电话、发文单位和日期。
- 缺失主体、落款或日期时保持缺项状态，不从接收方、邮箱或当前日期推回发文信息。
- 只写材料要求的动作和语气；完整通知要素不足时转通知专页。

### 局部修改

适用于只改一处或一组明确位置的任务。

- 以用户最新版底稿为唯一主线，只改本轮点名动作及必要衔接。
- 结构增删、移动或标题重排转结构修改页；字段拆行、增删或表单处理转字段页。
- 只审不改时输出位置、风险和建议；要求改稿时输出完整改后正文。

## 直接转长路径

遇到会议纪要、请示/申请完整骨架、方案或可研、采购/算力技术论证、正式 Word、跨文种合稿、材料冲突或综合审稿时，停止短路径，按总索引选择首叶。会议的未决状态和议定事项统一由纪要专页维护；本页不复制会议规则。

## 停止条件

短路径已经覆盖用户要求，完成正文或局部修改后停止加载；不因为文种名称或一个关键词继续预读其他长页。
