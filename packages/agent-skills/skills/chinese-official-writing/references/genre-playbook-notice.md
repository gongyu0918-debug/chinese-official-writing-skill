# 通知

本页只处理通知及内部告知。通知的核心是把办理对象、事项、要求、时限、材料和反馈方式写清楚；公开发布、名单公示和权威通报转入相应专页。

## 成稿骨架

通知面向明确对象办理事项；对象、事项、时限、材料、渠道和要求按材料组织，公开发布转入公开发布主叶。

事项或目的 → 主送/对象 → 办理内容、材料和要求 → 时限、渠道、联系人或后续处理 → 结尾语。

材料只说明当前进展时，按“已完成事项—已发现情况—仍在进行或未决定状态”收束，不为了形成通知格式补整改、会议、责任或期限。通知对象由材料或用户给出时保留原称谓；缺少正式落款、日期和文号时不自行补齐。

参加、报送、组织人员、反馈和办理等动作只在材料或用户明确给出时写入；“请参加”不自动扩展为“组织人员参加”，也不替对象增加责任、时限或后续安排。结尾语按材料要求取舍，不能为了显得完整新增办理承诺。

材料给出“参会对象”或具体对象名称时，标题、主送和正文沿用原称谓及范围；“业务科、资料室”不改写为“相关人员”“全体人员”或其他扩大、缩小范围的称呼。

## 边界

- 已发生的活动或事实面向公开传播，转新闻消息页。
- 面向社会公开宣布事项、期限或异议渠道，转公开发布页。
- 需要作出决定、命令或部署安排，转对应决定或部署页。
- 通知是主文种；方案、制度或附件另按附件功能处理，不把附件骨架并入通知。

交付前只核对象、事项、状态、时限、渠道和输出形态；完成后进入成稿或交付。
