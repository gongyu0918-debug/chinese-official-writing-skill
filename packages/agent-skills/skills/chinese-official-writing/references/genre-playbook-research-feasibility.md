# 调研报告/研究报告/可研报告

- 适用：专题调研、研究分析、可行性论证。
- 骨架：对象和范围 -> 事实、数据、样本 -> 发现和问题 -> 原因或方案比较 -> 建议/可行性/建设内容 -> 条件和风险。
- 路径：调研报告先锁定对象、样本、事实和问题；可研报告先核对项目类型、建设性质、建设内容、投资估算、资金来源、实施条件、风险和效益。
- 风险：不把公文报告写成投研报告；建议必须回到调研事实；可研结论要说明条件和测算边界。项目类型、资金来源、投资估算或测算口径缺失时不使用地方模板或空表补实，按 `information-selection.md` 判断是否属于实质缺口。
- 补充读取：`argument-chains.md` 的可研、调研和审查，专项技术材料再读 `ai-compute-docs.md`。
