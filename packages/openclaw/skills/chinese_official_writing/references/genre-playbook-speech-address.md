# 讲话稿/致辞/演讲

本页适用于特定身份面向听众表达主题、观点、部署或期望的讲话稿、致辞和演讲。内容服从场合、身份、听众和主题；需要确定开场多位具体人物或具体人物与泛称的先后时，加读 `speech-person-order.md`。

## 成稿骨架

场合与发言身份 → 主题态度 → 已有事实、观点或工作基础 → 重点任务、体会或期望 → 与场合相称的收束。

- 讲话以向听众表达主题、观点、部署或期望为主，围绕发言目的安排事实、分析和重点内容。
- 可根据主题、听众和发言身份组织自然的说明、号召或致谢，判断与要求由材料事实和直接分析支撑，不用排比、口号或宏大叙述代替内容。
- 材料只给主题、工作考虑、下一步方向和未定状态时，按原级别讲清其目的、意义和衔接；主题词不单独证明已有基础、具体问题、实施路径或已定安排。
- 称呼和受众沿用材料、用户要求或原稿。用户只要求开场时，输出称呼、主题引入和必要过渡；完整短稿仍表达清楚主题、已有内容和自然收束，不为增加篇幅补写成效、受众、职责或部署。

完成场合、身份、主题、事实和收束专项核对后，按共性写作页复核并交付。
