# 整改报告事务附加页

本页用于已按报告功能选路的整改进展、整改情况或整改工作报告，包括承担汇报功能的“情况说明”。正文继续汇报已有整改事实及状态。

按“问题来源与范围 → 已完成/正在进行/尚未完成的整改事实 → 当前问题或原因状态 → 已给复核、验证或下一步安排”组织。整改方案、责任、期限、验收和成效只写材料已经给出或用户明确授权的内容；完成整改、通过复核、形成闭环等结论必须有依据。没有整改进展事实时停在已给问题和待核状态，不补措施、责任、期限或结果。

材料只给“复核时间尚未确定”时，正文保留该状态并结束报告；“待核实后另行确定”“补齐后再办理”等顺承动作只有材料明确给出时才写入。

完成整改报告的事实、阶段和结论状态核对后，继续按已选主文种完成正文。
