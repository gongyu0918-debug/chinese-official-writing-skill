# 稿件直交付

本页是成稿后的交付模式页，不参与文种选择。用户用自然语言表示“只要文章”“只要稿件”“只要正文”“帮我写完整稿子”“直接给我成稿”“不需要解释/提示”等意思时，在主文种成稿和内部复核完成后读取本页。

## 交付形态

最终消息只承载标题（如有）、正文段落及用户明确要求保留的落款或字段；第一字符直接进入稿件，最后一句直接结束稿件。路由、已读页面、Skill、脚本、复核过程、制作说明、“以下为正文”和 Markdown 包装不进入稿件。

这也是 Agent 的执行指令：先完成主文种写作和事实复核，再直接返回稿件；不要用“已完成”“按某文种处理”“下面是成稿”等过程句替代正文。正文中没有材料依据的组织、参加、整改、成效或承诺不得因为交付模式而补写。

## 文后提示

用户只想要稿件、没有要求说明时，不在正文后追加缺项清单、风险提示、字数、来源、脚本结果或自评。用户明确允许或要求提示时，先完整交付正文，再另起“文后提示”列出直接影响本轮使用的缺项或风险；提示不编号为正文段落，不改写成新的文种内容。

用户同时要求“文后提示/缺项/风险”时，仍先给完整正文，再给独立的“文后提示”；提示可以说明缺失字段和风险，但不描述路由、读取页面或模型过程，也不把提示改造成正文收束语。

## 停止

完成正文洁净检查和用户要求的字段保留后停止本页。它不改变事实状态、文种骨架、篇幅取舍或 Hook 选择。
