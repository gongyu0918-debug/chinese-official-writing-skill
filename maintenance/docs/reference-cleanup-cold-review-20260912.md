## 冷审结论

独立高能力模型只读审查确认：

- 首页原有的文种功能段已移回各文种页；入口只保留交付动作、首叶选择、共性事实边界、正文洁净和必要转读条件。
- `适用范围`只保留能力覆盖和排除范围；兼容场景、意见、制度和 Hook 的路径指针已移到`入口契约`。
- “交付动作→主文种首叶→必要附加→复核→交付”只保留一处，删除重复的任务路由主线。
- “材料较少/可用信息较少”替代“材料稀疏/材料稀薄”；构建、维护、测试、镜像、总路由表和隐式补充读取等残留由产品面审计扫描。
- 合理推断保留事实和常识直接支持的原因、影响、下一步动作和低强度结论；具体调查经过、数额、已定程序、责任、期限、成效和联系方式仍要求直接依据。
- Hook 页面保留用户选择后的检查能力；宿主、运行时和 Skill 构建约束不写入首页或普通文种页。
