# 批复、意见、说明独立主叶证据（2026-09-12）

本页只记录公开规则的归纳依据，不把公开样稿中的机关名称、文号、日期、固定事实或具体模板写入 Skill。

## 来源与可迁移规则

1. [《党政机关公文处理工作条例》公开文本](https://www.miit.gov.cn/xwdt/szyw/art/2020/art_6afb8ee6d07540dcacccbeb47dbc0fd4.html)：公文拟制要求文种正确、格式规范、事实和政策依据准确、结构严谨、文字精练；审核要核对行文理由、文种、格式、人名、时间、数字、段落顺序和引文。迁移到三页的共同硬边界：不混用文种，不把待定状态写成决定，正文事实与依据可追溯。
2. [国家发展改革委《公文写作五步法》](https://www.ndrc.gov.cn/fggz/gbzj/wsgz/201508/t20150812_1105092_ext.html)：文种先由行文目的、主体权限和收发关系确定；每份公文只选一个文种；写作要开门见山、准确、简明、朴实、得体。迁移为三页的选种和表达边界，不复制原文样句。
3. [岳阳市教育体育局《机关公文写作基本要求》](https://edu.yueyang.gov.cn/22483/22510/content_536367.html)：批复的答复件应有来文依据、明确答复和必要的结尾；称谓、受文单位和专用语要保持规范一致。迁移为批复的“来文—表态—条件/程序”骨架和称谓一致检查。
4. [湖北省政协《关于政协机关公文的几个问题》](https://hbzx.gov.cn/581/2014-09-24/2014-09-24/2014-09-24/2014-09-24/2014-09-24)：批复限于答复下级请示，要求针对性、明确性、简明性；意见的核心是明确目的、充分依据和可操作措施。迁移为批复与意见的分流条件和状态强度，未迁移其具体机关场景。

## 三页的边界

- **批复**只答复下级请示。上级关系、来文事项和明确态度是成立条件；平行答复转函/复函。
- **意见**围绕重要问题提出本机关的见解、办法和措施。可以上报、下发或批转，但建议、拟议和已决定安排必须分级。
- **说明**解释事实、过程、原因或口径。它本身不产生请批、部署或权威决定；需要汇报、请批或办理时转相应主文种。

三页均采用“一个主文种首叶 + 信息选择 + 按需复核”的最小组合，不读取旧总清单或相邻主文种页。
