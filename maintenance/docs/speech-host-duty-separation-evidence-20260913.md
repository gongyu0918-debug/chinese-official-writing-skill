# 讲话、主持词与述职拆分证据（2026-09-13）

本页保存本轮新增主叶的公开依据和旧规则归属。公开样稿只用于确认文种功能，不把其中的机关名称、人物、人数、程序结果、专门考核项目、篇幅或固定结尾写入通用规则。

## 来源与采用范围

1. [北京市国资委：讨论接收预备党员支部大会主持词参考例文](https://gzw.beijing.gov.cn/gzdj/djzn/gzgf/dzbgzcywsxz/201812/t20181221_10128.html)：例文呈现开会条件、议程列表、逐项邀请、讨论和表决等主持动作。采用“主持词围绕会序和程序串联”；党员大会的法定人数、表决方式和专门称谓不推广。
2. [重庆市民政局：全市性社会团体换届选举工作指引附件 7](https://mzj.cq.gov.cn/zwgk_218/zfxxgkml/zcwj_166256/xzgfxwj1/202501/W020250817054595452757.pdf)：主持词按既定议程引导审议、表决、结果宣布和阶段转换。采用“程序状态随材料或现场形成”；换届程序不成为普通主持词的固定骨架。
3. [共青团芜湖市委：基层团组织换届工作规范化指引](https://www.wuhuyouth.gov.cn/zlzx/twgzzy/8395652.html)：多个范例使用继续开会、说明议程、邀请发言、议程完毕和提示下一安排等串联。采用“短串词也完整完成当前会序功能”；具体团组织程序不继承。
4. [重庆市人大常委会：有关任命人员如何写好履职情况报告](https://www.cqrd.gov.cn/site/article/1211356827051986944/web/content_1211356827051986944.html)：履职报告以个人履职为主体，围绕职责、具体做法、实绩、问题和下一步，并区分个人履职与单位工作、个人作用与集体贡献。采用其通用职责轴；人大场景的栏目、篇幅和结尾仅按实际任务使用。
5. [北京市国资委：市属国有企业总法律顾问述职评议办法](https://gzw.beijing.gov.cn/xxfb/2024zcwj/202406/t20240604_3703983.html)：书面和现场述职共享岗位职责内容，包含本人作用、问题和改进，且明确防止工作总结替代述职。采用书面/现场关系和职责边界；专业栏目不推广。
6. [盂县政府：关于做好 2022 年度事业单位目标责任考核工作的通知](https://www.sxyx.gov.cn/yxxxgk/zfzcbm/yxzfhcxjsglj/fdzdgknr_45587/lzyj_45589/bmwj_45590/202307/t20230728_1682408.html)：区分班子和个人述职，并要求个人对照目标任务说明分管工作、问题和下一步。采用“先辨个人/班子主体并对照职责或目标”；该通知的字数、考核项目和特定结构不推广。

## 当前实现边界

- `genre-playbook-speech-address.md` 只承担主题讲话、致辞和演讲。
- `genre-playbook-meeting-host.md` 只承担完整主持词与主持串词；主持人另作的主题讲话按其实际功能处理。
- `genre-playbook-duty-report.md` 同时承担书面和现场述职的职责内容；呈现方式按时长、场合和听众调整。
- 三条路由均保留 `information-selection.md` 和成稿复核可达性。真实写稿效果需另行与固定基线比较，本页不宣称已经验证等价或改进。
