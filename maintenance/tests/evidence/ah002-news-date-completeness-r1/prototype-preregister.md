# AH-002 source-bound 完整日期原型预登记

日期：2026-08-29。

## 固定输入与目标

原型继续以 `main@31dacd0805035521ad848bdc10e70c0a366d554c` 导出的 Skill 为公开基线。只在可选 Hook 的默认 `delivery_review` 生命周期内，对完整 D0 做一次确定性前置核对；普通无 Hook Skill、其他静态 capability 和 description 不变。

目标不是规定新闻一律写年份，而是保护用户请求已经给出的完整日期。候选仅在下列条件全部成立时生成 D0'：

1. 原请求明确要求起草、改写或整理新闻稿、新闻消息、快讯、活动报道、活动新闻稿或新闻通稿；
2. 请求中存在完整 `YYYY年M月D日`，D0 中没有该完整日期；
3. D0 中只出现一次对应 `M月D日`，且该月日不是另一完整日期的一部分；
4. 请求中没有两个不同年份映射到同一月日，没有明确要求省略日期或年份；
5. 整个请求与 D0 只形成一个可机械恢复的目标。

D0' 只能把该唯一月日替换为请求中的原样完整日期；其他字节不变。若任一条件不成立，逐字使用 D0。D0' 随后进入既有 `delivery_review`，既有门禁选择 D0 时指 D0'；原始 D0 与恢复后的 D0' 仅保留 hash，正文仍按现有终态脱敏规则删除。

## 先行机械测试

- 正向：冻结的三份自然漏年 D0 必须逐字得到既定机械期望值；
- 原样：完整日期控制稿、普通通知、日期只给月日、用户要求省略年份均不改；
- 歧义：两个年份对应同一月日、多个缺失日期、D0 已有完整日期同时又有月日均不改；
- 失败回退：模块加载异常时仍按既有 D0 路径运行；
- 生命周期：默认 `delivery_review` 的既有 D0/D1、终稿 hash、原文脱敏和无 Hook 路径不得回退。

先完成纯函数和共享核心单测。机械门通过后，再组装一个隔离 companion，以至少两家便宜 provider 对全新活动新闻做真实 Hook 生命周期；只有自然漏年得到修复、完整日期控制不变，且没有日期外候选独有回退，才登记为可合并产品。
