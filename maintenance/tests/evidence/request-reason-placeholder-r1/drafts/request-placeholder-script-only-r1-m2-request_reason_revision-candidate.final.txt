关于资料核对工作延期的申请

单位负责人：

资料核对工作原定9月20日完成，因＿＿＿＿＿＿＿＿，现申请将完成时间延至9月27日，延后7日。妥否，请批示。

综合办公室

**本次改动**

- 把“申请将完成时间延至9月27日”补全为“将完成时间延至9月27日，延后7日”，让审批人不必自行换算延期幅度。
- 标题、主送、请批语“妥否，请批示”和落款均按现稿保留，文种仍是申请，不改用请示或报告口吻。
- 未在“因”后替填事由，也未加入“各项工作不受影响”“确保按期完成”一类无材料支撑的表述。

**文后提示**

1. 延期原因仍缺，这是本稿唯一影响审批判断的实质缺项，请补入“因”后空位；如原因已确定，一句话写清即可。
2. 材料只给出两个时间点，未给新的工作安排或保障措施，故正文未写“下一步落实计划”，也未写落款日期，按单位审批稿习惯处理即可。
3. 主送“单位负责人”与落款“综合办公室”按现稿保留，若本单位审批稿习惯用“××单位负责人”或“领导”等称谓，可按实际调整。
