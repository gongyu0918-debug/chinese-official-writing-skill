# WR-026-R3 短意见正向结构原子预登记

日期：2026-09-01。

## 目的

R1 的两种放置和 R2 的显式禁令都会诱发正文包装或跨文种读取。本轮不再增加“正文如下、自检、横线”等禁令，也不修改通用短稿叶；只把意见建议专叶现有结构句改成一条更短的正向载体规则，验证能否减少平台栏、邮件正文的完整稿件壳层，同时保住独立成文短意见的题名、建议方和日期。

## 唯一产品改动

仅改 `chinese-official-writing/references/genre-playbook-advisory-feedback.md` 中“结构与版式”的既有首条，不新增段落：

> 常见结构是：简短合作性开头 -> 共性问题及代表事实 -> 按权责归并的具体建议 -> 简洁收束。完整独立稿按任务和材料保留题名、建议方和日期；平台建议栏、邮件正文等短反馈将实际情况和具体建议连续成文，不为“意见建议”另起“问题”“建议”两层。

不修改 `SKILL.md`、通用短稿叶、Hook、description、镜像、版本或包体。

## 真实写稿

复用 `main@69515dbc216e6e057e497fbaa0c1cebb9dac6547` 上轮同题 25 份技术有效基线，候选重新运行五家低成本 provider、同一五题、`max` 思考强度：平台建议栏、反馈邮件正文、独立成文短意见、短通知控制、正式长意见控制。

## 判定

- 只评价实际读取候选意见建议叶的有效稿。
- 正向改善：平台栏或邮件从制作说明、重复题名、称谓、横线、落款等壳层变为直接可粘贴正文；独立成文仍保留材料给出的题名、建议方和日期。
- 硬回退：候选新增制作说明或 Markdown 包装；删掉关键主体、数字、日期、建议对象、建议状态；把尚待研究写成已经决定；把短通知改成建议语气；把完整独立稿剥成字段正文。
- 基于给定事实和常识的一层原因、直接作用、条件性结论及正常文采差异不判失败。未逐字复现“尚未决定”也不单独失败，只要建议状态没有升级。
- 至少两家 provider 出现可归因改善且没有候选独有硬回退才选择；无净改善则恢复产品，不留 `HOLD`。
