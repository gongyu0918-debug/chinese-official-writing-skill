# R25 具体实现的判定记录

## 用户澄清前的暂缓判断

当时按旧工程准入条件暂缓两处追加式原型。MiniMax 三题两臂已完成真实写稿及独立全文评阅，主代理确认采购候选独有的设备分工状态改写与最终回复包装。这些问题不能由“允许分析”解释，已达到本仓库暂停候选、不补镜像的条件。Qwen 冻结测试继续完成，用于保留强弱模型差异与实际运行观察，不用强模型的成功抵消已确认的另一模型失败。

该决定针对本轮追加式表述的现有证据，不撤销用户确认的全局写稿原则，也不把同题独立采样的全部差异断言为原子的因果效果。当前需求规格已取消一层目的作为全局上限；候选入口和信息选择页原文保存在 prototype.diff 及 actual-*/snapshots/candidate/，运行包保持冻结。当前工作树的 canonical 两文件恢复 main，不同步兼容镜像、Hook或发布包。

后续若继续改产品，应处理现有入口和文种页的保守表述与全局原则之间的重复及适用关系，采用直接改写后的最小原子；不能把本轮追加“优先于下文”的方案称为已验证可推广。审批中具体分工、预算与工期、只要正文、复核是否误删有据分析继续作为真实任务观察点。本轮未做新的同D0 Hook修订、多版或长稿可靠率验证。

## 用户进一步澄清后的当前口径

用户要求不要过度工程化，一切以真实写作质量为准，所有规则为写作质量服务。上述自动暂缓条件不再作为最终结论：单次独立首稿中的候选新增问题，须保留并判断其影响，不能据此直接推定全局原则导致总体质量下降。当前改为结合实际成稿的事实准确、论证、自然程度、完整性和直接可用性作综合判断，不增加统计门、评分框架或新的防护机制。

全局原则是用户既有写作预期的明确化，不以全体稿件文采胜出为保留条件。事实与未决状态错误依然是实际问题，不能改名为合理分析而放过。原有独立评阅、原稿和失败记录不变；待剩余冻结成稿读完，再决定是否保留这份具体表述。前节的“原型不准入/恢复产品”只记录当时操作，不表示已经证明写作质量下降。

## 最终实施

保留冻结原型，恢复到 canonical 并仅同步两处规则至五套普通镜像。事实与常识支撑分析的原则符合用户既有写作要求；两家真实稿均能进行这样的分析，现有证据不足以将个别错误归因为原则使整体质量下降。作为全局口径明确化保留，不宣称本轮整体质量显著提高。没有忽略采购分工与交付说明问题，相关原稿和评阅仍保留。AGENTS同时按用户要求收紧为真实成稿质量优先，避免后续再次机械否决。
