# 匿名稿件评阅包

各 P 编号目录只提供原始自然材料、A/B 完整交付与交付方式。编号和左右位置不代表版本、模型或质量。

先读 materials.txt，再按 delivery.json 阅读。*-delivery.txt 是实际最终回复，保留前言、说明及其他包装；存在 *-manuscript-*.txt 时，同时阅读这些实际生成文件，不能把说明回复当完整正文，也不能替作者清除包装。生成稿中的说明或附件仍按实际内容判断，不因文件名叫 manuscript 就当作合格正文。

只评价目录中存在的交付；只有一侧时逐篇评价，不作成对偏好。逐篇通过与成对偏好分开。检查申请缘由与事项衔接、材料和市场证据主次、自然正式语言、事实与状态、费用和期限依据、主体及办理过程、正文附件和最终交付是否直接可用。合理目的和条件推论不机械判作编造；未经材料支持的事实、具体预算、工期、手续须指出。不要访问其他目录、映射、规则包、模型记录或先前结论。
