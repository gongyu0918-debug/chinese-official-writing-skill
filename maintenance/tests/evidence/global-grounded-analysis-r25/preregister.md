# R25 全局有据分析原子

用户澄清长期写稿要求：允许结合给定事实与常识分析前置原因、影响、后果和结论，不能因未逐字提供而一律判编造；要求参考付费版位置和已有验证，作为全局原子测试。

独立分支 `codex/global-grounded-analysis-r25` 从当前 main `176da7422b4ec2ffea82145c35498b09eddfea69` 建立。R24原子组合及更早未准入的项目专路不带入本轮。先只在 SKILL.md 任务模式路由前加简短原则，在已有信息选择页加“事实与分析”小节；不新增参考页、Hook或默认读页，不改付费功能或镜像。

两处表达属于同一职责原子：入口让所有写作任务可见，信息选择页明确有据分析、具体事实与既有保守限制的适用范围。已知关系、数字、未决状态和用户明确限定仍保持；由现状推原因不能无据写成已查明的唯一历史事实，复核也不能只因找不到材料原句就删除合理分析。不要求用户授权编造、填写要素卡或接受占位符。

本轮使用 Qwen 3.8 Max 与 MiniMax M3，同一自然任务两臂独立首稿：原始复杂增项申请、正常扫描仪采购申请、服务受理情况分析报告，共12次。前者沿用此前用户未经人工补因的原题；另两题检验跨文种作用和未定状态。提示不灌输候选规则或预期答案。两臂都按用户已澄清的分析标准评阅，不将“没有材料原句”当成充分失败条件。

模型自主读取入口及参考；沿用既有 Claude 隔离执行器，max effort、1200秒、零runner自动重试、不联网/Hook/其他Skill/记忆。运行器与提取器从R23固定来源复用，来源hash留证，不复制框架；冻结包由main Git字节导出，仅candidate覆盖两个已列文件。真实最终回复及实际文件均保留。工程完成、读页成功、长度达标与质量可用分别记录。

目标是能自然形成有依据的原因、影响和结论，同时不增加无据数字、事实记录、固定程序或状态升级；正文和交付要求不能回退。真实稿完成后先复核分析是否有依据与力度，保留未通过项；通过才补必要镜像和相关smoke，不以扩大裁判框架替代产品改进。本轮不预先授权合并或发布。
