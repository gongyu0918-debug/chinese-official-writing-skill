# 完整冷审三处修正的实际复验

对照为已冻结完整组合 `output/reference-integration-r16/candidate`，候选为同一包加 F01/F02/F03 的 `output/reference-integration-r16-final/candidate`。仅三文件不同，逐文件 SHA 和组合指纹由 combine_cold_fixes.py 保存。旧原稿、原候选及首轮 40 次组合写稿保持原样。

四个自然任务：100字以内的完整通知、明确40字以内的内部提醒、新闻评论审核后优化、同一评论仅审核。评论原稿包含错字、病句、用反引号包住的制作旁白和承担实际限定作用的否定比较，检验正常改稿、语义保真、脚本可见性及不同交付任务。80字下限仅适用于普通完整稿，明确更短提醒及审核意见按实际范围；不用短于prompt判失败。

Qwen第一通道medium、DeepSeek provider-default，四题各一对，16次原生Codex调用，420秒。本批补足三处实际改动，五通道的大组合另有冻结四题，不扩成全部修正×所有模型的交叉组合。脚本已有原始复现、阳性和技术代码/引用负控制；本批观察实际成稿和处理过程，不把模型未恰好保留反引号当作脚本回归失败。

对比时分别看：完整稿在有效篇幅范围，明确40字要求得到尊重；评论事实与有意义的否定比较保留，原稿语言问题可修；审后改稿交付全文，仅审核交付位置/问题/建议；过程旁白、文后提示、执行缺口单列。用户材料支持的合理原因、影响及通常拟议措施沿用既定宽容尺度。
