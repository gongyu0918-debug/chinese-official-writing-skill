# WR-018 丰富材料下的事务稿密度与合理推断预注册

## 目标

检验当前集成产品在材料事实较丰富、用户没有限定字数时，能否形成完整事务文稿，而不是只把提示词压成更短的事实摘要；同时检查一般原因、即时作用和低强度预期是否自然出现，且不升级成已经取得的成效。

本轮只诊断当前产品，不预设候选句。只有五路中出现跨模型、同方向且能由最小 reference 修改归因的功能缺口，才进入下一 A/B。

## A：采购申请

明川市政务服务中心业务协调处向中心主任办公会提交采购申请。现有2台高速扫描仪由6个综合窗口共用；2026年7月8日至19日业务记录显示，高峰时段每笔业务平均等待扫描7分钟，3次卡纸造成窗口累计暂停42分钟。拟采购4台高速扫描仪，单价1.7万元，合计6.8万元；资金可从2026年度信息化运维经费中安排。具体型号仍在采购评审中，事项尚未批准，也未采购。成文日期为2026年8月22日。

验收：原因或必要性前置；2、6、日期、7分钟、3次、42分钟、4台、1.7万元、6.8万元、资金来源、型号未决、未批准未采购和请批事项完整；允许写缓解扫描资源紧张、减少等待、提升办理效率等低强度预期，不得写成已实现。

## B：异常处置报告

明川市数据中心向市政务服务中心报告网上申报接口异常。2026年8月21日9时10分接口响应变慢，9时18分接到服务热线报告，9时25分切换至只读备用节点，9时42分恢复，10时05分完成业务核验；23笔请求一度排队，11时30分前全部处理完毕，未发生数据丢失。初步定位为缓存参数配置不当，根因复核仍在进行。平台组已形成参数优化建议，尚待技术委员会审核，未实施。成文日期为2026年8月22日。

验收：按时间、处置、影响、初步原因和未决建议形成关系；全部时间、23笔、无数据丢失、初步定位、根因在核、建议待审未实施完整；不得把初步原因写成最终结论或把建议写成已执行。

## C：活动新闻

明川市图书馆于2026年8月18日在一楼报告厅举办数字资源使用培训，主办和发布者均为市图书馆，62名社区文化工作人员参加。活动包括政策讲解、数据库演示、分组实操和现场答疑。54人完成检索任务，8人将于8月25日补测。现场收回16份意见表，其中界面建议7份、内容建议5份、场次安排建议4份；图书馆正在分类汇总，尚未决定是否采纳。一名参与者说，通过演示知道了地方志资料的检索入口。材料没有后续活动安排。

验收：完整日期、主办/发布者、地点、62、四环节、54/8、补测日期、16=7+5+4、汇总进行态、采纳未决和原话范围完整；允许写为参与者了解资源检索提供机会等一层即时作用，不得扩大为62人均已掌握、长期成效或新增后续活动。

## 共同判定

- 事实、状态、责任、文种功能、正文洁净度和直接可用性为硬门。
- 没有统一字数下限；若材料关系、必要文种动作和合理展开均完整，不能只因短而判失败。若成稿比材料主体更薄且遗漏关系、请批/报告/新闻功能，记 `THIN_FUNCTIONAL`。
- 结构与官方稿件对照只看目的/结论位置、事实支撑、事项落点和阶段关系，不要求复制官方标题、套话、段数或小标题。
