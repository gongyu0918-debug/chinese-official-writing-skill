# 官方真实稿校准

日期：2026-08-26。

本页只记录可用于判定边界的方法，不复制第三方模板或大段文字。

## 持续动作与尚未开展

- [上海市血液检测设备及耗材专项资金项目经费情况说明](https://www.shanghai.gov.cn/cmsres/58/58319f3561e94341bd46f757eba7ef50/83ed14c11486d5297b87d759b5068828.pdf)把“继续开展”明确承接到上一年度已经开展的同一筛查工作；同页另将其他机构“尚未开展”的工作与本中心已经开展的工作分开。可借鉴的是状态承接方法，不是固定措辞。
- [重庆市纪委监委转载的云南专项整治报道](https://jjc.cq.gov.cn/web/aritcle/web/content_1455482899752353792.html)明确区分已经开展或正在开展、需要持续巩固的项目，与虽有安排但尚未开展的项目。由此确认：已有职责或安排不等于工作已经开始，“继续”必须绑定已经发生或正在发生的同一动作。

## 采购原因与影响强度

- [北京大学高性能集群 GPU 节点单一来源采购公示](https://www.lab.pku.edu.cn/info/2411/42951.htm)从用户争用 GPU 服务器直接形成资源紧张判断，并据此提出增加 GPU 服务器。它支持“资源紧张—拟补充资源”的一层必要性，不支持在没有延期、中断或故障数据时继续扩大为业务已经无法正常开展。

## 局部未发生与整体结论

- [上海市政务外网网络建设及运行服务项目绩效评价报告](https://www.shanghai.gov.cn/cmsres/b7/b798df5cdfaf4ceaa13a1e80f2ee15d9/f976b5d0608947deb0f8c5ff0b3816a2.pdf)把零中断、未发生信息安全事故分别绑定到具体统计期间、重大保障期间或网络维护期间，再据此评价对应指标。可借鉴的是时间、对象、指标范围与结论绑定；不能把一次或两次事件中的“未发生”外推为系统整体长期安全稳定。

## 对本轮判定的约束

1. 官方稿允许基于直接事实形成原因、必要性和有限影响；不能因为结论未在材料中逐字出现就判错。
2. “继续”不是禁词。只有同一主体的同一工作已经开展或正在开展时，延续性表述才有事实支点。
3. 未发生类结论必须保持原统计期、事件、对象和指标范围；范围足够时允许总体判断，范围不足时不得升级。
4. 这些来源只校准判断方法，不作为 Skill 固定句式，不复制其文字、模板或代码。
