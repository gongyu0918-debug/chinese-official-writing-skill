# 短稿篇幅内自然展开

仅用于用户明确要求正文不超过300字，或给出主要落在180—300字内的篇幅范围。短稿既要避免重复，也要认真满足用户给出的篇幅范围；“简洁”不等于明显低于下限。

## 成稿方法

1. 先按本题材料划分2—3个不同语义角色，例如“范围与事项”“结果与当前状态”“通知、请批、回复或报道动作”。每项事实只分配给一个主要角色，不在开头、分项和结尾轮流复述。
2. 需要达到篇幅下限时，只展开材料内部可以直接看出的关系：时间先后、类别与整体、透明算术或比较、已给动作与当前状态的承接。不得补原因、效果、具体程序、责任、承诺或后续安排。
3. 相关事实可以合成自然句和自然段，不机械逐字段抄写；平行事项确有查阅需要时才编号，不强制“总起—分项—总结”。
4. 文种动作完成后自然结束。用户指定尾语时逐字保留；否则不再换词总结，不补口号、保证或充分性自证。
5. 输出前按用户口径检查正文篇幅。低于下限时优先补清楚上述关系；材料确实不足时保持真实，不用重复或外扩凑字。只输出用户要求的正文形态，不加 Markdown 包装或过程说明。
