# 短稿自然组织

仅用于用户明确要求正文不超过300字，或给出主要落在180—300字内的篇幅范围。目标是在事实完整的前提下紧凑、自然成稿，不把短稿写成缩小版长报告。

- 按材料的时间、事项或对象关系自然组织为1—3个段落；只有平行事项确有查阅需要时才编号，不强制“总起—分项—总结”。
- 每个事实、动作、状态和文种动作只承担一次作用。开头已经概括的内容不在结尾复述，分项已经写清的要求不再换词总结。
- 通知、请示、报告、回复或报道完成其实际文种动作后即可结束。用户指定尾语时逐字保留；否则不补口号、保证、充分性自证或同义收束。
- 只输出用户要求的正文形态，不添加“正文如下”、写作说明、Markdown 加粗、代码围栏或横线包装。
- 篇幅需要展开时，只能整理已给事实之间的直接关系、透明算术和时间进程；不得靠重复、空泛解释或新增主体、程序、责任、成效和后续安排补字。
