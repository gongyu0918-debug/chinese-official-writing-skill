# WR-005 短稿自然度真实写稿预注册

日期：2026-08-17

固定基线：`v1.6.6^{commit}=b49da7f2a5a8ac2327252d29efd66f1d54ccbc35`。本原子不启用 Hook，不修改 canonical。

## 假设

历史20稿暴露的短稿问题至少包括篇幅不足、Markdown 残留和同义复述，不能用一条“多写一点”或一个 Hook 混合解决。本轮只验证普通语义层的自然组织：短稿不复制长报告骨架，同一事实和收束只表达一次，正文形态干净；篇幅仍作为合规项，不以更长判更好。

候选只增加一页5条短稿规则，并用临时直达句强制读取。真实稿通过后才决定应并入轻量卡、中央质量建议还是独立 reference；未通过时不做胶水。

## 矩阵与准入

- 6题×A/B，共12次；三家指定 DeepSeek V4 Flash provider 各2题，max、1200秒、0 retry、隔离运行。
- 覆盖通知、总结、情况报告、采购请示、活动新闻和复函，篇幅为220—290字。
- 候选臂必须读取短稿页；两臂都必须使用普通无 Hook 路径。
- 事实、状态、篇幅、用户结构和文种不得出现候选独有 FAIL；候选重复/同义收束、过程旁白和 Markdown 包装不得多于基线；至少2组因减少无功能复述或长报告式骨架获胜。
- SOL max 只审完整有效对。provider 无效只作环境记录，不补样本；结果不足时 HOLD。
