# 短稿自然度 R3：上限题

日期：2026-08-17

R1/R2 证明把明确下限与自然度放进同一规则，会迫使模型在偏短和材料外扩之间摆动。R3 只测试自然度：四题改成“不超过260/280字”，不设下限；under-length 仍是独立能力。

- 4题×A/B，共8次；Ollama、Alibaba 各2题，max、1200秒、0 retry、两条 lane 内串行。
- 候选必须读取 R3 页，普通无 Hook；基线仍为 v1.6.6。
- 事实、状态、上限、用户结构和文种不得出现候选独有 FAIL；候选的同义复述、长报告骨架、空泛收束和包装不得多于基线。
- 至少2组因减少无功能复述、分层或包装而获胜，且候选无材料外扩，才考虑写入产品；完整有效对交给全新 SOL max 匿名复核。
- 不因稿件更短判它更好，也不把未达到不存在的下限记失败。
