# WR-005b-SHORT-ROUTE-SEMANTIC-R3 预登记

## 单原子

在 R2 已移除 `300字`、`200字` 固定阈值且消除过程说明回退的基础上，只收口两项直接风险：

1. 用户明确说明“不要求短稿”时，不读取短稿自然收束页；
2. 短稿压缩不得把相对、可能或条件判断收紧为绝对结论。

不新增“简洁、精炼、紧凑”等直达触发词，不改五条既有写稿动作，不改 Hook。

## 真实写稿

沿用固定 main 基线和同题旧稿，仅重跑五家低成本 provider 的三个病例：

- `SEMANTIC-COMPACT-PURCHASE`：保护“维修费用接近同档新机价格”，不得升级为“已无维修价值”；
- `UPPER-480-SITUATION`：验证仅有上限的短情况说明仍可按语境路由并完整保留未决状态；
- `UPPER-1500-FULL-SPEECH`：题面明确不要求短稿，验证短稿页误读及讲话完整性。

## 判定

- 技术失败不计质量票，但必须保留；
- 与差异无关的模型随机扩写只作风险观察；
- 任一与短稿读取直接相关的材料外数字、决定、责任、程序或正文外包装为硬回退；
- 两家及以上有效 provider 在完整讲话中仍读取短稿页，终止本候选；
- 合理的原因、作用、总结和条件性推断不算失败；
- 通过真实写稿后才进入直接工程门，不合入 `main`、不发布。
