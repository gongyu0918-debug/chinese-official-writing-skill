# 编者按独立主叶

当前新闻消息页同时要求编者按标识和消息标题导语。新原型把编发者身份、编发对象/缘由/阅读方向归到独立编者按页，从消息页撤去按语专属句，在目录增加明确去向。只改三文件，消息其余规则、共性流程和脚本不变。目录清理原型另行构建，后续组合时合并此独立目录条目，不覆盖彼此改动。

已在2026-09-13复核两篇发布者原稿：[新华社2025-01-10](https://www.news.cn/20250110/3f5339fe02704cb8a5426f456a55a173/c.html)以开头标识承载编者按；[人民日报2025-01-07](https://paper.people.com.cn/rmrb/pc/content/202501/07/content_30050370.html)以标题和编者署名标示身份。两者都以编发对象、背景和阅读目的组织，但段数和标识形式不同。据此归纳写作功能，不把个例段数、题名或署名同时提升为硬格式。此处是架构推论，来源并不规定Skill分几页。

真实写稿先用独立按语、按语与消息合并交付、既有消息负控制三题，Qwen第一通道medium、DeepSeek默认，各做双臂。请求不指定叶子文件名，观察选页、按语身份、消息必要事实、原文范围、80字及提示隔离；合理作用、评价和编发期望不判成具体既往事实。逐次保留输出和读页/脚本轨迹，独立比较正文与整条交付。单项可用后再与本轮目录和文种用途修正进行组合，不把文件可达当写稿通过。
