# 函、复函与征求意见函 Playbook

本文件用于普通函需要常规或完整文种骨架时快速进入对应叶子。复函和征求意见函继续按 `SKILL.md` 读取完整文种 playbook。

## 使用方式

- 从 `SKILL.md` 直接进入本页；本页只给文种骨架和专项风险，不补材料外事实。字段式材料按入口硬边界保持字段单元，信息进入正文、保持状态、省略或短列缺口按 `information-selection.md` 处理。只有任务另有复杂改稿、多材料合稿或文种/行文关系不明等条件时才补读长 reference，节末“补充读取”不是固定清单。

## 函/复函/征求意见函

- 适用：平行商洽、答复来文、征求意见或协调事项。
- 骨架：来文依据或事项背景 -> 商请/答复/征求事项 -> 办理意见 -> 反馈期限和渠道 -> 联系人和附件。
- 风险：复函重回应来文；函不写成命令；征求意见函必须给反馈路径。
- 称谓与语气：称谓服从用户模板和已给主体；不相隶属单位之间需要称谓时可用“贵单位”等中性称谓，商请事项用“商请”“请予支持”等平等措辞，不使用命令式或审批式口吻。
- 反馈信息：材料已给或办理确有需要时，保留反馈期限、方式、联系人和附件；材料未给且不影响办理时不把这些内容补成固定要素。
- 结语：按商洽事项需要简洁收住；需要结语时，可用“专此函达”“请予支持为盼”等函件表达。
