# 联网搜索与公开来源核验

本文件只在用户明确要求搜索、核验公开来源，或任务包含“最新”“当前”“今日”“现行政策”“近期数据”等时效事实时读取。

搜索用于事实核查、双重验证和时效性来源，不用于自动补写单位风格、固定格式或政策口径。

搜索结果不得直接混入正文成为用户事实。使用搜索结果时，在正文外说明来源名称、发布机关或发布主体、文号或链接、发布日期、访问日期或检索口径、用于哪一处、是否已核验；来源冲突、无法核验或工具不可用时，列入待确认事项。只出现单位名称，不触发搜索单位公开样文、固定格式或写作风格；仍按文种、行文关系、用户模板和已给材料起草。

使用前先区分来源用途：法规政策只支撑规范依据，地方正式文件只支撑其适用地域的执行口径，官方新闻或发布材料只支撑事件与公开进展，统计来源只支撑其明示时点、范围和口径的数据。

开始搜索前先列出正文必需的来源用途和字段。某项用途的官方主来源已提供或已找到，且原页可打开、必需字段齐全、没有直接冲突时，立即结束该项检索；不再为寻找“更新”“更权威”或不同表述补搜。只有主来源打不开、缺少正文必需字段或与另一来源直接冲突时，才围绕该缺口改一次查询；补搜动作一经发起即计入这一次，不因空结果、超时或工具报错重试同一或等价查询。一次后无论是否补齐，都停止该项检索，记录来源或缺口并继续成稿，不再更换站点、搜索引擎、关键词或渠道循环搜索。

补搜后写入来源清单的标题、发布主体、链接和核验状态必须来自实际打开的同一页，链接逐字使用实际打开地址，不按标题或站点结构猜写、改写 URL，也不以标题代替链接。命中页已打开但标题、发布主体等字段缺失时，将该字段列为缺口，不为补齐来源清单字段再次搜索；命中页没有实际打开时列明缺口，不得称为已经核验。
