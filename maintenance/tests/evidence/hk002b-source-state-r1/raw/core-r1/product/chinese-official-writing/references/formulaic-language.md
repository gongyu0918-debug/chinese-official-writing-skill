# 公文行文用语

本文件用于选择正文内部的开端、引叙、承启、期请、综合和结尾用语。它们服务文种功能、行文关系和办理目的，不是 GB/T 9704 的版式参数。版式、位置和落款仍按 `format-gbt9704.md`；用户已有模板时优先保留其合法用法。

下表20类事务文体在文种明确、材料单一且表中功能足以覆盖任务时，本文件与 `information-selection.md` 组成直接叶；无需继续读取 `workflow.md`、`genre-routing.md`、整套 `genre-playbooks.md` 或复核清单。只有文种不明、多材料合稿、长文、正式版式或专项要素超出本表时，才补读对应 reference。

## 基本原则

- 先确定文种、行文方向和办理目的，再选择用语；不用某个固定词反推文种。
- 用语只能组织已给事实。没有来文，不写“收悉”；没有批准事实，不写“经批准”；没有请批事项，不补请批语。
- 引用材料事实时保持原时间锚。材料只给月份、月日或时间段，不补`今年`、`本年`或具体年份；材料只说调整提示卡、指引、工具或流程时，只写已给调整事实，不自行补调整内容、材料外使用场景或已经实现的便利和成效。
- 固定尾语不是每篇必填。事项已经自然结束，或纪要、汇报提纲、调查报告等按内容自然收束时，不强加固定尾语。
- 一篇稿只保留一个有效收束，不叠加“综上所述”“特此报告”“以上报告”等多层尾语。
- 报告不写请批语，函不写成命令，通知、批复、请示和函的口吻不得串用。

## 事务文体功能接引

下表只提示文体功能和常用接引，不是固定模板。材料不足时不为补齐表中环节编造事实。

| 文体 | 必须完成的功能 | 可按需使用的接引或收束 |
| --- | --- | --- |
| 计划 | 交代执行期、任务、主体和已给节点 | `现将有关工作安排如下`；任务列完可自然结束 |
| 汇报 | 报告事实、进展、问题和已给下一步 | `现将有关情况汇报如下`；不补请批语 |
| 调查报告 | 交代调查范围、数据、发现和已有处置 | `现将调查情况报告如下`；无分析依据时按事实自然收束 |
| 讲话稿 | 体现称谓、场合身份、事实基础、要求或期望 | 以称谓开篇；结尾可致谢或提出与场合相称的期望 |
| 演讲词 | 体现演讲人身份、主题、事实、观点和号召 | 可用`大家好`、`谢谢大家`；一般延续须由演讲主体承担 |
| 答复 | 承接意见、建议或询问，说明现状和答复事项 | `现就有关情况答复如下` |
| 责任书 | 明确各方责任、共同事项和材料已给要求 | 不写材料未给的`经协商一致`、签订过程、奖惩或追责 |
| 公开信 | 面向明确对象说明背景、事项和配合要求 | 保留称谓；结尾可作与材料相称的呼吁 |
| 倡议书 | 说明缘由，提出具体可执行的倡议 | `现发出如下倡议`；不把倡议扩成处罚或检查制度 |
| 建议信 | 以事实和问题为依据提出具体建议 | `现提出如下建议`、`以上建议，请予考虑` |
| 新闻发布稿 | 发布核心事实、处置进展、当前状态和已给渠道 | 标题与导语先交代最重要事实；不补恢复时间和结果 |
| 总结 | 回顾周期事实、工作、在办事项和已给下一步 | 有真实归纳时可用`综上所述`；不靠总结段新增成效 |
| 情况反映 | 说明对象、时间、数据、问题表现和当前处置 | `现将有关情况反映如下`；无依据时不补原因结论 |
| 情况综合 | 综合来源、分类、共性差异和当前研究状态 | `现将有关情况综合如下`；未形成决定时保持原状态 |
| 编者按 | 显示编者身份，说明编发对象、目的和下文内容 | 以`编者按：`或用户模板中的同类标识起笔 |
| 新闻 | 用标题、导语和主体报道已发生事实及当前进展 | 进行态由材料主体、写作主体或近邻可继承主体承载 |
| 短评 | 以事实为前提提出中心判断并展开不同论点 | 事实与评论推演分开；论点充分后自然结束 |
| 讲解稿 | 面向受众说明对象、顺序和已给信息 | 可用称谓和路线承接；互动、问答须有材料或用户授权 |
| 宣传手册 | 用标题和分项内容说明已给要求、方法和渠道 | 分项标题服务查阅；不补处罚、监督或其他责任 |
| 宣传材料 | 说明宣传对象、事项、时间地点、参与方式和边界 | 号召只落在材料允许的行为，不扩展服务和适用范围 |

## 当前常用

### 开端和依据

- 目的：`为……`、`为了……`。
- 依据：`根据……`、`按照……`、`遵照……`、`依据……`。
- 背景或现状：`鉴于……`、`由于……`、`目前……`、`近日……`。
- 承接办理：`现将……`、`经研究……`、`现就有关事项……`。

依据、会议、批准或研究动作必须在材料中成立，不用“经研究”“经批准”提升权威感。

### 引叙来文

- 复函可用：`《关于……的函》收悉。经研究，现函复如下：`。
- 批复可用：`你单位《关于……的请示》收悉。现批复如下：`。
- 标题、文号、日期和来文主体以材料为准；未知时不编造占位。

### 承启和综合

- `为此`、`据此`、`有鉴于此`用于承接前文事实、原因或依据。
- `综上所述`、`总之`用于真实归纳。单个综合用语不是 AI 味；没有新增归纳作用、只是重复上一段时才删减。
- 条款式正文可用`现提出如下意见`、`现将有关事项通知如下`等承上启下，但下文必须与引语对应。

### 按文种结尾

- 请示：`妥否，请批示。`、`当否，请批示。`、`请予审批。`、`请予批复。`
- 报告：可用`特此报告。`、`以上报告，请审阅。`；内容已自然结束时也可不另加尾语。
- 批复：`此复。`、`特此批复。`
- 通知、通告、公告：需要固定收束时可用`特此通知。`、`特此通告。`、`特此公告。`
- 去函：按事项可用`特此函达。`、`请予函复。`、`盼复。`
- 复函：`特此函复。`、`此复。`

请示必须有明确请批事项；报告不得夹带批准请求；去函是否要求回复应在结尾中说清，不需要回复时不写期复语。

## 条件使用

- `兹`、`兹有`、`兹定于`可见于证明、法律通知或固定公告体；普通事务材料优先直接说明事项。
- `敬悉`、`谨悉`、`承蒙`、`惠示`、`惠寄`、`如蒙`用于特定函件或礼仪语境，服从双方关系和用户模板。
- `为盼`在商请函中仍可使用；`为荷`、`为要`等依赖单位习惯，不作为通用默认结尾。
- `前接`、`现接`、`近接`等可按既有模板保留；新稿优先使用`收悉`或`来函收悉`。

条件用语不因“更像公文”而自动添加；同一篇避免敬辞、谦辞和期请语堆叠。

## 历史文体兼容

`切切`、`此布`、`切切此令`、`近奉`、`顷接`、`左列`、`右列`、`上项`、`数纸`等主要用于历史公文、档案转写或特定旧式模板。普通现代公文不主动生成；用户要求保留历史原貌时，按原文和时代语境处理，不擅自现代化或扩写。

## 复核

- 用语与文种、主送对象、正文功能是否一致。
- 引叙的文件、文号、日期和研究/批准动作是否确有材料依据。
- 固定尾语是否真正需要，是否与落款、日期位置正确衔接。
- 是否重复收束、堆叠敬辞，或用旧式词掩盖事项不清。
