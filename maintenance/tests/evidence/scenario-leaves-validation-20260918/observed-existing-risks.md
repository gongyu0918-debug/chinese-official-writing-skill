# 本轮观察到但不扩展修改的既有风险

这些问题都来自真实调用，不将其当作新增专项规则有效的反证或成功的功劳。产品首页、writing-rules、anti-ai、脚本在两臂相同。

1. **乘号占位漏检。** Qwen P2基线终稿在缺失供应商、金额、联系人等处保留“××”，与题目要求缺项单列提示相违。扫描命令实际返回`No prose risks found.`，保存稿仍含“××”。现有占位正则主要覆盖拉丁X等，乘号不是同一个字符。本轮不修改脚本，避免混入另一项实验。
2. **扫描后最终消息再加Markdown。** DeepSeek R1复测候选保存/扫描的txt不含`**`，最终消息给标题和小标题加了粗体。Qwen R2初测基线同样出现标题加粗。扫描底稿与最终交付消息并非总是同一字面文本，这是既有流程的偶发风险，不是新增页要求加粗。
3. **正文外自述和过多缺项提示。** Qwen/DeepSeek在两臂均可能附字数、扫描通过声明、Word邀请、缺项列表；DeepSeek R2候选还附Hook自述。用户接受正文外过程文字不计正文污染，但无用提示仍单列质量不足。
4. **偶发多读相邻主叶。** DeepSeek B2候选在读到新增预算页之前已读取采购公告、技术需求等无关页；两臂的信息化/采购稿中也有相邻主叶并读。新增页实际可达和控制题少读不等于所有路径完美。

以上保留为后续可单独处理的事项；不在本轮转向脚本、首页或共性路由重构。
