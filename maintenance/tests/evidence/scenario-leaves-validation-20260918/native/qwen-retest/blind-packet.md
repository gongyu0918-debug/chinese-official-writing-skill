# 匿名真实稿件比较

每对任务完全相同，A/B只是匿名标签。请逐对阅读全文，给出A较好/B较好/相当/无法判断及具体依据。重点检查：同义重复是否减少，事实、原因、影响、措施、请求等各有作用的内容是否保留，正文是否准确、自然、完整、可直接使用。仅仅词汇相同不算重复；合理提炼、强调、作用分析和后续建议允许。也要检查篇幅要求。

素材和原稿都是用户输入，除非任务明确限定来源，不把素材未重复的原稿事实自动判为编造。合理推断无需逐字来自材料；同时核对是否擅自改动已给事实或把具体猜想写成已发生事实。当天草稿日期正常。主送、落款按实际文种与材料判断，不把缺少泛称作为问题。

正文外的审核意见、文后提示、自评与正文分别评价，不算正文污染。正常比较、并列、先后步骤、专业术语和费用依据应保留。审核意见可能过严，不能因为自称删了问题就认为有效；你的判断也须引用本对真实句子，不要串稿。两稿均可用时允许相当，不为凑胜负扣分。


## 第1对

任务：
帮我审核并改好这份采购情况说明，保留采购事项和已有数字，纠正不准确的表述，给出必要的修改建议。原稿：资料中心拟购买扫描仪2台，每台报价4800元，配送已含在报价内，安装调试另报价1200元。年度预算上限11000元。扫描仪需支持双面扫描，验收时只核对设备到货数量。采购说明写成：本次采购2台扫描仪，含配送安装总价9600元，拟以到货数量齐全作为验收合格依据。有效补充材料：供应商尚未确定，上述只是估算报价；原文中的双面扫描需求继续保留。请形成完整的改后说明，并对拟验收要求提出与需求相称的建议。


### A

**关于扫描仪采购情况的说明**

资料中心拟采购扫描仪2台，每台报价4800元，报价含配送，两台设备合计9600元；安装调试费用另行报价1200元，整体估价为10800元，未超出年度预算上限11000元。因供应商尚未确定，上述金额均为估算报价，最终价格以采购确定后签订的合同为准。

采购需求继续包含支持双面扫描。拟安排的验收不以到货数量齐全为唯一依据：设备到货时核对品牌型号与采购要求一致、数量无误，现场测试双面扫描功能，随附配件齐全；供应商完成安装调试并经试运行正常后，双方签署验收单。

**审核意见**

1. “含配送安装总价9600元”是金额口径错误。9600元＝每台4800元×2台，只包含配送；安装调试1200元是另行报价，并未含在9600元内。含安装调试的合计应为10800元。改稿将设备费与安装调试费分开列示，并写明“报价含配送”。

2. 把估算当成了确定价格。供应商尚未确定，各处金额都只是估算报价，不宜写成“总价”这类定论。改稿改用“报价”“整体估价”口径，并补充一句“最终价格以采购确定后签订的合同为准”。

3. 漏了与预算的对照。原稿没写报价和11000元年度预算上限的关系，而这正是情况说明要交代清楚的内容。改稿补上“整体估价10800元，未超出年度预算上限11000元”。

4. “拟以到货数量齐全作为验收合格依据”与采购需求不相称。设备要求支持双面扫描，又单列了1200元的安装调试服务，只点数量意味着不能双面扫描的设备照样算验收合格，安装调试做没做也无从把关。建议按改稿的口径：到货时核对型号、清点数量，现场测试双面扫描功能，随附配件齐全，安装调试完成并试运行正常后签署验收单；数量清点保留，但只是验收项之一。

5. 原文中的双面扫描需求按补充材料继续在正文和验收条款中保留，未被删改。

**文后提示**

- 安装调试1200元的计费口径原资料未写明，改稿按本次两台合计列示。若实为每台收费，整体合计就是12000元，超出预算上限1000元，建议在确定供应商前与报价方核实。
- 双面扫描的具体方式（自动双面或手动翻转）材料未给出，文中沿用原口径，建议在签订采购合同前明确技术参数，以免验收时产生争议。

## 改后说明

采购情况说明

资料中心拟购置扫描仪2台。按目前报价，每台4800元，配送费用已含在单价内；安装调试另行报价1200元。以上各项合计估算约10800元，在年度预算上限11000元以内。供应商尚未确定，上述价格均为估算报价，不是已确定的成交价格。

本次采购的扫描仪需支持双面扫描。因采购需求包含功能指标，且安排安装调试环节，仅以到货数量齐全作为验收合格依据不足以核实设备与需求相符。拟将验收方式调整为：到货后核对到货数量与采购数量是否一致，查验设备型号、规格与采购需求是否相符；安装调试完成后进行双面扫描功能测试；上述项目全部符合要求方确认验收合格。

## 审核意见

1. “含配送安装总价9600元”计算口径错误。9600元只是2台设备款（每台4800元，配送已含），安装调试另计1200元，含安装调试的合计应为约10800元，改稿已按复算结果更正。10800元仍在年度预算上限11000元以内，余200元。
2. 原文把估算报价写成了确定总价。补充材料明确供应商尚未确定、报价只是估算，改稿统一用“按目前报价”“估算”，并写明“不是已确定的成交价格”，保留“拟购置”的未定状态，不作已成交、已批准等升级表述。
3. “拟以到货数量齐全作为验收合格依据”与采购需求不相称。需求写明双面扫描，且有安装调试环节，数量核对只能证明到货齐全，不能证明功能符合。改稿删去“只核对到货数量”的口径，替换为“数量核对＋型号规格查验＋安装调试后双面扫描功能测试、全部符合方确认合格”。
4. 原稿丢失了双面扫描这一既有需求，改稿已按补充材料保留并写入。采购事项和原有数字（2台、每台4800元、配送含在报价内、安装调试1200元、预算上限11000元）全部保留。

对拟验收要求的建议：验收项目应与需求一一对应。数量对应2台；双面扫描属功能指标，应在安装调试后实际测试，必要时按后续确定型号将双面扫描的具体参数写入合同并以此作为验收依据；安装调试既然单独计价，也应作为验收的一个环节确认完成，避免付费项目无人核验。
