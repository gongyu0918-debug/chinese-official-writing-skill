# WR-013b-R8.3 活动即时作用窄例外预登记

- 固定输入：继续使用 `prompt.txt` 的 A/B/C 三篇活动新闻，同一模型、同一思考档位比较 R8.2 与 R8.3。
- 单一变量：把发布者角色约束与即时作用约束拆成两个条目，并明确即时作用是通用禁补效果规则的文种内窄例外；稀疏材料不得为写作用补参与者动作或活动内容。
- 目标：A/C 在不改变角色、待核状态和事实范围的前提下各出现一层合理即时作用；B 可写“提供阅读交流机会”一类由活动名称直接支持的最小功能，也可因 260 字上限省略，但不得再补“青年开展分享”等材料外动作。
- 硬回退：新增地点、辖区来源、主承办角色互换、参与者动作、反馈结果、后续安排、长期成效，或漏写年份、设备支持、待核状态等题面硬事实。
- 判定：合理原因、目的、即时作用和低强度预期不作为事实扩写失败；五路结果用于发现风险，不按模型多数投票。
