# WR-014-R5 采购状态层级官方语料研究

日期：2026-08-25。

## 问题来源

“尚未形成采购决定”不是多重否定；句内只有“尚未”这一层否定。风险在状态层级：材料只给型号、供应商、采购方式等局部节点未定时，若正文上推成整体采购决定未形成，可能与已经作出的原则采购决定冲突，也可能把具体阶段写成抽象套语。

仓库早期合成样本曾明确给出“会议没有形成新增采购决定”，后续模型写成“会议未形成新增采购决定”或“尚未形成采购决定”。显式来源里的整体未决状态应保留其办理含义，不能因为表达不自然就删除。当前 `anti-ai-patterns.md` 处理的是采购下游未发生事项链，没有覆盖局部状态向整体状态的上推；当前 Hook 也没有这一语义关系的专门 adapter 或 capability。

## 官方公开表述

- 中国政府采购网《中国政府采购报》案例在讨论合同签订条件时写“政府采购活动尚未完成，中标、成交供应商尚未确定”，把活动阶段和供应商状态分别说清；没有抽象成“采购决定尚未形成”：<https://www.ccgp.gov.cn/llsw/202404/t20240423_21892700.htm>。
- 上海市发展改革委公布新型基础设施投资机会清单时写“部分产品或服务等尚未确定采购对象或承建主体”，直接承载具体未定对象：<https://fgw.sh.gov.cn/fgw_fzggdt/20231019/440820b253814ef9929fb9cb6aa99e8f.html>。

上述两例只用于校准状态层级和表达方法，不把单个官方例句复制成固定模板，也不据此宣称“尚未形成采购决定”在所有正式材料中错误。

## 研究假设

1. 已有总体采购决定、只有执行节点未定：保留总体已决和具体未定，不上推成整体未决。
2. 材料明确整体未决：保留其办理含义；可以写“未作出新增采购决定”，也可以用“会议仅听取情况、后续再研究是否采购”等正向事实承载，不要求机械保留某一原句。
3. 材料给出明确采购阶段：优先写该阶段和具体未定对象；若同时保留具体阶段，偶尔附加抽象概括只记表达风险，不直接判事实硬失败。
4. 事实和常识直接支持的采购原因、即时作用、低强度预期、必要结论和论证仍按 WR-013 接受；本原子不把合理推断重新挡回事实罗列。
