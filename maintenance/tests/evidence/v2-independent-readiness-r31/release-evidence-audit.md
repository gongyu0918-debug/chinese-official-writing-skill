1. **1.0 对照仍有效。** `1ce71123` 与本轮开始时 `main@d561bf6b` 的普通 `SKILL.md`、references 和两个普通脚本相同，差异只在七个 1.x Hook manifest 版本字段。因此本轮把 `1ce71123` 继续作为普通能力金线合理，不必因 main 版本推进重跑整套 1.0。
2. **2.0 基础架构和功能归属可承接。** R25 已签结 67 个 reference、40 个主文种叶、两个独立普通脚本和五套兼容镜像；R24/R25 共 34 次原生调用中 32 次具备规则比较资格，讲解页定向修复后当时为一优一平。该证据支持主文种/任务双轴、合理推断、事实状态、日期、篇幅、复核、Word 工具衔接和普通脚本等职责已建立，不等于每次写稿都正确。
3. **全包可达性和静态职责可承接。** R28 的 GLM 完整回读 67/67 references 和两个脚本，Sol 另作全包审阅；文件路径和 route manifest 通过，未发现硬断链或强制死循环。R31 只改四页局部文字和 `prose_lint.py`，未改 67 页主体架构，故无需重做全包冷审。
4. **R30 的格式修法可有限承接。** 两模型、两轮共 20 次原生调用中，普通采购申请外层围栏由基线 3/4 降到候选 0/4，8 份明确 Markdown 通知都保留标题和列表。它支持“区分底稿样式与本轮交付格式”的局部收益；一份候选仍未完全按列表要求组织，正文称谓、资金来源和耗时风险均保留，不能承接为全面质量或效率胜出。
5. **R31 脚本增量仅能证明行为契约。** `--allow-markdown` 能放行明确要求的标题、加粗、列表、横线和围栏，同时继续报告旁白、思考泄漏和占位符；它不能判断材料事实、状态或正文质量，也不能证明模型会正确选择该参数。

历史证据不能覆盖本轮已重复出现的公告、采购和讲解正文风险。尤其 R25 曾处理的讲解具体事实扩写再次出现后，不能再把旧签结解释为“该风险已经永久消失”。

## 尚未消解的发布阻断与限制

### 发布阻断

- **公开范围被扩写成业务保证。** “局部开放”被写成其他业务或培训“不受影响”，属于材料未给的具体运行状态/承诺；当前摘要显示两模型候选重复、1.x 对照未出现，已超过单次风格波动。
- **未决预算状态被具体化。** 材料仅说明预算科目已询问、尚未回复，却补成“拟从公用经费列支”。这不是一般购置目的推断，而是具体资金来源；R30 和 R31 均有同类观察。
- **讲解稿具体事实扩写复现。** 加工链和销售状态需要材料依据；在 R24 曾构成阻断、R25 定向修复后又出现，当前不能按一般观察指引或合理说明放行。

### 非阻断但必须如实披露

- R28 仍记录偶发错读主叶、漏读 anti 页、临时稿与最终回复包装不一致、假链接和个别讲解错误。R31 已修正兼容路由指针与格式规则，但不能据规则存在宣称模型每次执行到位。
- 历史数据只支持规则读取字符减少；input、未缓存 input、耗时和输出量在模型与题目间方向不一致，无账单证据，不能宣传更快、更省或成本下降。
- Word 能力是“规则衔接宿主文档工具”，包内没有 DOCX 生成器。历史有文字级 DOCX 证据和脚本能力，但不是所有宿主、所有版式的当前实物验证。
- `agents/openai.yaml` 未随包复制，意味着依赖该文件的宿主不会获得自定义英文展示名/default prompt；它不承载写作规则，通用 Skill 加载不因此缺功能。若目标平台强制要求该元数据，应在该平台上传前另核其包规范。

## 本轮仍需回答的最少问题

不需要扩大全文种样本，也不应继续抽样 unchanged 候选来冲淡已经重复的硬回退。最低闭环如下：

1. **完成并固定现有预登记批次的配对判读。** 只回答公告范围、采购资金状态、讲解具体事实，以及是否存在其他候选特有的普遍硬回退；正文外 Markdown/质检说明、合理推断和当天落款按既定尺度排除。
2. **若采用公开发布叶和申请叶的近场修复，最多保留已计划的 8 次定向 A/B**（两题 × 两模型 × 父 2.0/修复候选），确认无依据保证和具体资金来源消失，同时原有事实、待定状态、Markdown 交付和正常申请功能没有受损。失败即停止，不重复抽样。
3. **讲解风险不能靠上述 8 次顺带关闭。** 若本轮不修改讲解页，则维持 HOLD；若要争取对外测试版，只需围绕同一复现题对具体修法做最小两模型父候选配对，不需要再跑全矩阵。
4. **最终产品候选需要一次真实新身份 smoke。** 用预览目录名和 `name: chinese-official-writing-v2` 原生调用一次，确认宿主确实加载新 Skill；结构检查不能替代安装/调用证据。
5. **任何规则修复后重建一次预览并重算清单。** 复核仍为 72 个预期文件、70 个非身份文件与最终冻结候选逐字节一致、所有相对链接可达、ZIP 与 manifest 哈希匹配。无需为了可选 UI 元数据增加第 73 个文件。
