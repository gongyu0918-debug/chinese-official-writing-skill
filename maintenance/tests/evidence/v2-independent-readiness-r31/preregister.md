## 判定

完整正文由主审和独立模型评阅，区分事实/状态/要素、合理推断、正文污染、格式、范围与文后提示。草稿补今天不自动判错；明确待定或留空时按原要求。正常目的/原因分析允许；正文外意见的 Markdown 和质检声明不当成正文污染。单次差异是观察，读页/调用行为和复测支持后才做规则因果判断。

耗时、input、cached input、未缓存 input、output、实际读取规则字符、脚本执行分别统计，脚本调用率不作为写作胜负。无账单证据不宣称费用下降；均值、合计与分题波动同时呈现。

脚本行为用必要 Python 单元测试；文件路径、manifest、镜像用结构检查；语义规则不做关键词/整句门禁。已有完整规则冷审按未变职责承接，本轮增量另冷审。产品暂保留内部源目录名用于同题 A/B，发布名称与独立包标识在发布准备阶段隔离，旧兼容包不得直接用于新产品上传。
