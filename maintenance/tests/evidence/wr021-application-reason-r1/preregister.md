# WR-021 申请原因前置 R1 预登记

## 问题与边界

采购申请、请假申请属于请求审批的事务性申请，正文不能只换写申请事项而完全没有原因、依据或必要性。官方公开材料中，大型设备采购要求分析采购必要性和现有设备负荷；教职工请假表把“请假事由”列为独立字段，现行年休假规章也提供一般制度依据。

本原子只调整请示/申请专叶，不改变通用事实边界：

- 材料已经给出原因、依据或现状压力时，在正文前部自然承载，再落申请事项。
- 由已给事实与常识直接支持的一般必要性、直接用途或非特指制度依据，可以低强度补足；不得新增具体故障、损失、业务后果、政策名称、条款编号、单位制度细节或审批结论。
- 完全无法闭合原因时，正文仍保留可写事项；输出允许正文外提示时，短列需补充的申请原因或用途。只交正文时不夹带缺口说明，不留占位符。
- 不把原因、依据、必要性机械要求扩散到事故通报、通知等其他文种。

## 固定测试

当前 `main@7143bd247be1997f3edff8c15870b64f9c241cd8` 为 baseline。候选只允许修改申请专叶；同三题、同五条低成本 provider、`max`、每臂每题一次、零质量重试。

1. `P1_PROCUREMENT_INFERABLE`：现有扫描仪在高峰期轮候共用，检查是否在采购事项前部形成与事实同层的必要性，不补采购程序、预算来源或完成效果。
2. `L1_ANNUAL_LEAVE_BASIS`：年休假没有个人私事原因，检查是否可用一般休假规定承载制度依据，不捏造单位制度名称、剩余假期或已获批准。
3. `L2_PERSONAL_LEAVE_MISSING_REASON`：事假事由完全缺失且允许正文外提示，检查是否不编家庭、疾病等原因，并明确提示补充事由。

## 采用标准

- 目标改善：候选在三题中稳定区分“事实可推”“一般制度依据”“完全缺失”，且采购、年休假不再成为无理由申请。
- 硬回退：遗漏用户给定数字、日期、申请事项、交接或未决状态；把申请写成已批准；捏造具体原因、政策条款、流程、责任或既成效果；正文交付被过程说明污染。
- 合理的一层目的、必要性、制度性依据、直接作用和正文自然增量不判为外扩。
- 只有目标改善且没有候选独有硬回退才补工程测试、镜像与规格；否则恢复产品字节并终止，不留 `HOLD`。

## 官方校准来源

- 大连理工大学资产与实验室管理处《关于填报2023年计划采购设备预算的通知》：要求采购前调研必要性，并分析现有设备功能、精度、使用负荷和支撑作用。
- 广东工业大学《教职工考勤管理办法》附件：请假申请表单列“请假事由”。
- 《企业职工带薪年休假实施办法》：规定职工年休假资格及单位结合工作情况统筹安排，单位规章高于法定标准时按相关规定执行。
