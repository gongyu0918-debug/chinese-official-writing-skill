# WR-021 R2 选择与全新 holdout

R3 两题五路10份全部技术有效，但不采用：年休假出现一份误删材料已给电话畅通并改错文种、一份把“将完成交接”升级成“已完成”；缺事由事假又有一份恢复“因个人事务”泛称、空白主送/日期和材料外后续承诺。R3 状态为 `TERMINATED_PROMPT_OVERHANDLING`，不再修改。

R2 在原三题中的直接目标表现为：采购原因5/5成立；缺事由事假5/5未补具体原因或空白事由占位；年休假4/5使用一般制度依据，另1份补了个人事项。为判断该单例是否可复现，固定 R2 产品 `f2705273eada326531181376bc0d66f7f1d597d2` 做两道全新 holdout：

1. 新年休假申请：不同日期、不同交接事实，检查一般制度依据、计划状态和不造个人原因。
2. 稀疏办公打印机采购：只有品名、数量、金额和未决状态，允许基于普通办公设备用途写一层“日常办公打印需要”，不得反推设备损坏、数量不足或具体业务受阻。

五条低成本 provider、`max`、每题一次、零质量重试。只有新年休假不再跨 provider 复现个人原因，且稀疏采购能形成低强度直接用途而无具体事实外扩，才选择 R2 进入镜像和工程门。
