# WR-021 R2 修订登记

R1 五路三题共15份候选稿全部技术有效。目标方向有改善，但不能直接合入：

- 采购申请5/5在事项前承载既有压力和必要性。
- 年休假一般制度依据由 baseline 的3/5前置变为4/5前置；另1稿把依据放在申请事项之后。
- 缺事由事假5/5不再用“因个人事务”等泛称或空白横线代填，但五路均把提示扩大到主送、日期等其他缺口；MiniMax另补通讯承诺、代办责任和流程建议。
- 部分稿把交接扩大为“确保不影响工作”，属于申请原因原子之外的无依据承诺，不因合理扩写放宽而接受。

R2 仍只改申请专叶，缩短并收紧三点：

1. 能闭合时只写一层低强度原因、必要性或一般制度依据。
2. 不能闭合时，文后只提示申请原因或用途这一项，不顺带清点主送、日期、附件、流程等其他缺口，不留占位。
3. 年休假一般依据放在申请事项之前；请假交接只写已给交接，不推成工作不受影响、保持通讯或代办责任。

R2 继续使用同三题、同五条 provider、`max`、每题一次、零质量重试。采用标准仍为目标改善且无候选独有事实、状态、指令或直接可用性硬回退。
