# R8 共性层内容归属审计（供 R10 精简使用）

审计结论：可以让所有稿件在主文种之后使用同一组较短的共性动作，复杂内容再按实际需要展开。主要减负空间来自重复规则、长例子和场景细节；不需要再设短稿入口、长稿入口、复读次数或新的例外清单。下表是审计归属，不建议作为一套新路由原样放进产品。

## 80 字下限与脚本语义

**普通短稿正文至少 80 字是用户本次新增要求，R8 没有该阈值。** 原型需把它落实为普通短稿的篇幅目标，并由独立字数脚本核对。正文不足时，可使用材料及常识支持的原因、用途和必要分析写完整；不得靠文后提示、重复状态、拆句复述或虚构业务内容补齐。若有效信息和合理分析仍不能达到下限，应如实区分“事实安全”和“篇幅未达标”，不能把较短正文报成合规。此处不另创计数口径，也不把标题片段或局部改词自行纳入“普通短稿”定义。

脚本页可以压缩，但应留下能够直接执行的调用语义：

- 脚本路径以本次实际读取的 `SKILL.md` 所在目录定位，草稿用带引号的绝对路径；文件或标准输入均可。
- `prose_lint.py` 按实际扫描对象选 `draft-body`、`gap-note-allowed` 或 `review-only`。审核收到的原稿仍是 `draft-body`；审稿意见本身才是 `review-only`。成稿扫描的 `--structure --format` 语义保留。
- 审核原稿保留原文件；要求改稿时修正已确认问题并交付新稿。最终发送采用已检查文本；修改后检查关联事实和状态并复扫变动文本，影响篇幅时另行复测。
- 合理用语或引用经人工核对可以保留，不能为清空脚本提示改坏正文；运行失败如实说明实际检查范围。

上述依据为 `prose-lint-usage.md:3,7-29`；本轮未读取或运行脚本，未验证具体字数计数算法。

## 可按实际条件展开的内容

条件控制的是细节或伴读，不取消上表中的共同动作。可沿用现有场景和格式页，不必为下列每项新建一页。

| 内容 | 何时才需展开 | 普通共性层保留什么 |
| --- | --- | --- |
| 月份与年份继承、合计差额、办理启动与结果的细例 | 材料确有不完整时间、总分数据或动作状态歧义 | 保留事实与状态不能互相代填的简短原则。`information-selection.md:15-17` 是实例化说明，不必每稿读长解释。 |
| 多轮讲话中原材料与模型现稿的特殊核对 | 同时有原始材料和讲话现稿，且需核对自述、经历或部署 | 通用底稿与无据内容边界已覆盖通常修改；第 29 行讲话例子可在对应任务展开。 |
| 跨段、跨表和附件关系，细字段及多主体责任 | 存在实际关联需要核对 | 基础数字金额和主文种要素仍每稿检查；详细对应项按材料展开。`final-review-layers.md:15,21`。 |
| 保密、内部数据、个人信息的接收范围处理 | 材料确实含有关信息或标识 | 保留条件本身即可，不把保密审查扩成所有稿件的额外步骤。`final-review-layers.md:9`。 |
| 成语、引语、术语、量词及语法细查 | 用户要求校对，或相关表达存在、需核准准确性 | 必经语言检查保留；数字和日期已在事实复核覆盖，不必仅因有数字就再读一整页重复清单。`proofreading-checklist.md:5-12`。 |
| 采购下游否定链、预算充分性自证、费用表述 | 稿件涉及相应采购、资金或成本表达 | 抗 AI 味共同检查保留“必要否定与无用重复、具体事实与空泛自证”的语义；第 10、11、25 行例子按场景使用。 |
| 高频句式长词表、宣传腔、句群节奏例子 | 语义检查发现相应成簇问题或判断拿不准 | 保留“按语境，不机械替换；删除旁白和无用重复”的短规则。`anti-ai-patterns.md:7,29-44,50` 的例子不必列成全部稿件的禁词库。 |
| 英文缩写、算力技术评价、DOCX 样式、网页复制噪点 | 真实包含相关内容或要求该交付格式 | 主体事实、必要术语和用户模板继续保留；格式及场景细节按既有页处理。`anti-ai-patterns.md:54-58`；`SKILL.md:49,73`。 |

## 重复归属

归属表示同一规则只保留一份完整说明，其他位置保留必要的执行连接；不要求维持五次串行读页。

| 重复主题 | 主归属 | 可缩短的重复位置 |
| --- | --- | --- |
| 材料事实、合理分析、状态、最新版底稿与实质缺项判断 | 信息选择的短核心 | 首页第 63-68 行保留必要入口或用户权限；终审只要求按该依据核对，不再次长列相同状态和推断边界。 |
| 主文种要素、模板与关联内容复核 | 最终复核 | 校对页第 5-7 行的数字、状态和格式重复可收回；文种页负责该文种是什么，复核负责对照落实，不再复制完整文种清单。 |
| 无用重复、旁白、教学腔及语境判断 | 抗 AI 味短核心 | 信息选择第 18、33 行、终审第 17 行、校对第 8 行不再各自展开同义重复规则；信息选择保留“不用无据内容凑篇幅”即可。 |
| 如何执行扫描、选择模式、复扫及解释告警 | 脚本使用 | 首页只保留必经调用连接；不要再复制一次命令表。扫描是动作，抗 AI 页负责语义判断，两者不能合并成“脚本通过即完成语言检查”。 |
| 文后提示的默认形态、内容清理、正文隔离和省略条件 | 交付 | 信息选择只识别缺项，终审只记录待处理问题，脚本页只说明失败或遗留项需记录；不在三处重写提示标题、位置和分类。 |
| 只审、审后改及范围 | 首页任务契约与交付的短连接 | 抗 AI 页第 17 行、校对第 13 行可引用本轮交付模式，避免各页分别决定是否改稿；脚本页仍需保留原稿扫描对象与意见扫描对象的区别。 |

“已经读过的规则直接应用”至多作为一次简短说明即可；不建议新增禁止复读清单、读页账本、强制回跳或长短稿门槛。是否需要合并承载页面由主任务原型决定，本审计不另设新层级。

## 审阅边界

仅阅读冻结 R8 的五个指定共性页，并加读 `SKILL.md`、`proofreading-checklist.md` 对照重复。未读取测试稿、其他文种页或脚本，未修改产品，未运行新模型或脚本测试。本报告是精简时的语义与归属依据，不是 R10 原型的验收结论。
