# OC-003-R2C “未形成决定”状态修正预登记

日期：2026-08-25。

显式激活控制的六个 A/B 臂均技术有效。Luna、Alibaba Candidate 只恢复或删除失实内容；Ollama Candidate 在最后一项先恢复“尚未形成采购决定”，又追加“尚不具备采购条件”。材料没有给“不具备采购条件”结论，该表述是 Candidate 独有的反向状态外推，触发预登记硬回退。

本轮不撤回整个状态分层候选，也不改起草侧三处 reference。只在 `genre-checklist-feasibility-review.md` 现有“恢复原状态或删除”句中补一个状态转换：材料只说未形成决定时，原样恢复，不改成“不具备/暂不具备条件”。不增加采购程序、统一事实门或篇幅门。

复用 R2B 同一显式激活反向审稿题，只跑 Luna、Ollama、Alibaba 三条 Candidate，共3次。三稿必须删除“已具备立即采购条件”并止于“尚未形成采购决定”等材料原状态，不得出现“不具备采购条件”“暂不具备采购条件”或另一套核查、审批、比选、上线、验收程序；任一硬回退则终止候选。
