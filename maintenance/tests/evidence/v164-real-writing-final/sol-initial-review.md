# v1.6.4 真实写作终审裁决

## 判定口径

本次仅按 `cases.json` 所列任务和 W1—W6 各稿自身表现判定，不与其他版本或基线比较。事实安全只看稿内事实是否有材料依据、未决状态是否保持原有强度；篇幅不足单独判定，不据此否定事实安全。篇幅按去除空白字符后的字符数粗略核计，是否明显达标不受常见计数口径差异影响。

PASS 表示该维度可直接接受；WARN 表示存在实质瑕疵，但单项尚不足以构成硬性否决；FAIL 表示违反明确要求或足以影响直接使用。

## W2 自然语言审稿

总裁决：WARN

| 维度 | 判定 | 具体理由 |
| --- | --- | --- |
| 事实边界 | PASS | 审稿意见围绕原段已有资金、采购状态和后续表述展开，没有加入具体人员、程序、期限、成效或新的采购事实。 |
| 未决状态 | WARN | 第2条保留了“供应商尚未确定”，没有把事项写成已完成；但在文种和办理目的不明的情况下，将合同未签、设备未到、验收未实施一概认定为“没有独立办理作用”并要求直接删除，判断过于绝对。这些状态虽可按常识视为下游事项，是否合并仍应取决于该稿是否需要完整交代当前进度。 |
| 文种/结构 | PASS | 按“位置—问题—建议”逐项给出意见，未替用户重写正文；增加风险层级不妨碍审阅。 |

| 保护性外扩/无依据具体化 | PASS | 没有为原稿补造证明材料或外围事实；对下游状态的关联属于常识判断，不构成材料外具体事实。 |
| 重复空话 | WARN | 三条意见均有具体落点，但“没有独立办理作用”“不要求用户补充材料”等方法性表述重复出现，略显机械。 |

事实安全是否通过：通过。稿件没有制造新事实，也没有把未决事项改写成完成事项；第2条的问题是删减判断过于绝对，属于审稿质量风险。

直接使用是否通过：不通过。第1、3条可直接采用，第2条应改为结合文种用途决定“保留、合并或压缩”，不宜在缺少语境时下“整条直接删除”的结论；同时宜减少规则化术语。

并入候选意见：修订第2条判断并自然化表达后可并入，当前稿不宜原样并入。

## 整体结论

本组稿件当前不适合整体并入候选。W1 达到事实、结构和直接使用要求，可原样并入；W2 未编造事实且遵守只审不改，但第2条删减结论过于绝对、表达偏规则化，修订后可并入；W3、W4、W5 的事实安全均通过，否决原因主要且明确地限于严重低于用户规定篇幅，其中 W5 另有段落偏碎的自然度问题；W6 除篇幅严重不足外，还把“拟”升级为“将”，并以重复性收束代替真实归纳，事实安全和直接使用均不通过。

因此，若以“原样可直接使用”为候选门槛，仅 W1 通过；W2 可修订后复审，W3—W6 均需重写或实质补强后再审。
