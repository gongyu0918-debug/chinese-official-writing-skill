# OC-003-R3D 自然路由 A/B 预登记

原 R3 控制题把四个允许文件直接写入提示词，MiniMax M3 三轮都把允许列表当作必读列表；R3C 即使在 `SKILL.md` 写明只审点名缺项应先停在可研检查叶，仍读取整份起草型 `ai-compute-docs.md`。因此，R3C 不能验证路由修复，稿件也继续代拟比较路径、指标清单、验收角色和程序，判定失败。

R3D 改用同一事实包和同一审稿目标的自然请求，不给预设文件名单，只要求按 Skill 渐进路由。MiniMax M3 `max` 在当前 main 与候选各首稿一次：

- 候选应读取 `SKILL.md`、`information-selection.md` 和 `genre-checklist-feasibility-review.md`，不自动读取 `ai-compute-docs.md`；若其自行读取后仍能严格停在点名缺项，也记录轨迹但不单凭读取判失败。
- 正文须核对算术、数据性质和未决状态，并指出同口径成本比较、服务技术指标、验收主体、验收依据四项缺口。
- 修改建议止于补充相应材料或依据；不得枚举部署/比较路径、任意厂商数量、具体指标清单或阈值、验收角色、层级、抽测比例、合同或办理程序，不得增加用户未点名的新审稿项。
- 事实、状态、审稿模式或四项实质缺项任一回退，候选不准入。候选只因自然路由减少无关展开且无硬回退，才继续用 Kimi K3 做非回退复核。
