# 术语自然度候选原子

本页只作为真实写稿候选，不是当前产品规则。每次实验只能启用一个小节。

## WR-019a 口径和测算追溯

“口径”不是禁词。统计、核算、测算、验收、审计等具体对象需要说明范围时，可保留“口径”，并尽量在近邻写明时间、范围、单位、分母、方法、纳入/排除项或依据中的至少一项。不同对象的必要使用不因裸词重复而合并。空泛的“统一口径”没有对象和边界时，按材料改成具体规则或动作；材料没有时不补造。材料已经给出单价、数量、公式或范围时，保留可追溯关系；是否表格化服从文种和用户要求。

## WR-019b 行业词的机制锚

`赋能、生态、底座、场景、抓手、矩阵、闭环、体系化` 等词不是禁词。词语指向具体主体、对象、动作、机制、节点、产物或指标时保留；例如“闭环”已经列出提交、受理、回传、评价等真实节点时，可以使用。多个抽象词成簇出现却没有信息增量时，删去或改为材料已有的具体工作，不补造责任、时限、指标或成效。

## WR-019c 必要英文术语和缩写

中文正式材料中的必要英文术语、产品名、型号和缩写保持官方拼写与大小写。首次出现是否采用“中文全称（英文全称，缩写）”“中文全称（缩写）”或中文简称，服从用户材料、现行规范和受众；材料已经给出准确形式时沿用。材料只给标准英文全称和缩写、且中文译名确定时，可补准确中文全称；内部代号或含义不明的缩写只保留原样，不自行展开或翻译。后文简称保持一致，不因降 AI 味删除 `AI、GPU、API、SLA、PUE、Token` 等必要术语，也不把 Token 改写为调用次数。`end-to-end、one-stop、quick win、best practice` 等英文口号不承担产品名、指标、型号或引用功能时，只按已给事实改成具体中文动作；材料没有对应事实时省略，不补造效果。

AI 算力与云服务材料只复用已经核准的少量常见映射：`图形处理器（Graphics Processing Unit，GPU）`、`应用编程接口（Application Programming Interface，API）`、`服务级别协议（Service Level Agreement，SLA）`、`数据中心电能利用效率（Power Usage Effectiveness，PUE）`。用户材料或任务适用标准采用其他正式译名时以其为准；不从这四项外推大词典。

## WR-019d 翻译腔句群

翻译腔按句群判断，不看孤立词。多个 `基于、面向、围绕、通过、对于` 框架或名词化动作连续出现，导致动作和对象难以辨认时，优先改成直接动词；只有材料已经明确或上下文能够无歧义继承主体时，才改为“谁做什么、作用于什么”。主体不明时保留无主表达或只调整动词，不得为消除翻译腔新增责任主体、实施主体或归属关系。单个介词框架、政策标题、法律定义和专业术语保持。修改只调整句法，不增删事实、状态、归属或结论强度。
