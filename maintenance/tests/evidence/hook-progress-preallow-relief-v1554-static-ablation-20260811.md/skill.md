# Skill Synthetic Outputs

### Skill-短文-通知-基础办理
现就报送范围、材料要求、完成时限和联系人等事项明确如下。主办部门按既定流程组织办理，明确材料清单、反馈时限和联系人。涉及资金、数据、期限和附件的，同步明确来源、范围、提交方式和后续管理要求。

### Skill-短文-通知-补充事项
现就报送范围、材料要求、完成时限和联系人等事项明确如下。对前期材料缺项和口径不一致的事项，由责任部门补齐依据并统一报送。涉及资金、数据、期限和附件的，同步明确来源、范围、提交方式和后续管理要求。

### Skill-中篇-通知-专项推进
现就报送范围、材料要求、完成时限和联系人等事项明确如下。专项工作实行节点管理，重要事项形成台账，完成情况纳入后续复核。涉及资金、数据、期限和附件的，同步明确来源、范围、提交方式和后续管理要求。

### Skill-中篇-通知-跨部门协同
现就报送范围、材料要求、完成时限和联系人等事项明确如下。涉及多部门配合的事项，由牵头部门统一协调接口、数据和反馈安排。涉及资金、数据、期限和附件的，同步明确来源、范围、提交方式和后续管理要求。

### Skill-长文-通知-年度安排
现就报送范围、材料要求、完成时限和联系人等事项明确如下。年度任务按照季度分解、过程跟踪和结果验收推进，确保责任落实到岗到项。涉及资金、数据、期限和附件的，同步明确来源、范围、提交方式和后续管理要求。
后续工作按照准备、实施、检查、整改四个环节推进。准备阶段完成资料核验和责任分工，实施阶段形成过程记录，检查阶段对照目标逐项复核，整改阶段明确时限和反馈要求。

### Skill-长文-通知-整改复核
现就报送范围、材料要求、完成时限和联系人等事项明确如下。整改事项逐项明确责任人、完成时限和复核方式，逾期未完成的及时说明原因。涉及资金、数据、期限和附件的，同步明确来源、范围、提交方式和后续管理要求。
后续工作按照准备、实施、检查、整改四个环节推进。准备阶段完成资料核验和责任分工，实施阶段形成过程记录，检查阶段对照目标逐项复核，整改阶段明确时限和反馈要求。

### Skill-中篇-通知-结果通报
