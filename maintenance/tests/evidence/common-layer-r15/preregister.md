# R15 共性伴读归并试验

来源：当前完整 2.0 开发候选，提交 `01c2a659`。前轮已有真实写稿支持共性统一与固定用语去重，仍存在旁白和无关伴读；不能据其通过把本轮撤页直接判为安全。

A 将办理要素内容归入既有共性复核段；B 将正式语言中需要保留的叙述身份及同义正式化归入既有抗 AI 味段；AB 同时应用。保留完整 Skill，不增加短长入口、审批条件、空壳转跳或新页。范围与功能对照见 [用途审计](owner-audit.md)；两项普通脚本保持不变。

## 原生写稿

- A：`formulaic_application_attachment` 与 `review_estimate_table`。前题沿用已能自然读到办理要素的申请和附件任务；后题检查实测/估算、分项金额、不同主体责任及未定期限的对应。
- B：`speech_control` 与 `plain_speech_style`。前题验证正常总结讲话，后题核对叙述身份、先后关系、判断程度、稳定性和成本两层意思。
- 两原子分别用 `alibaba-token-plan/qwen3.8-flash` medium、`command-code/deepseek-deepseek-v4.1-flash` provider-default，各8次调用。前者沿用已记录的 max/high 不收束后的强度；不为测试另做模型能力演示。
- 单独结果未见明确功能损失时，AB 用 `procurement_application_and_speech`，在五条现有通道各生成一对。Qwen 第一通道沿用 medium；Qwen 第二通道、MiniMax、GLM 优先 max；DeepSeek 使用默认。若环境拒绝或实际不收束，记录原失败并按实际情况降低强度，不把技术失败判成规则回退。

原生 Codex CLI 自主读取 Skill 和参考、保存并扫描草稿。请求不指定应读叶名、不预拼接全部规则。分别记录基线是否真的读到拟撤页面；未读到时，该题只证明自然选路和正文表现，不记为已经暴露的内容对照。多份稿件分别选主文种，必要共性可以复用。

## 判断与保留

独立匿名比较正文及完整交付，重点看主体、必要原因、数值口径、先后关系、强度、未定状态及附件对应；允许有材料支持的目的、影响和通常拟议动作。金额复算属于可直接核验的计算，普通草稿当天落款允许。80字与用户具体范围单独判断，不用一个字的边界代替写作质量。原始旁白、无关读取、缺项误报和失败全部保留。

文件变短只证明静态减载；实际读页、检查执行、token与耗时另报。若出现候选独有问题，核对被改语义与实际读取，必要时做同题双臂复跑或撤回对应原子；不以一次好稿覆盖差稿，也不把正常波动或过严裁判当成确定退步。

验证成功后才更新 canonical、镜像及相关维护映射并提交；保持 1.x 金线独立，2.0 不发布。本轮不等于完成全体文种和 Word 的最终验收。

## B 单项双臂复跑（首轮已保留，复跑前记录）

首轮 Qwen `speech_control` 候选补写了“从今天的交流情况看，有的问题来回确认了几轮”及具体会后整理安排，基线也有未给的会议时长、具体问题判断。为核对这种差异是否持续，以相同冻结 baseline/B、同提示及 medium 强度复跑 Qwen 双臂一次；首轮不替换。该复跑是归因诊断，不用新一次没出现问题证明纯模型波动，也不修改原裁判尺度。

## B2：调整归并后的表述范围（写稿前）

B 首轮正文候选1、基线2、相当1，区别包括一条轻微可能性强度变化及两侧的会议事实/责任扩写。Qwen 同题双臂复跑后，候选仍有主持结束动作、较具体的会后整理和文后状态解释，首轮不利表现不能一概归为偶发；这次复跑由主代理检查，未独立盲评，也不纳入首轮偏好计数。

原归并句从“口语或情绪化表达改为……”开头，容易把后面的保真要求理解为仅对去口语化动作适用。B2 把保真检查明确施于所有语言调整，并显式保留条件、可能性；口语正式化作为其中一个动作。共性段允许少量增字，以保住语义和可读性，撤页收益不靠压掉条件取得。该解释是待验证的机制假设，不是已证明首轮失败的因果。

只替换 anti-ai 的同一段，保留 B 的其余改动；另生成 AB2。仍用原 baseline，与 B2 重跑两题两通道8次。原 B 及复跑均保留。后续五通道组合使用通过判断的 B2 与 A，未通过前不纳入 canonical。

## 组合前规则冷审的可读性修正

独立规则审阅未发现 AB2 独有语义丢失或断链，指出复核句把关系、载体和字段挤在一个枚举中。接受其非阻断建议，将同一段改为关系核对与对应要素一致性两句，保留原有主体、结论、期限、指向、名称、数值、顺序、状态及实测/测算/估算。形成 AB3，原 A/B/AB/B2/AB2 均不覆盖。

这是现有内容的可读性修改，无新页面、检查项目或长短分流，单项语义证据沿用 A；最终五通道组合直接验证 AB3 的真实写作，准确记录它比原始 A+B2 多了这项文字整理。

Qwen 第一通道 medium、第二通道 max 的候选在 240 秒截止前已保存稿件并执行检查，但未返回最终消息，原调用记 timeout/missing_final，不能计成完成交付。第一通道在相同 medium 下成对延长至 420 秒；第二通道待原 max 双臂结束后改用 medium，成对采用 420 秒。原组与补测分包判读，保留全部失败与已生成草稿轨迹，不用补测覆盖原组，也不从超时直接推断规则导致正文退步。
