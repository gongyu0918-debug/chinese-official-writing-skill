# R15 组合问题的定向消融

R15 两次 MiniMax 组合候选均未执行字数/prose，并补出询价等具体经历；基线也有背景扩写和预算顺序矛盾。独立审阅没有证明组合整体更差，也没有证明这些问题只是波动。两页撤并仍未纳入 canonical。

本组只区分归并项：复用冻结 baseline，与原 A（办理要素归并）和 B2（正式语言归并）各做一对原生写稿，仍用原 `procurement_application_and_speech` 请求，MiniMax-M3、max、420秒。四次调用不改变材料、模型路由或裁判尺度，不覆写原组合及复跑。A 保留初始复核句，AB3 的等义分句差异单列，不能据此声称所有文字因素都已完全隔离。

检查实际是否读取对应旧页、是否调用检查、两稿主体、价格来源、金额、未定状态与办理先后。先判断正文与整条交付，再结合读页解释；即使某次没有再出问题，也不能据此断言纯随机性。本组不以单项结果替代后续完整候选的组合验收，不再扩大同题重复采样。
