## 旧整包失败的正确拆法

- 13 个 Markdown 广泛清晰化失败，只证明多职责同时重排不安全，不证明 13 个文件逐句不可动。
- Request 叶 MIXED 不冻结整叶；后续物理拆叶已真实通过，单个数字空格和“为”字负项属于局部噪声。
- Workflow 密度回退不冻结全部 workflow；事实源回指是承重项，方案顺序、段落链条和路由速查仍可分别研究。
- 风险短稿失败只否定“再堆一组风险场景规则”，其来源边界、对象状态和行动链外扩要按不同机制拆分。

## 新增规则实验

已完成的第一项新增规则实验是轻量卡“状态谓词沿用材料原词”。Candidate 在冻结的“接口恢复”和“下次会议时间未定”两题仍分别写成“恢复正常”“另行确定”，且出现正文外说明；产品已撤回。结果证明同义提醒前移并不能稳定解决该问题。

当前第二项独立新增实验改测论证链资格，不复用失败句。通过条件仍是：至少两家 provider 出现可归因净改善，完整通知和建设方案控制无欠写；否则撤回。

所有候选继续遵守：独立 worktree、先预注册、单一变量、首个最终正文、硬边界先判、与 DIFF 无关的 B 项波动只记噪声、失败完整撤回。
