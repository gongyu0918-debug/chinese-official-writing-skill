# WR-029 R4：不采纳整页替换

原四题、两模型8次独立调用全部完成且技术有效；[真实稿与隔离回执](actual/summary.json)。返回 R2 加一个可用分析示例，并修入口个人视角及领导交流边界。模型会借用示例中的认识表达，但仍不能稳定保持事实状态。

MiniMax窗口稿不再加记录数量和起始时间，仍加等候场景、对话及心理转变；青年稿新增“开会前半小时”追问；身份稿仍把办事人称同事，还新增过去凭印象答错、事后更正的本人工作过失，不能淡化为修辞。领导稿把内部试用放在汇总审定前，并新增下次例会听进度；这改变了执行过程。千问领导稿三任务较清楚，身份稿不再扩张正式部署，但窗口稿把预期记录价值写成已有成效、身份稿补下班后翻记录。

独立审阅同意 R3/R4 未形成替代 R2 的整体收益，建议保留 R2 有限首稿收益，将身份改稿交回原通用路径。审阅当时已读 R4 七稿，最后的千问身份稿由根代理补读；不称八稿全由子代理盲审。

本轮不采用新增示例或整页替换，保留已证实的入口视角冲突修正。身份边界 A/B 单独保留在[boundary-r4](../speech-role-boundary-r4/preregister.md)。下一步是收窄覆盖范围的[R5](../speech-role-leaf-r5/preregister.md)，不择优拼接各轮好稿，不据重复抽样宣称错误率下降。
