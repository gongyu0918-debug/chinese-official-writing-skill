# R3 SOL 盲审分批修订

日期：2026-08-17

原冻结匿名包共 13 组。首次单次 SOL max 审阅运行约 522 秒后返回平台错误，未生成 verdict 或 receipt；该调用记为无效，不得补写结果或计入准入。

为降低单次上下文和输出负荷，在不读取 restricted mapping、不改稿件、不改评分口径的前提下，将同一冻结匿名包按原顺序机械拆为两份：

- A：`G01,G03,G04,G06,G07,G08,G09`；
- B：`G10,G11,G12,G13,G14,G15`。

两份各调用一次同一 `gpt-5.6-sol`、`max`、1200 秒、0 retry。仅当两份均返回一个通过 schema 和输入哈希校验的结果时，才按原组顺序合并；任一份失败则 R3 质量审阅仍为无效，不再追加第三次审阅。

本修订只改变裁判包的运输大小，不改变候选、基线、匿名映射、评分维度或准入条件。
