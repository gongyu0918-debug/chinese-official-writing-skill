# 事务文体功能与结构

本页是计划、汇报、调查报告、讲话稿、演讲词、答复、责任书、公开信、倡议书、建议信、新闻发布稿、总结、情况反映、情况综合、编者按、新闻、短评、讲解稿、宣传手册和宣传材料的默认写作参考。它只提供文种功能、结构选择和事实边界，不提供统一措辞模板。

只有用户明确询问或要求选择公文开端、引叙、承启、综合、期请或结尾用语时，才继续读取 `formulaic-phrases.md`。普通起草、改写、压缩和复核不读取该页。

## 基本原则

- 用户给定的标题、提纲、段落顺序、单段写法、语气和结尾优先。
- 先完成文种应承担的办理功能，再按材料自身的时间、事项、主体、问题或受众关系组织正文。
- 信息较少时紧凑成段；信息较多时才按真实层次设标题。不得为了显得正式而补统一总起段、总结段或尾句。
- 用语和结构只能组织已给事实。没有来文，不写收悉；没有批准或研究事实，不补批准、研究动作；没有请批事项，不补请批语。
- 材料只给月份、月日或时间段时，不补年份；材料只给调整事实时，不补具体调整内容、适用场景、便利或成效。
- 一篇稿只保留一个有效收束。事项已经自然结束时不另加；用户指定尾语时逐字保留。
- 明确篇幅范围仍须遵守，但只能通过分类、时间进程、主体关系和已给事实之间的联系展开，不能补主体、程序、承诺、结果、评价或充分性自证。

## 文体功能和结构轴

| 文体 | 必须完成的功能 | 可按材料选择的结构轴与边界 |
| --- | --- | --- |
| 计划 | 交代执行期、任务、主体和已给节点 | 按时间、任务或责任组织；不补考核、奖惩和量化成效 |
| 汇报 | 报告事实、进展、问题和已给下一步 | 按事项、阶段或问题组织；不得夹带请批事项 |
| 调查报告 | 交代调查范围、数据、发现和已有处置 | 按对象与方法、发现、处置组织；无分析依据时不补原因结论 |
| 讲话稿 | 体现称谓、场合身份、事实基础、要求或期望 | 结构服从讲话对象和目的；期望只落在材料允许范围 |
| 演讲词 | 体现演讲人身份、主题、事实和观点 | 可按经历、主题、观点组织；一般延续由演讲主体承担 |
| 答复 | 承接意见、建议或询问，说明现状和答复事项 | 先回应核心问题，再给事实和已有安排；没有来文事实不写收悉 |
| 责任书 | 明确各方责任、共同事项和材料已给要求 | 按主体或工作环节组织；不补经协商一致、签订过程、奖惩或追责 |
| 公开信 | 面向明确对象说明背景、事项和配合要求 | 按受众关切和行动事项组织；不补材料外倡议 |
| 倡议书 | 说明缘由，提出具体可执行的倡议 | 按缘由和行动事项组织；不扩成处罚、检查或评比制度 |
| 建议信 | 以事实和问题为依据提出具体建议 | 按问题、依据、建议组织；建议不升级成决定或命令 |
| 新闻发布稿 | 发布核心事实、处置进展、当前状态和已给渠道 | 先写最重要事实，再按时间进程展开；不补原因、恢复时间和结果 |
| 总结 | 回顾周期事实、工作、在办事项和已给下一步 | 按业务板块、时间或问题组织；总结段不得新增成效和计划 |
| 情况反映 | 说明对象、时间、数据、问题表现和当前处置 | 按事实、问题、处置组织；无依据时不补评价和原因 |
| 情况综合 | 综合来源、分类、共性差异和当前研究状态 | 按分类和差异组织；未形成决定时保持原状态 |
| 编者按 | 显示编者身份，说明编发对象、目的和下文内容 | 保留“编者按”或用户模板中的同类标识 |
| 新闻 | 用标题、导语和主体报道已发生事实及当前进展 | 按新闻价值和时间进程组织；进行态须有可继承责任主体 |
| 短评 | 以事实为前提提出中心判断并展开论点 | 事实与评论推演分开；论点充分后自然结束 |
| 讲解稿 | 面向受众说明对象、顺序和已给信息 | 可按空间、路线或主题组织；互动和问答须有材料依据 |
| 宣传手册 | 便于查阅地说明已给要求、方法和渠道 | 分项标题服务查阅；不补处罚、监督和其他责任 |
| 宣传材料 | 说明宣传对象、事项、时间地点、参与方式和边界 | 按受众行动路径组织；不扩展服务范围和适用对象 |

## 交付检查

- 文种功能是否成立，用户结构是否逐项保留。
- 标题和段落是否来自本题信息层次，而非通用骨架。
- 开头、承接和结尾是否各有实际作用，同一功能是否重复。
- 是否为了满足篇幅或显得完整，补出材料没有的评价、口号、保证、后续行动或自证。
