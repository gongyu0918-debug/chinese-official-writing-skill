# R4 普通任务不加载常用语总页预注册

日期：2026-08-17

固定基线：`v1.6.6^{commit}=b49da7f2a5a8ac2327252d29efd66f1d54ccbc35`。R1—R3 结果保持不变；本轮不修改 canonical。

## 假设

R3 表明，即使删除固定用语词表，只要默认上下文仍出现20类文体结构总表，模型仍会逐项补齐、同义复述或新增职责。R4 不再提供新的默认结构页：

1. 普通任务沿用当前 SKILL 的事实边界、信息选择和实际命中的既有文种叶，不读取 `formulaic-language.md`；
2. 用户明确要求选择、核对或解释开端、引叙、承启、综合、期请或结尾用语时，才读取精简后的 `formulaic-language.md`；
3. 不增加反套话 prompt，不创建20个新叶，不在原型阶段修改镜像或 Hook。

## 真实写稿

- 9题×A/B，共18次调用；三家 provider 各3题。
- 模型固定为 `opencode-go/deepseek-v4-flash`、`ollama-cloud/deepseek-v4-flash:0731`、`alibaba-token-plan-2/deepseek-v4-flash-0731`，全部 max、1200秒、0 retry、每臂隔离。
- 普通题覆盖总结、用户指定结构、责任书、情况反映、宣传手册和宣传材料；显式用语题覆盖通知、报告、复函。
- 候选普通臂读取用语页或显式用语臂未读取，均记技术无效。任一 provider 少于2个完整对时只作诊断，不补样本。

## 准入

- 候选事实、状态、用户结构和文种功能不得出现独有 FAIL；
- 候选机械化 FAIL 不多于基线，且不得以明显篇幅不足换取表面简洁；
- 至少2组因减少无功能的固定开合、结构复述或同义填充而获胜；
- 总体胜负只作观察。通过后才修改 canonical 路由和查询页；失败则只记录证据。
