# 文种功能与行文衔接（研究原型）

本页先帮助完成文种功能和整体结构，再按实际需要选择少量行文用语。用语不是模板槽位，也不用于把不同材料整理成同一种文章。

## 优先顺序

1. 用户给定的标题、段落、提纲、语气、模板和结尾优先；合法结构不得因通用范例被改写。
2. 先完成文种必须承担的办理功能，再按材料的事实关系组织段落。
3. 只有缺少自然衔接时才选择惯用语。正文已能顺畅起承转合时，不为“更像公文”补固定开头、总结句或尾语。
4. 同一功能只表达一次。不要把“现将……如下”“为此”“综上所述”“特此……”串成通用闭环，也不要让不同稿件共享同一组一级标题。

单个正式连接词不是机械化。判断重点是它是否承担本句功能，以及整篇是否出现没有信息贡献的套话簇。

## 20类事务文体

| 文体 | 必须完成的功能 | 常见结构选择 |
| --- | --- | --- |
| 计划 | 交代执行期、任务、主体和已给节点 | 可按时间、任务或责任展开；任务列完即可结束 |
| 汇报 | 报告事实、进展、问题和已给下一步 | 可按事项、阶段或问题展开；不补请批功能 |
| 调查报告 | 交代调查范围、数据、发现和已有处置 | 调查对象与方法、发现、分析或处置按材料取舍 |
| 讲话稿 | 体现称谓、场合身份、事实基础、要求或期望 | 围绕讲话目的自然分段，不强制编号或总结段 |
| 演讲词 | 体现演讲人身份、主题、事实、观点和号召 | 以现场交流逻辑展开，可用自然致谢收束 |
| 答复 | 承接意见、建议或询问，说明现状和答复事项 | 先回应核心关切，再说明事实和安排 |
| 责任书 | 明确各方责任、共同事项和材料已给要求 | 按责任主体或工作环节组织，不补协商、签订、奖惩和追责过程 |
| 公开信 | 面向明确对象说明背景、事项和配合要求 | 保留称谓，以受众易读的顺序组织，可自然呼吁 |
| 倡议书 | 说明缘由，提出具体可执行的倡议 | 以行动事项为主体，不扩成处罚或检查制度 |
| 建议信 | 以事实和问题为依据提出具体建议 | 问题、依据和建议按需要组合，不要求固定三段式 |
| 新闻发布稿 | 发布核心事实、处置进展、当前状态和已给渠道 | 重要事实前置，背景和措施按新闻价值排序 |
| 总结 | 回顾周期事实、工作、问题和已给下一步 | 可按业务板块、时间或问题组织；有实际归纳才另写总结段 |
| 情况反映 | 说明对象、时间、数据、问题表现和当前处置 | 事实与问题前置，处置只写已给内容 |
| 情况综合 | 综合来源、分类、共性差异和当前研究状态 | 以分类和差异组织，不把未决事项写成决定 |
| 编者按 | 显示编者身份，说明编发对象、目的和下文内容 | 使用明确编者按标识，篇幅服从编发功能 |
| 新闻 | 用标题、导语和主体报道已发生事实及当前进展 | 按新闻价值而非公文条款排序，不套通知或报告尾语 |
| 短评 | 以事实为前提提出中心判断并展开论点 | 事实、观点和论证清楚后自然结束 |
| 讲解稿 | 面向受众说明对象、顺序和已给信息 | 按参观、空间或主题顺序组织，称谓和互动按场景使用 |
| 宣传手册 | 用标题和分项内容说明已给要求、方法和渠道 | 以查阅效率安排分项，不添加空泛前言和总结 |
| 宣传材料 | 说明宣传对象、事项、时间地点、参与方式和边界 | 以受众行动路径组织，号召不超出材料授权 |

## 需要正式办理标识时

- 来文确实存在时，复函、批复可用“收悉”等引叙语；标题、文号、日期和来文主体必须来自材料。
- 正式请示应有明确请批事项，并使用与请批关系相称的结尾；用户指定“妥否，请批示”等写法时保留。
- 正式通知、通告、公告、报告、批复或函确需标识文种收束时，可使用相应尾语；正文已经自然结束时不重复收束。
- 编者按应有“编者按”或用户模板中的同类标识。

## 避免同质化

- 不为了覆盖范例而补“现将……如下”；开头可以直接交代事实、背景、目的或来文关系。
- 不把“为此、据此、综上所述、总之”当作段落标配。前后逻辑已经清楚时直接进入下文。
- 不从文种表复制统一标题。标题层级和段落数量由信息量、用户模板和阅读需要决定。
- 短稿优先紧凑成段；长稿才按真实信息层次设标题。不得把短稿拉成“背景—做法—成效—下一步”的固定骨架。
- 保持文种功能不等于统一语气。讲话、公开信、新闻、短评和讲解稿应保留各自受众关系和自然节奏。

## 事实边界

用语只能组织已给事实。没有来文，不写“收悉”；没有批准事实，不写“经批准”；没有研究动作，不写“经研究”；没有结论或成效，不借总结段补造。相对时间、主体、数字、状态和用户明示结构按原材料保留。

## 复核

- 用户给定结构、顺序、单段要求和明确结尾是否原样保留。
- 每个开头、承启、总结和尾语是否有实际功能；删去后若信息与办理关系不受损，则可省略。
- 文种功能是否成立，是否误套另一文种的语气或结尾。
- 跨稿比较时是否反复出现同一开头链、一级标题组或收束链；单个合用词不单独判错。
