# 官方协议与问题记录

本轮读取时间：2026-09-05。固定原始响应、仓库树和源码摘录在 `research/`；不是依赖搜索摘要猜字段。

- **CodeBuddy**：[官方 Hooks](https://www.codebuddy.ai/docs/cli/hooks) 的 Stop 表明确 `continue:false` 与 exit2 用于阻止停止、要求继续。prompt Hook 的 `continueOnBlock` / `impossible` 是另一种 Hook 类型，不能移植为 command stdout 的独立终止字段。本机 npm cache 内已下载的官方 2.141.0 包元数据将问题入口指向 [官方 CNB issues](https://cnb.cool/codebuddy/codebuddy-code/-/issues)，未找到可替代的官方 GitHub issue 仓库，未把第三方同名仓当官方。已读本地编译包 command/prompt 处理摘录和 SHA-256；`preventContinuation` 位于 prompt 分支，command 分支未提供已核实的对应返回接口。
- **Kimi**：[当前官方 Hooks](https://www.kimi.com/code/docs/en/kimi-code-cli/customization/hooks.html)，官方源码固定 `MoonshotAI/kimi-code@f9ca33376604ae91ea35a4ac1d6f1d4425a5aead`。`packages/agent-core-v2/src/features/externalHooks/internal/runHook.ts` 只归一化 allow/block，`agent/agentExternalHooksService.ts` 的 Stop 消费 block reason 来附加用户消息并续写；没有独立硬停。官方问题 [#1905](https://github.com/MoonshotAI/kimi-code/issues/1905)、[#2455](https://github.com/MoonshotAI/kimi-code/issues/2455)、[#2766](https://github.com/MoonshotAI/kimi-code/issues/2766) 分别讨论 fail-closed、输出通道差异和静默失败，均不能代替当前能力。查询结果 `kimi-issues.json` 保留。
- **OpenCode**：官方源码固定 `anomalyco/opencode@e2894562f8ba943d72172d10b727c24d5f650c16`。`packages/sdk/js/src/gen/sdk.gen.ts:551` 提供 `session.abort`，`:1118` 提供 TUI `showToast`，本仓当前 plugin client 使用这个 v1 SDK。官方 [#29894](https://github.com/anomalyco/opencode/issues/29894) 是已关闭的历史实例绑定问题，不能据它声称当前 abort 仍有该 bug；当前 plugin factory 已优先采用 serverUrl。本项没有调用 abort，因为触发点已经是 idle，且异步取消不能用于中断后来开始的用户请求。官方问题查询与两个 SDK 版本源码均保存。
- **DeepSeek Harness**：官方仓库 `deepseek-ai/deepseek-harness@d347e703908d0406b7a7ef80e3a0e594d86b2215`，API 元数据 `has_issues:false`，故检查官方 Discussions。[取消 API 说明](https://github.com/deepseek-ai/deepseek-harness/blob/d347e703908d0406b7a7ef80e3a0e594d86b2215/.agents/notes/implemented/simplification/2026-06-20-public-agent-stop-api.md)、[当前 Agent 类型](https://github.com/deepseek-ai/deepseek-harness/blob/d347e703908d0406b7a7ef80e3a0e594d86b2215/packages/core/session/src/types.ts) 与本机 0.1.1-rc.2 都支持 `{kind:'hook',reason}`；实际 installed AgentLoop 在 turn-stopping 后检查 signal。官方 [取消测试](https://github.com/deepseek-ai/deepseek-harness/blob/d347e703908d0406b7a7ef80e3a0e594d86b2215/packages/core/agent-loop/tests/cancel.spec.ts) 为本次小驱动提供初始化与 MockAdapter 复用依据。官方讨论 [#465](https://github.com/deepseek-ai/deepseek-harness/discussions/465)、[#4832](https://github.com/deepseek-ai/deepseek-harness/discussions/4832) 区分取消和排队消息保留，促使本项使用 `keepInbox:true` 并直接验证。旧 Claude bridge 的 false 不硬停限制与原生 adapter 分开。
