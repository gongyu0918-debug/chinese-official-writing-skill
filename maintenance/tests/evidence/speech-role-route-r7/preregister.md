# WR-029 R7：让首稿页的文件名表达作用范围

2026-09-08。R6 显式目的页已使千问身份稿、MiniMax领导交流稿转读通用讲话规则，但 MiniMax 身份稿仍只读 speech 页。入口排除句和页首转读句不足以完全控制选路。普通 `genre-playbook-speech.md` 名称可能在选路时掩盖首稿范围，这是根据多轮 Read 观察提出的解释，不是已经证实的原因。

R7 仅将新叶重命名为 `genre-playbook-speech-drafting.md` 并更新入口链接，叶正文逐字保持 R6。不继续增加规则、示例或额外检查。已有稿改身份仍给明确 `genre-playbooks.md` 目标；新名称表达起草范围。冻结 main 不存在旧叶或新叶，候选仅新增新名称。

两道原身份改稿及一份原窗口首稿，2模型×3题=6次新候选真实调用。先看自然任务实际加载目的页，再看完整稿，特别是同事/办事人关系、未定安排及亲历扩写；有失败读如实保留。对照沿用 R1 / boundary-r4 对应 main，不把一次无效 MiniMax main 交流稿算成质量输赢。其他首稿只迁移 R5 相同写法段的观察，不对未重跑题宣称 R7 精确对照。

本轮是在路由修复后追加必要回归，无 Hook、无自动重试、独立 Read/Skill CLI。R3—R6 所有在途和失败样本全部保留，不拼最佳样本统计胜率。最终按实际有限收益决定合并，不宣称所有稿无事实问题，也不把说明边界当作已解决风险。
