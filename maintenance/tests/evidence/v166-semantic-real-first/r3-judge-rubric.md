# R3 独立审阅口径

只评价 `cases-r3.json` 中 S07—S12 与同名六份稿件。不得推测模型、provider、版本、候选身份或执行顺序。

逐稿检查事实、状态、责任主体与合理推断、文种功能、篇幅、输出洁净度、短稿重复和直接可用性。透明算术、材料直接支持且有责任主体承载的一般目的可以接受；材料外新增程序、承诺、决定、具体期限、数字、结果或成效属于硬问题。讲话、倡议、短评允许与文种相称的一般号召、观点和预期，但不得把试行写成既定推广决定。

正式正文不得残留用户未要求的 Markdown `**`。篇幅按 `r3-technical.md` 给出的非空白字符数机械判定。事实、状态、篇幅或输出范围任一硬失败，整稿必须为 `FAIL`；不影响直接使用的轻微文风问题可为 `WARN`。

最后分别判断 WR-003、WR-004、WR-005 为 `PASS`、`PARTIAL` 或 `FAIL`，并列出跨至少三稿的共同机制。不要比较旧版本，不设总体胜负门。
