## 独立裁决与人工校准

独立 `gpt-5.6-sol` max 只读取冻结 packet 和 template，六项 JSON 完整，模型与哈希闭合。裁判原始判定完整保存在 `sol-verdict.json`，SHA-256 为 `c4f2f011dd14346f9991f5e15a99326b98325ec8dc8bdde2706ed551e9bc4d07`，没有按人工意见覆写。

唯一实质分歧为 S04。裁判把“检查用电设备，确认关闭后再离开”认定为材料外责任。结合题面已明确的“离开教室时关闭照明和空调”，以及高校公开安全规范中“最后一人离开时检查并关闭水、电、气、门、窗”的稳定用法，该句属于有材料近邻和责任主体承载的自然展开，不按事实外扩处理。参考：[浙江海洋大学实验室安全十条准则](https://sbc.zjou.edu.cn/info/1112/5607.htm)、[大连理工大学生物工程学院实验室安全管理指导细则](https://biotech.dlut.edu.cn/info/1052/2561.htm)。

S06 的标识问题成立。最高人民法院、最高人民检察院、中央纪委国家监委及高校公开案例均以“编者按：”或同类显式标识引出编者说明，说明该标识承担文种识别功能，而不是可随意省略的装饰。参考：[最高人民法院知识产权法庭案例](https://ipc.court.gov.cn/zh-cn/news/view-2831.html)、[最高人民检察院理论研究](https://www.spp.gov.cn/llyj/202302/t20230204_599932.shtml)、[中国农业大学志愿服务专题](https://news.cau.edu.cn/zhxwnew/547871.htm)。

## 机制归因

- WR-003 为 `PARTIAL`：六稿均能给动作或预期安排责任主体，但有主体不等于有材料依据；S03、S05 仍分别补造程序和反馈承诺。
- WR-004 尚未建立：六种文体中五种基本功能成立，编者按标识缺失；约20类事务文体仍未覆盖。
- WR-005 尚未建立：S02 篇幅不足，S01、S04 有短稿同义收尾；本轮没有出现覆盖至少三稿、至少两个 provider 的同一清晰重复机制。

S03、S05 的材料外扩写只有两稿；S01、S04 的明确短稿重复也只有两稿。它们都未达到预注册的“三稿、两个 provider”产品语义原子门槛，因此本轮不修改 canonical Skill、reference 或胶水。
