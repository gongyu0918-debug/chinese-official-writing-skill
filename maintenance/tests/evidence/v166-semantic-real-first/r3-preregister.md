# WR-003/004/005 第二批真实写稿预注册

## 目的

在首批计划、调查报告、责任书、公开信、答复、编者按之后，继续覆盖工作汇报、讲话稿、倡议书、新闻发布稿、短评、情况综合。仍先看真实成稿，不修改产品或胶水。

## 固定输入

- 沿用 `preregister.md` 固定的 v1.6.5 产品 tree、`formulaic-language.md` 原型及 `prototype-system-prompt.txt`，不追加临时规则。
- 题面、provider 和精确模型见 `cases-r3.json`。
- OpenCode Go、Ollama Cloud、Alibaba Token Plan 2 各两题；三 provider 可并行，provider 内严格串行。
- 每题独立 HOME、配置和临时目录，max，1200秒，0 retry，只取首个完整终稿；普通 Skill 路径，无 Hook、无 web search。

## 判定

沿用首批五项功能判定。重点复核：

1. 一般目的和合理预期是否有材料或责任主体承载；
2. 是否擅自补具体程序、承诺、决定、结果、期限或数字；
3. 文种功能标识、行文关系和必要结构是否完整；
4. 短稿是否出现同义收尾、同一主旨重复或正文外旁白；
5. 篇幅和事实状态是否满足题面。

合并首批与本批观察后，同一机制至少出现在3份真实稿、覆盖2个 provider，才进入产品语义原子；单一文种的专属功能缺口只进入该文种叶候选。本轮仍不以旧版本总体胜负作为功能门。
