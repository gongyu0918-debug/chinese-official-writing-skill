# WR-003/004/005 六稿独立审阅包

你只评价下列六份稿件。不得推测模型、provider、版本、候选身份或执行顺序。

## 判定口径

逐稿检查：事实与状态、责任主体与合理推断、文种功能、结构、篇幅、短稿重复和直接可用性。透明算术、由材料直接支持且不新增具体程序或结果的一般目的可以接受；材料外新增主体、程序、期限、数字、决定、反馈承诺、结果或成效属于硬问题。不要机械要求固定开端或尾语，但文种必需的功能标识和行文关系应完整。篇幅按给出的非空白字符数机械判定。

每稿给 `PASS`、`WARN` 或 `FAIL`：事实、状态、篇幅或输出范围硬失败时必须 `FAIL`；不妨碍直接使用的轻微文风问题可 `WARN`。最后归纳是否出现覆盖至少三稿、至少两个模型来源的共同机制问题，但不要比较旧版本，也不要把总体胜负设为功能门。

## S01

### 任务

请根据材料起草《市公共文化中心第四季度读者服务计划》，包括标题和正文，300—380字，只输出可直接使用的完整文本。材料：执行期为10月至12月；读者服务部每周编排开放服务人员；数字服务组每周检查数字阅读区设备并登记故障；志愿服务队在10月、11月各组织1次服务培训；综合办公室每月底汇总开放服务、设备故障和培训记录。不得补预算、合作单位、考核奖惩、量化成效或材料外期限。

### 稿件

市公共文化中心第四季度读者服务计划

本计划执行期为10月至12月。为做好第四季度读者服务工作，现将有关工作安排明确如下。

一、开放服务人员编排。读者服务部每周编排开放服务人员，保障读者服务正常有序开展。

二、数字阅读设备检查。数字服务组每周检查数字阅读区设备并登记故障，及时掌握设备运行情况，确保数字阅读服务正常有序开展。

三、志愿服务培训。志愿服务队在10月、11月分别组织1次服务培训，提升志愿者服务能力，促进志愿服务有序开展。

四、记录汇总。综合办公室于每月底汇总开放服务、设备故障和培训记录，全面掌握各项工作的执行情况。

各有关部门要按照本计划的安排，认真组织实施，确保第四季度读者服务各项工作任务落到实处。

### 稿件

为规范档案数字化工作，明确综合档案室与信息中心在档案数字化工作中的责任分工，加强协作配合，确保按期完成工作任务，经双方协商一致，签订本责任书。现就有关事项约定如下：

二、信息中心责任

（一）负责扫描、图像整理和目录著录。

三、双方共同责任
双方共同承担以下责任：
（一）共同建立每周工作台账。
（二）发现档案缺页、图像不清或目录信息不一致时，当日登记并相互告知。

四、保密要求
双方在档案数字化工作中严格遵守现有保密规定。

### 稿件

致全校师生的节约用电公开信

全校师生员工：

为做好节约用电工作，减少电力浪费，现将近期夜间巡查情况和有关要求告知如下，请广大师生知悉。

8月1日至7日夜间巡查发现，3栋教学楼在22时后仍有部分照明和空调运行，存在用电浪费现象，应引起广大师生重视。为加强用电管理，后勤管理处自8月19日起每周开展1次夜间巡查，对夜间用电情况进行检查，请广大师生予以配合。

节约用电是全体师生共同的责任，需要大家共同参与。请大家自觉遵守上述要求，共同营造节约用电的良好校园氛围。

### 稿件

关于延长图书馆周末开放时间建议的答复

你提出的关于延长图书馆周末开放时间的建议收悉。感谢你对图书馆工作的关心和支持。现就有关情况答复如下：

目前，图书馆周六、周日的开放时间为9时至17时。为更好满足读者周末的阅读和学习需求，图书馆决定自9月1日至10月31日试行延长周末开放时间，为期两个月。试行期内，每周六、周日的开放时间调整为9时至19时，每天延长开放2小时。试行期间，读者服务部负责轮班安排，保障延长开放时段内各项服务正常有序开展。

试行结束后，图书馆将根据试行期间的入馆记录和读者反馈，对后续开放安排进行综合评估，评估情况将向读者反馈。试行期间读者提出的意见建议，一并作为评估参考。衷心感谢你的建议，欢迎继续对图书馆工作提出宝贵意见。
