# WR-003/004/005 第三批真实写稿预注册

## 目的

补齐约20类事务文体中的演讲词、建议信、总结、情况反映、新闻、讲解稿、宣传手册和宣传材料。与前两批合计20类，仍先看真实成稿，不修改产品或胶水。

## 固定输入与执行

- 沿用 v1.6.5 产品 tree、研究 `formulaic-language.md` 和未改变的 `prototype-system-prompt.txt`。
- 题面、provider 和模型见 `cases-r4.json`。
- OpenCode Go 运行 S13—S15，Ollama Cloud 运行 S16—S18，Alibaba Token Plan 2 运行 S19—S20。三家并行，单家内部串行。
- 每题独立 HOME、配置和临时目录；max、1200秒、0 retry，只取首个完整终稿；普通 Skill 路径，无 Hook、无 web search。

## 判定

沿用前两批事实、状态、责任主体、文种功能、篇幅、自然度和输出洁净度判定。特别检查：

- 演讲、宣传和倡议允许有文种所需的一般号召，但不得补具体成效、安排或承诺；
- 总结和情况类材料保留在办状态，不以连续否定或保护性论辩凑完整；
- 新闻中的意见卡以“工作人员正在汇总”承载进行态，不补统计结果；
- 讲解稿只组织已给展项，不补历史故事和价值结论；
- 用户未要求 Markdown 时不得残留 `**`。

满20类后按功能验收：WR-003 看合理推断是否有责任主体承载，WR-004 看文种功能是否成立；不与旧版本做总体胜负。WR-005 的篇幅、重复和洁净输出另按累计真实失败归因。
