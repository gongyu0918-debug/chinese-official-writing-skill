## 十二稿累计观察

- 显式篇幅失败 6/12：S02、S07、S09、S10、S11、S12，覆盖三家 provider；这已经是稳定机制，不是单稿波动。
- Markdown 标题残留 3/12：S10、S11、S12，覆盖两家 provider。当前 SKILL 已明确禁止，说明简单重复禁令不足；启用交付洁净度 Hook 时应由该能力兜底，普通无 Hook 路径仍需保持直接闭环。
- 责任主体承载在第二批 6/6 通过；累计12稿中，新增动作和预期基本能找到主体。WR-003 的“主体承载”功能成立，但它不能替代事实边界，S03、S05 仍分别存在材料外程序和反馈承诺。
- 文种功能累计 11/12 通过，唯一明确缺口为 S06 未写“编者按”标识。WR-004 已有正向信号，但尚未覆盖约20类事务文体。
- S01、S04、S11 分别出现短稿套语重复、倡议重复和评论内容复述，覆盖三家 provider；三者属于同一上位风险，但具体删除位置和文种功能不同，暂不合成一条机械删句规则。
- S11 再次出现“并非……”“不等于……”“不是为了……”“数据本身不回答……”的保护性论辩，说明普通语义层尚未稳定压住保护性外扩。
