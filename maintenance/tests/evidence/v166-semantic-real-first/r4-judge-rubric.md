# R4 独立审阅口径

只评价 `cases-r4.json` 中 S13—S20 与同名八份稿件。不得推测模型、provider、版本、候选身份或执行顺序。

逐稿检查事实、状态、责任主体与合理推断、文种功能、篇幅、输出洁净度、重复和直接可用性。材料支持的透明算术、一般目的、讲话号召和责任主体承载的自然延续可以接受；不得把它们机械判为外扩。材料外新增具体程序、互动安排、承诺、决定、期限、数字、结果、成效或责任要求属于硬问题。题面点名禁止的事项优先。

篇幅按 `r4-technical.md` 的非空白字符数机械判定。事实、状态、篇幅或输出范围任一硬失败，整稿必须 `FAIL`；轻微文风或重复问题可 `WARN`。

最后按20类累计目标评价 WR-003、WR-004、WR-005 为 `PASS`、`PARTIAL` 或 `FAIL`。WR-003 只判断合理推断是否有责任主体承载，不要求它替代全部事实核验；WR-004 判断文种功能；WR-005 判断自然、篇幅和输出稳定性。不比较旧版本，不设总体胜负门。
