# 决定性文种单叶来源

本页记录五个单文种叶的外部语义校验。来源只用于确认文种功能、主体关系和正文动作，不作为具体业务事实模板。

读取范围：议案与命令两份中国政府网 PDF 的打开请求返回 403，本轮仅取得官方搜索摘要，未核对完整 PDF 或原版版式。对应规则仍需结合真实写稿和后续可访问的一手全文验证；不能把这两项记为全文阅读通过。

## 决定

- 来源：国务院《关于取消和下放一批行政许可事项的决定》，中国政府网，https://app.www.gov.cn/govdata/gov/202009/21/463039/article.html
- 支持规则：发文主体先明确决定事项，随后向执行对象提出落实、配套监管和时限要求，正文保留附件与落款关系。
- 旧共享页语义去向：原页“依据权限和事实作出明确事项、范围、生效和执行要求”进入 `genre-playbook-decision.md`，并补足决定对象、执行对象和权限边界。

## 决议

- 来源：第十四届全国人民代表大会第四次会议《关于政府工作报告的决议》，中国人大网，https://www.npc.gov.cn/npc/c2/c30834/202603/t20260313_453190.html
- 支持规则：决议以会议为作出主体，标明会议通过日期，承接已审议对象，并用“同意”“决定批准”“会议要求”等表述呈现通过后的集体意志。
- 旧共享页语义去向：原页决定、决议合写的权威事项规则中，会议讨论通过、会议主体和通过日期进入 `genre-playbook-resolution.md`。

## 议案

- 来源：国务院、中央军委《关于提请批准南京港对外国籍船舶开放的议案》，中国政府网《国务院公报》1986年第2号，https://www.gov.cn/gongbao/shuju/1986/gwyb198602.pdf
- 支持规则：议案由法定提案主体送同级人大常委会，交代事实依据、必要性和拟议事项，以“特提请审议批准”“请审议决定”收束，并保留提案主体和日期。
- 旧共享页语义去向：原页“围绕提请审议事项交代依据、方案和请求，不写成一般建议”进入 `genre-playbook-motion.md`，并明确上报、提请关系和不得代作批准结论。

## 公报

- 来源：《中华人民共和国和马来西亚联合公报》，中华人民共和国外交部，https://www.fmprc.gov.cn/web/wjb_673085/zzjg_673183/yzs_673193/dqzz_673197/dnygjlm_673199/zywj_673211/200512/t20051215_7605603.shtml
- 支持规则：联合公报先交代形成背景和会谈事实，再分别呈现双方立场及达成的共识，结尾保留形成日期和地点；共同表述与单方表述须区分归属。
- 旧共享页语义去向：原页“只发布已经形成并适合公开的权威事项”进入 `genre-playbook-communique.md`，并补足发布主体、立场归属和联合公报边界。

## 命令（令）

- 来源：中华人民共和国国务院令第799号及《公共安全视频图像信息系统管理条例》，中国政府网《国务院公报》2025年第5号，https://www.gov.cn/gongbao/2025/issue_11866/material/gwygb202505.pdf
- 支持规则：公布行政法规的国务院令使用令号，简要写明会议通过、现予公布和施行日期，随后列签署人、日期及被公布的独立法规正文。
- 旧共享页语义去向：原页“仅在有相应权限、对象和正式发布要求时使用”进入 `genre-playbook-order.md`，并补足令号、签署、施行时间和命令正文与所公布文件的关系。
