# 语义判定校准

依据本轮用户两次纠正：各科室与各业务科室可以是合理选择；判断过严与否时须检查原要求、合理推理、转换、宽泛说法和前后承接。词语未逐字复现不等于功能或范围回退。

有效判定顺序：理解原任务目的和上下文实际指代；辨别是否等价转述、概括、简称或材料与常识支持的分析；再检查数量、对象、责任、办理动作及事实状态是否实际改变。只有能说明实际改变之处才判错。主送简称、句式、标题长短、条列/合段及材料概括，不按固定词句打分。

本轮更正：

- M1“各科室/各业务科室”：撤回早期依该差异认定胜负、扩大范围的结论，不用新规则或反复同题追求原词输出。
- P1“部分货物/所供货物”：总括问题不能自动解释成全部不符，按句群实际含义判断。
- “已排查”概括为已梳理，“需研究消防和权属”转为现有条件制约，以及相关下一步建议：一般可以成立。与此不同，具体场地紧邻哪里、权属属于哪些具体主体等肯定事实，应分清是在作条件性分析还是声称已查明。
- 未定事项仍按拟议口径、条件成熟后推进，不因增加合理的实施建议就判升级；只有写成已批准、已完成等明确相反状态才构成实际问题。
- 匿名包中文件链接被统一改成“本地稿件文件”，不是模型生成坏链接；对此扣分属于审阅误报。

独立审阅原文保留，主代理裁定与用户校准单列，避免回写旧报告制造从未误判的记录。疑似波动用不同题材的同模型同条件A/B扩大范围；本轮M3、H4覆盖明确分工、不同期间、多级期限和部分落实，避免只在一个称谓例子上刷重复样本。
