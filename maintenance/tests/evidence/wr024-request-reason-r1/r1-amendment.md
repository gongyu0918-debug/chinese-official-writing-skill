# WR-024 R1 最小候选补充预登记

Baseline 已证明有依据三题不缺理由；R1 只修请示与申请之间的语义断层：

1. 把申请叶第一条收敛为“请示和申请都应有能够成立的缘由、依据或必要性”，通常先缘由/依据、后请求事项；紧凑短稿允许同句承载。
2. 把“材料事实与常识可直接支持则自然承载、真正无法闭合则正文外短提示”的现有申请边界明确扩展到请示。
3. 把单项采购的原因、数量、金额和升级条件写成同时适用于采购请示与采购申请。

不修改 Hook、description、`information-selection.md`、通用文种、字数门或格式规则，不增加范文和固定句式。

## R1 采用标准

- Q1—Q3：缘由/依据/直接用途目标保持，不出现候选独有事实、状态、事项、数字或交付形态硬回退。
- Q4：0份正文使用“因故”等泛称代填具体缘由；相对 Baseline，至少三家不再把主送、落款、日期、流程或关联事项扩成缺项清单。
- 合理的一层目的、必要性、直接作用、低强度资格判断和条件性结论不判失败；只对候选可归因回退作否决。
- 若 R1 没有真实改善，恢复产品字节并终止，不做 R2 提示堆叠、不留 `HOLD`。
