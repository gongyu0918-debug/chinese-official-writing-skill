# WR-024 请示缘由、依据与材料缺口 R1 预登记

## 研究结论与待验证问题

《党政机关公文处理工作条例》规定行文应当确有必要，请示应当一文一事；下级机关转报请示事项时还应提出倾向性意见。岳阳市教育体育局机关公文写作要求、云南人大机关写作说明、南京工业大学请示写作说明等官方机关或高校办公规范，均把正文概括为请示缘由、请示事项和请示要求，并强调缘由应说明原因、背景、依据或理由。

抽取的政府公开请示覆盖工程调整、项目立项、车辆报废、延期、道路命名、人员聘任、机构设立、养老设施、社保方案、医疗系统接入、活动举办和规划印发。样本都在请批事项前或同句中给出至少一种承载：既有问题、制度依据、前序批复或工作状态、现实需要、办理目的。它们不支持把“缘由”机械等同于一段宏大意义、既成效果或具体损失。

当前仓库 `handling-elements.md` 已把请示的依据、必要性列为核心要素；申请叶却写“请示可先明确请批事项，再说明依据和必要性”，随后“材料可推/完全缺失”的规则未明确限定是否同时适用于请示。本轮先验证当前产品是否因此产生无缘由请示、错位缘由或材料缺失时的捏造。

## 固定边界

- 请示缘由可以是事实问题、制度或上级要求、前序决定与当前进度、事项本身可直接支持的一般目的，不要求固定使用“因、为了、根据”。
- 已给事实与常识能闭合时，允许写一层低强度原因、依据、必要性、直接用途或条件性结论；不能因材料没有逐字给出成句而判外扩。
- 真正无法闭合时，不编造具体故障、损失、政策条款、上级要求、程序、责任或审批结论。输出允许正文外提示时，只提示补充请示缘由或依据；只交正文时不夹带提示或占位。
- 紧凑请示可以在同一句中承载缘由与事项，不以固定段数、正文长于提示词或出现指定连词为门。
- 只把候选改动可归因的事实、状态、文种、交付形态或目标功能回退判失败；合理扩写、常识推断和自然论证不判失败。

## Baseline 任务

固定 `main@e05de14a7376f310dfb891bef322ca3a57a3b084`，五条登记低成本 provider、`max`、每题每模型一次、零质量重试：

1. `Q1_REPAIR_FACT_CAUSE`：确认故障、报价和未批状态齐全，检查是否先承载现实原因，再提出维修经费请示。
2. `Q2_PERSONNEL_BASIS`：制度依据、培训考试与工作需要齐全，检查是否形成紧凑的依据—事项链，不扩大任职资格或批准状态。
3. `Q3_PROCUREMENT_COMMON_SENSE`：只有碎纸机、数量、金额、普通办公室语境和未定状态，允许概括“日常文件处理需要”，不得外推涉密、安全事故、设备损坏或现有数量不足。
4. `Q4_MISSING_REASON_HINT`：延期事项、日期和未批状态齐全，但没有任何延期原因，且允许正文外提示；不得用天气、场地、人员冲突等代填。

## 是否形成候选

- 若至少两家有效 provider 在有依据题遗漏缘由/依据、把请批事项写成无理由转述，或在缺失题编造具体原因，形成最小申请叶候选。
- 候选只允许把请示明确纳入已经通过的“事实与常识可闭合则自然承载、真正缺失则正文外提示”边界，并把通常顺序收敛为“缘由或依据—事项—请批语”；不新增 Hook、description、字数门、固定段落或其他文种规则。
- 若当前基线已稳定覆盖，不为文字对称单独改产品，状态进入 `CURRENT_BASELINE_SUFFICIENT`。
