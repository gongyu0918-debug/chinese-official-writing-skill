# 联网来源用途、有限补搜与命中页绑定 R2h

日期：2026-08-22。范围为公开来源核验的真实写稿行为，不验证浏览器或搜索服务本身，也不新增搜索 Hook、工具代理或调用门禁。

## 结论

来源用途分型和命中页绑定完成：最终 R2h 五路均把国家条例作为国家规范依据、上海条例作为本市执行口径、浙江条例只作为外省比较；五路来源清单均写入实际打开的上海全文页 URL，没有再用标题代替链接或猜写 URL。

有限补搜的写作规则可显著减少无边界检索，但不能承诺每个模型严格只发起一次工具调用。R2f—R2h 共15份同题真实稿中12份只发起一次定向补搜；其余3份分别是 R2f Ollama 7次、R2g Luna 2次、R2h Ollama 3次。失败在不同路线间转移，继续堆提示词不再作为下一方向。产品保留“只围绕缺口补搜一次”的语义约束；若未来必须硬限制调用次数，应另做宿主级搜索预算原子，不能把当前规则写成确定性工程门。

## 失败驱动的原子

1. 来源用途：法规政策只支撑规范依据，地方正式文件只支撑适用地域的执行口径，官方新闻只支撑事件与公开进展，统计来源只支撑明示口径的数据。
2. 有限停止：主来源可打开、字段齐全且无直接冲突时立即停止；只有打不开、缺必需字段或直接冲突时才围绕缺口改一次查询。
3. 重试计数：补搜动作一经发起即计入一次，空结果、超时和工具报错不构成重试授权。
4. 同页绑定：来源清单的标题、发布主体、URL 和核验状态来自实际打开的同一页；工具返回的 URL 逐字照录。
5. 元数据缺口：命中页已打开但缺发布主体等字段时列缺口，不为补来源清单字段再次搜索，也不用标题代替链接。

## 当前边界

- `DONE`：来源用途分型、实际打开同页绑定、缺字段列缺口、真实 URL 照录。
- `DONE_WITH_LIMITATION`：有限补搜作为写作语义和停止提示；15稿中12稿精确一次。
- `TERMINATED_AS_PROMPT_ONLY`：用更多提示词追求所有模型严格一次工具调用。若没有新的宿主级机制和真实生命周期，不继续叠字。
- 未实现：文件提取失败后的下载/解析降级。当前样本没有形成该类真实失败，不启动胶水。
