根据 Skill 自带的说明（`README.md`），直接回答你的三个问题：

## 1. 它能帮你做什么

这是一个中文正式材料的写作助手，覆盖这些类型：

- **公文与事务性材料**：申请、请示、报告、通知、通告、函、批复、纪要、总结、调研、讲话致辞等
- **专项材料**：投诉与情况反映、意见建议反馈、新闻消息与评论、制度规定办法、整改方案、可研与审查材料、AI 算力类正式材料
- **加工方式**：起草、改稿、压缩、扩写、审校（只提问题不改文也行）、去口语化、去 AI 味、Word 正文与排版

核心理念是**材料里有什么就写什么**：事实、数字、日期和"建议""拟开展""尚未决定"等状态会被保留；没有依据的内容不编造，也不会用占位符硬拼一篇看似完整的稿子。

## 2. 只有零散想法，怎么请它写

直接说，**不用先整理成标准提示词，也不用填什么要素核对卡**。README 里原话是"想到哪里，就从哪里开始"——几句想法、一段聊天记录、半篇旧稿，都可以作为起点。

具体用法，照着说就行：

> "帮我写一份……" + 手头材料 + 写作要求

比如："这是下周培训的安排，帮我写个通知，把报名的事说清楚。"材料还没整理好，就把想到的内容先发来；篇幅、语气、用途、必须保留的内容也可以一起说。要改旧稿就说"帮我改一下"，给它新情况让它出新版；只要正文就明确说"只输出正文"。

## 3. 能写小说吗

**不能。** README 明确写明"这个 Skill 不用于小说和文学作品创作"；SKILL.md 的边界也规定不为文学创作、英文写作、营销软文、社交媒体文案、代码说明启用本技能。这是它的边界，写小说请找其他工具。

一句话总结：**正式公文和事务写作交给它，创作类内容不归它管。**
