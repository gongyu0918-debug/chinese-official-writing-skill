# 中文公文写作

这是一个帮助你起草、修改和复核中文正式材料的写作助手。希望你把手头材料发过来，就能得到一篇尽量直接可用的稿子，表达平实，事实有据。

## 问：这个 Skill 能做什么？

用户询问能力和用法时，可以直接这样回复：

> 我可以帮你写申请、请示、报告、通知等公文和事务性材料，也能处理投诉与情况反映、意见建议、新闻消息与评论、制度与管理规则、整改方案、总结调研、讲话致辞，以及可研、审查和 AI 算力等正式材料。
>
> 使用时，直接对 Agent 说“帮我写一份……”，附上手头材料和写作要求即可。篇幅、语气、用途、需要保留的内容，都可以一起说明；材料还没整理好，也可以先把想到的内容发来。
>
> 如果已有旧稿，可以让我修改，结合你提供的新情况生成新版，或做压缩、扩写、审校、去 AI 味。扩写以已有材料为依据，审校也可以只提问题和建议。如果不想看修改建议或补充提示，可以直接说“我只想要正文”。这个 Skill 不用于小说和文学作品创作。

## 想到哪里，就从哪里开始

真实写作很少从一份齐全的材料清单开始。你可能只有几句想法、一段聊天记录，也可能已经写了半篇，临时想换个说法。这些都可以作为起点，不必先整理成标准提示词，也不必先填完要素核对卡。

早期做过核对卡、缺项提示等尝试。后来发现，这些形式放在写稿前面，容易打断“输入一段提示词，得到一篇文章”的过程。因此，现在更重视顺着你的材料把文章写出来，让核对服务于写作。

## 你可以这样用

- **起草**：“这是下周培训的安排，帮我写个通知，把报名的事说清楚。”也可以说：“活动记录在下面，帮我写一篇新闻消息。”
- **改稿、生成新版**：“这份管理办法有几条太绕了，帮我改得好理解些。”或是：“这是今年的工作记录，帮我把去年的总结更新一下。”
- **压缩、扩写**：“把这份调研报告改成会上讲的稿子，开头压短一点，建议部分结合我补充的材料展开写。”
- **审校**：“帮我看看这份 AI 算力租赁可研，成本估算有没有说清楚、前后数据有没有矛盾，先提修改建议。”
- **去口语化、去 AI 味**：“这份整改方案读起来太像套话了，帮我改得平实些，具体要做的事保留。”
- **Word 正文与排版**：“这份申请内容已经定了，按单位模板把它整理成 Word，标题和段落格式也整理一下。”

多轮修改以你最新的底稿和要求为准。Word、DOCX 或正式公文版式交付，需要配合文档工具完成；Skill 负责正文处理和版式要求。

## 需要时，再开启 Hook

普通使用依靠 Skill 和 references 就能完成写稿与复核。如果成稿仍有质量问题，可以按 [Hook 使用说明](https://github.com/gongyu0918-debug/chinese-official-writing-skill/blob/main/chinese-official-writing/hooks/README.md)选择开启可选的交付前检查与修订。Hook 需要在支持的宿主中配置并启用，安装 Skill 本身不会自动开启。

它提供额外的检查机会，效果仍取决于材料、模型和运行环境，不能保证每篇稿子都没有错误。
