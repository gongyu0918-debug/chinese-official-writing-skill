# 中文公文写作 Skill 能帮你做什么？

根据 Skill入口说明（README.md能力答复），这个写作助手可以帮你起草、修改、压缩、扩写和复核以下中文正式材料：

- **公文类**：申请、请示、报告、通知、通告、意见、决定、决议、议案、公报、命令、函、复函、批复、说明- **事务性材料**：方案、纪要、公告、公示、通报、制度、规定、办法、管理办法、细则、操作规程、工作要点- **总结调研类**：总结、调研报告、考察材料
- **讲话致辞类**：讲话稿、致辞
- **专项材料**：可行性研究、审查材料、AI 算力相关正式文本
- **新闻类**：新闻消息、快讯、活动报道、新闻通稿、新闻评论、时评、评论员文章
- **合作性意见**：面向政策制定、审核、平台建设运营方的意见建议、建议反馈
- **投诉与整改**：投诉与情况反映、整改方案

还能帮你做去口语化、降 AI 味、文种校验、办理要素核对、Word 正文整理与排版交付。

## 只有零散想法时，怎么请它帮你写稿？

不必先整理成完整提示词或填要素卡，直接把"手头的东西"发给它就行。常见的起点有：

- **几句想法**："下周要开个培训，帮我写个通知，把报名说清楚就行。"
- **一段聊天记录或会议纪要原文**："这是刚才的讨论要点，帮我整理成一份会议纪要。"
- **半篇旧稿**："这份稿子有几段太啰嗦，帮我改得平实一些。"
- **已有成稿 + 新材料**："这是去年的总结，帮我用今年的材料更新一下。"

写稿要求可以一起说：篇幅、语气、用途、要保留的内容、读者对象等。如果不想看修改建议或补充提示，可以直接说"我只想要正文"。

Skill 会顺着你给的材料把稿子写出来，而不是先让你填一堆表单。

## 能写小说吗？

**不能。** Skill 的使用边界明确排除了小说和文学创作（SKILL.md 第28 行："不要为以下任务启用本技能：英文写作、文学创作、营销软文、社交媒体文案、代码说明"）。README.md 中也直接说明："这个 Skill 不用于小说和文学作品创作。"

它写的是平实、可执行、有事实和要素依据的正式工作材料，不会做虚构叙事、人物塑造、情节铺陈这类文学创作任务。如果你需要的是故事、小说、散文、剧本，请使用其他专门的写作工具。
