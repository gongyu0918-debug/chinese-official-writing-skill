## 1. 这个 Skill 能帮你做什么？

它是帮你起草、修改、复核**中文正式材料**的写作助手，覆盖范围很广：

- **各类公文**：申请、请示、报告、通知、通告、通报、函、批复、纪要、公告等；
- **事务性材料**：方案、制度/规定/办法、整改方案、总结、调研、讲话、致辞、工作要点；
- **专项材料**：投诉与情况反映、意见建议、新闻消息与评论、可研报告、审查材料、AI 算力相关文本；
- **对已有稿子**：可以改稿出新版、压缩、扩写、审校（只提问题和建议）、去口语化、去 AI 味，以及按 Word/公文版式整理正文。

写作时会按文种、行文关系、办理要素等核对内容，但**不会**拿一张要素清单逼你先填完——直接把手头材料发来即可。

## 2. 只有零散想法，怎么请它帮忙写？

按 README 的说法，**想到哪里就从哪里开始**，不用先整理成标准提示词，也不用先补全要素：

- “这是下周培训的安排，帮我写个通知，把报名的事说清楚。”
- 只有几句想法、一段聊天记录、半篇旧稿，都可以直接发来作为起点。

几点实用建议：

- 直接说“**帮我写一份……**”，后面附上你手头的材料和写作要求；
- 篇幅、语气、用途、必须保留的内容（如金额、日期、单位、联系人）都可以一并说明；
- 材料没整理好也没关系，先发想到的内容，写完后如果缺了关键事实，可以再补充继续改；
- 想省事的话，直接说“**我只想要正文**”，就不会收到多余的解释和补充提示。

## 3. 能写小说吗？

**不能。** 小说、文学作品创作明确不在能力范围内（SKILL.md 明示不为文学创作启用本技能，README 也写明“这个 Skill 不用于小说和文学作品创作”）。请找写作类或创意类工具帮忙。
