# 关于这个中文公文写作 Skill

## 一、它能帮你做什么

这是一个**专门处理中文公文、事务性材料和新闻稿件**的写作助手，覆盖起草、改写、压缩、润色、复核等全流程。

**适用文种**包括：
- **上行文**：请示、申请、报告、情况反映
- **下行文**：通知、通告、意见、决定、决议、命令、批复、通报、公告、公示
- **平行文**：函、复函、议案、公报
- **规范性文件**：制度、规定、办法、管理办法、细则、操作规程
- **事务性材料**：方案、工作要点、总结、调研报告、纪要、讲话稿、致辞- **专项**：可研报告、审查材料、新闻消息、新闻评论、AI 算力相关材料

**额外能力**：文种校验、格式核验（GB/T 9704 红头文件）、去口语化、降 AI 味、办理要素核对、Word 版式整理。

---

## 二、只有零散想法时怎么请它帮忙

把"骨架信息"交给它，剩余的让它按事实边界成稿。**建议你按以下顺序提供**：

| 必给项 | 举例 |
|---|---|
| **文种** | "帮我写一份申请" / "这是情况说明" |
| **发文主体** | 哪个单位发文 |
| **接收对象** | 上级、平级还是下级（决定结尾语和语气） |
| **事项与依据** | 为了什么事、依据什么文件或政策 |
| **关键事实** | 时间、数量、金额、责任分工、时限 |
| **期望动作** | 请示批准 / 通知执行 / 征求意见 / 反映问题 |

**零散想法的具体建议**：
- 直接把要点列成几条发过来即可，例如"想申请一笔经费，用于培训，3 万元，下个月开始"
- 它不会替你编造单位、金额、日期、电话、邮箱、印章- 缺的要素它会在正文里如实留白或说明，不会用"上级单位""相关部门"等泛称硬补
- 想让它润色或压缩已有稿子，直接把原文贴过来并说"按正式公文语气改一遍"或"压到 800 字以内"

## 三、能写小说吗？

**不能，也不建议使用本 Skill 写小说。**

入口文件明确规定不适用于：英文写作、文学创作、营销软文、社交媒体文案、代码说明。小说属于文学创作，本 Skill 的所有规则（行文关系、文种功能、去 AI 味、办理要素等）都不适用于虚构叙事，硬用反而会让稿件失去文学性。

如果你有小说、散文、剧本等写作需求，应当使用其他通用写作类工具，而不是本 Skill。
