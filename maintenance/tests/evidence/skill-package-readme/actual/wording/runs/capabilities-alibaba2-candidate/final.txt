我读了 Skill 入口和 README，直接回答你的三个问题：

## 1. 能帮你做什么

这个 Skill 专门处理**中文公文和事务性正式材料**，覆盖起草、改写、压缩、扩写、审校、去 AI 味等全流程，常见用途包括：

- **公文类**：申请、请示、报告、通知、函、批复、纪要、公告、通报、意见、决定等
- **事务性材料**：投诉与情况反映、意见建议、制度规定与管理办法、整改方案、工作总结、调研报告、讲话致辞
- **新闻与宣传类**：新闻消息、活动报道、新闻通稿、新闻评论、时评
- **专业材料**：可行性研究报告、审查材料、AI 算力相关的技术材料等
- **加工处理**：给旧稿换说法的改稿、压缩长文、扩写、审校（可以只提问题和建议不改写）、去口语化和去 AI 味、按单位模板整理 Word 排版

## 2. 只有零散想法怎么用

**想到哪里就从哪里开始，不用先整理成标准提示词，也不用填任何清单。** 直接说"帮我写一份……"，把手头想到的内容发过来就行。比如：

> "这是下周培训的安排，帮我写个通知，把报名的事说清楚。"

哪怕只有几句话、一段聊天记录，甚至写了半篇想临时换个说法，都可以作为起点。多轮修改以你**最新的底稿**为准；如果材料里的事实、数字、"拟开展""尚未决定"这类状态你没给，它不会编造，也不会用占位符拼一篇看似完整的稿子。你只要正文时直接说"我只想要正文"即可。

## 3. 能写小说吗

**不能。** 这个 Skill 明确不用于小说和文学作品创作（也不管英文写作、营销软文、社交媒体文案），它的边界就是中文公文和正式工作材料。写小说需要找对应的创作类工具。

简单说：**手头有什么想法，直接发过去，说"帮我写个××"就行。**
