# U1—U6 剩余语义探针

## 判断

- **U1 有窄缺口。** 当前入口清除旁白，`anti-ai-patterns.md` 保护真实领导背景，`final-review-layers.md` 只泛称事实、字段、附件和批注；没有直接区分用户要求保留的正式声明、版本/密级标识与模型生成的版本说明、免责包装。旧整句断言不必恢复，但应验证角色识别。
- **U2 主要是旧字面断言过严。** 当前入口要求标题/小标题用普通文本，校对页检查标题、标点和空行，Word 页又按实际统领关系区分层级标题与完整编号正文句，足以支持场景判断。缺的是纯文本例证，不宜把“标题后必须空一行”等排版偏好升级为所有载体硬门。
- **U3/U4 部分已有覆盖，仍需合并验证。** 信息选择页已保护逐字限制，抗 AI 页保护直接引语、引用和论断强度，校对页覆盖引用保真与搭配；但“引号即逐字”不成立，成语也不应默认永不修改。真正要守的是明确原文/逐字边界、未核引用状态及低置信语言项不硬改。无需恢复固定核实句、“的地得/量词”词表。
- **U5 有明确关系缺口。** 通知页分别列对象、渠道、联系人并禁止补落款，但未说明邮箱或接收单位名称不能据此成为发文主体；一般主体一致性不足以表达这个非推导关系。
- **U6 已有通用覆盖。** 算力页把 Token、调用次数列为不同用量维度，要求单位一致、Token 主线承接费用；抗 AI 页保护专业术语，技术术语页保护官方拼写。旧句必须落在 `technical-terms.md` 的断言是职责错位；无需补回。真实探针只需确认模型不把两种量混写。

## 建议的自然真实提示（不超过四条）

1. **声明、版本和保密标识改稿（U1）**

   > 请把这份内部工作提示改得正式、简洁，只输出改后全文。材料明确要求首页保留“内部资料 注意保密”和“第二版（2026年9月修订）”；正文中另有“本文由AI整理”“以下为最终版本”“仅供参考，以实际审核结果为准”。保留正式标识，清除生成和交付旁白，其他事实不变。

   观察：两项正式标识仍在，三项模型包装被删。边界：真实业务声明、法规要求或用户指定版本名不能仅因含“版本/说明/声明”判错；普通文件名中的“版本升级”也不是交付元信息。

2. **引语、成语和纯文本标题改稿（U2—U4）**

   > 请校改下面的纯文本讲话材料，只改确有问题处，不用 Markdown。有效材料明确全年组织3场培训；负责人原话由用户提供，但出处和日期尚未核验。现稿为：`凝心聚力推进服务改进。`（主标题，下一行直接接正文）`一、工作要求。` `会上，负责人原话是：“要久久为功，把群众的事办实。”` `1. 各部门要快速的回应诉求，全年组织3台培训`。允许在正文后给文后提示，请给完整改后稿。

   观察：主标题去掉正文句号并与正文分开，层级标题不留句号，完整编号正文句保留句末标点；明确原话及成语不被随意改写，明显“的/地”和量词错误得到校正；未核状态只在允许的文后提示中说明，不把引文本身换成“请核实出处”。边界：不能规定所有引号、所有成语都逐字保留；用户模板优先，低置信用法不机械判错。

3. **通知渠道与发文主体（U5）**

   > 根据材料起草简短通知：请各业务科于9月20日前把培训报名表发送到市培训中心邮箱 pxzx@example.org，接收联系人王老师。材料没有说明发文单位、落款、成文日期，也没有授权市培训中心发布通知。只用这些信息成稿。

   观察：通知写清对象、事项、期限、渠道和联系人；不把“市培训中心”或邮箱域名反推为发文主体，不补落款和日期。边界：渠道名称可以作为真实接收方保留；若材料另行明确发布主体，就应正常写入，不能因同时是接收方而删掉。

4. **Token 计量概念改稿（U6）**

   > 改写一段算力费用说明：试用期共调用模型1200次，输入和输出合计800万Token；按Token计费，单价及总额尚待核实。请把需求与费用口径写清，保持数字和待核状态，不新增GPU、并发或SLA数据。

   观察：调用次数与 Token 分列为不同指标，费用仍按 Token 口径且金额待核，不互相换算或把800万Token改成1200次。边界：材料明确给出平均每次Token或换算公式时可以透明计算；`Token调用需求`是自然术语搭配，不能仅因同时出现“调用”二字判混淆。

以上探针用于判功能，不以固定句、固定段数或逐字命中评分；本次未运行模型，也未修改产品或测试。
