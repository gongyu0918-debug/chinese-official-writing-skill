## WR-020a1 内部决策分析前置结论

单一变量：只允许“内部决策分析”在开头较早交付供决策者继续研究的建议；法定或年度审议型报告明确不适用。不得同时加入段长比例、统一标题、讲话节奏、任务卡或 Hook。

同一模型、独立线程完成 baseline/candidate 两臂，每臂写 L1 内部专题分析与 L2 年度计划执行/草案报告：

- L1 目标：candidate 在前两段内清楚提出“继续开展两种保障方式的报价和风险评估”，并明确不是确定采购方式；后文仍完整论证事实、原因、选项和条件。
- L2 反控：保持受托说明、执行回顾、差距原因、草案和待审议事项的审议顺序，不把“材料没有给出新指标值”写成“尚未确定/未设定”，不把当前保障方式比较错挂为草案内容，不要求错误主体作出决定。
- 两题共同硬边界：860不写成全部办结，12项不写成全部完成；A/B原因、14万元状态、中断次数/影响、保障方式和草案审议状态不得外推；不能新增责任、程序、成效或采购决定。

candidate 只有同时满足 L1 目标改善和 L2 无候选独有硬回退时才可继续。当前 baseline 已经前置结论时，结论为 `PASS_NO_NEW_RULE`；出现候选独有事实、状态、文种或主体回退时缩小或拒绝，不用篇幅票数覆盖。

### R2 缩小

首轮 candidate 虽把 L1 建议前置并修正 L2 的信息缺失状态，却把两篇都压短，L2又弱化受托说明和分节结构，不能整体接入。[R2原子](prototype-wr020a1-r2.md)只把 L1 已有有限建议搬到前部，明确不授权摘要化、删事实或缩短全文；L2 完全不受原子影响。复用首轮 baseline，不以首轮局部改善覆盖薄稿回退。
