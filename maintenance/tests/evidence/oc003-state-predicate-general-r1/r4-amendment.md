# R4 条件缺口例示原子

R3 五路 Candidate-only 中，Alibaba2、MiniMax、Luna 接受“资金未下达→暂不具备启动政府采购条件”，OpenCode、Ollama 仍要求材料逐字写出因果；三条后续控制均保持合法条件判断或总体已决/局部未定，没有候选硬回退。目标由 R2 的0/5改善为3/5，但尚不稳定。

R4 是本方向最后一次最小化：不增加新门禁，只在同一句列出资金未到位、审批未完成、技术条件不足三类常见前提缺口，明确它们可支持“暂不具备相应条件”，但必须同时写出缺口和暂时性，不得扩大范围或写成永久否定。

新素材改用预算落实、环评批复、消防/应急电源和总体采购已决四题。五路 Candidate-only 任一路误删有依据的低强度判断，或改变采购已决状态，即不把本方向作为稳定写稿能力准入。
