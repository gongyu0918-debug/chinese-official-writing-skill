# R3 合理条件判断原子

R2 holdout 的五路 Baseline/Candidate 均正确处理“单次会议未审议不能上推总体未决定”和“总体采购已决、局部节点未定”，但十稿也全部把官方实际存在的“资金未下达→暂不具备启动政府采购条件”判成材料外因果。R2 没有候选独有硬回退，却没有解决用户指出的过度谨慎问题。

R3 不增加新的禁止项，只把“材料明确前提缺口可直接支持低强度条件判断”拆成独立一句：不要求材料逐字给出因果句，但必须同时写明缺口、保持同一对象和暂时性，不扩成更大范围或永久否定。

使用四题新 prompt 运行五路 Candidate-only：资金未下达的采购条件、明示审批前提的开工条件、实测技术缺口的部署条件，以及总体已决/局部未定的直接改稿。任一路误删合法条件判断、改变已决状态或新增责任/期限，即拒绝本方向。
