# 中文公文写作

用于中文公文、事务性材料、正式工作材料、新闻消息和新闻评论的起草、改写、压缩、润色、审核及 Word 正文整理。

## 主要能力

- **法定与通用公文**：申请、请示、报告（含突发事件初报/续报/终报）、通知、通告、通报、公告、公示、意见、决定、决议、议案、公报、命令、函、复函、批复、纪要。
- **事务与工作材料**：工作总结、工作要点、述职、整改方案与进展、反馈报告、情况说明、签报呈批、制度办法与操作规程、应急预案、调研提纲与报告、可行性研究、审查意见、政务信息与简报、先进事迹、组织鉴定、证明与介绍信、授权委托、承诺书与责任书、工作交接、会务筹备、礼仪书函、讲话与主持词。
- **新闻与技术专项**：新闻消息、编者按、新闻评论、技术需求、AI 算力方案与评审、信息化建设运维、采购专项核对、项目验收、软件正版化。
- **编辑、复核与排版**：主次重构、多材料统稿、压缩扩写、精确逐字替换、去 AI 味与去保护性叠甲、审校与审后改稿、Word 及 GB/T 9704-2012 版式整理。

## 使用方式

直接提供现有材料、稿件用途和写作要求即可（几句要点、会议记录、多份草稿或旧版文件均可）。多轮修改默认以最新版底稿和本轮要求为准；需要只输出成品时，直接说明“只给正文”。

八组常见中英文用法示例见 [examples/prompts.json](examples/prompts.json)。

## 写作理念

1. **主次分明，先答核心**：围绕本件读者需要了解、决定或办理的事项组织全文，核心内容写透、背景支撑从简、明细按用途集中到附件，不平均铺陈、不在引言无意义复述后文分项细目。
2. **硬事实零虚构，合理推断不畏缩**：主体、数字、日期、已发生事件和办理阶段严格以材料为据；在此边界内，鼓励结合常识做因果归因、风险判断、做法提炼与可执行建议，不做僵硬的素材复读机。
3. **直述自然，拒绝对冲叠甲**：用前置主语、期间和定语直接写准事实范围，仅保留避免读者误判结论、权限或下一步动作的必要业务状态，删去仅为自我避险而追加的保护性免责尾巴。
4. **工具轻量可靠**：配套 5 个 Python 3 零依赖脚本，支持精确字数/汉字统计（`draft_length.py`）、机械风险/机关硬规范与公开脱敏扫描（`prose_lint.py`）、内存精确替换（`edit_scope.py --stdin`，脚本自身不读写磁盘文件）、原文定位与数字/日期/书名号自动对账（`material_diff.py`）以及 GB/T 9704-2012 公文 Word 确定性生成（`build_docx.py`）；无工具或写入受限时仍可直接完成写稿与审校。
