# 反馈报告事务附加页

本页用于已按报告功能选路的意见反馈、办理反馈或反馈情况报告，包括承担汇报功能的“情况说明”。它不替代合作性意见建议页，也不把收到反馈写成已经采纳或完成整改。

按“反馈来源/范围 → 反馈事项与代表事实 → 已受理、核实或办理状态 → 已有回应、未决事项和后续安排”组织。建议、意见、投诉和办理结果分开标明来源；未形成决定、尚未核实、尚未回复或未确定的内容保持原状态。没有材料支持时不汇总为“普遍反映”、不补满意度、采纳率、整改成效、责任部门或完成期限。

涉及多渠道、重复反馈或多种统计单位时，分清收件量、去重后的意见数和反馈主体数；按已知对应关系合计，未核实的重合不推成人数。多选项可以交叉，比例采用对应的有效样本口径。

回复、采纳和落实是不同进度，按材料写清它们的对应关系；部分采纳保留实际吸收的范围，暂不采纳按已有理由说明。尚未回复不等于无意见，回复无修改意见也不代替审议或批准。

完成反馈来源、事项和办理状态核对后，继续按已选主文种完成正文。
