# 意见反馈场景附加页

在已选主文种中核对征求意见、办理反馈的来源、处理和回应情况，可用于反馈报告、结果公告或具体答复。正文仍按原用途组织，不因加读本页改成报告；单纯提出建议不进入本页。

把反馈来源、范围、事项及其处理状态对应起来，已有回应、未决事项和后续安排按本稿用途取舍。建议、意见、投诉和办理结果分开标明来源；未形成决定、尚未核实、尚未回复或未确定的内容保持原状态。没有材料支持时不汇总为“普遍反映”、不补满意度、采纳率、整改成效、责任部门或完成期限。

涉及多渠道、重复反馈或多种统计单位时，分清收件量、去重后的意见数和反馈主体数；按已知对应关系合计，未核实的重合不推成人数。多选项可以交叉，比例采用对应的有效样本口径。

多种处理状态交叉时，写清已回复但仍在研究、已采纳但尚未落实等对应情况；部分采纳保留实际吸收的范围，暂不采纳按已有理由说明。尚未回复不等于无意见，回复无修改意见也不代替审议或批准。

完成反馈来源、事项和办理状态核对后，继续按已选主文种完成正文。
