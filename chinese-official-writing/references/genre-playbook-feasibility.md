# 可行性研究

本页只处理以项目决策依据和可行性论证为主要交付物的可研材料，不承担一般调研报告或采购审查骨架。

## 成稿骨架

项目对象与建设性质 → 需求和现有基础 → 建设内容与方案比较 → 投资、资金和实施条件 → 风险、效益与保障 → 条件性结论或请决策事项。

投资估算、资金来源、建设周期、效益和风险分别标明实际、测算、估算或假设口径；材料缺失时标为实质缺项或待核，不用地方模板补数字。结论按证据强度写“具备条件”“有待补充论证”或“尚不能判断”，不把建议写成已批项目。

算力、GPU、模型服务或租赁等场景只在主文种确定后叠加 `ai-compute-docs.md`；采购审查转采购审查页。完成可研核对后停止读取本页。

材料只给初步设想、待核估算和仍需论证的状态时，正文停在这些状态和条件性判断，不替用户补写下一步项目动作、周期、效益或资金安排。只输出正文时不附路由、复核或 Skill 说明。
