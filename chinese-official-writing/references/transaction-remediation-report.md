# 整改报告事务附加页

整改进展报告、情况说明或情况通报围绕问题、整改事实和当前状态展开，保持已选文种的用途与语气。

按问题来源与范围、对应整改事实及结果、尚未解决事项、复核或下一步安排组织。每项进展对应原问题；采取措施、达到阶段目标、完成整改、通过复核分别采用材料中的状态及证据。

汇总时统一统计时点和计数单位，分清问题、整改事项、责任单位及金额等口径。一个问题下有多项措施时，按其对应关系归集；阶段性结果和持续整改分别说明。

材料和常识支持的原因、影响及下一步建议可写入，建议与已经确定的安排分开。具体责任、期限、验收结论和成效采用材料或明确授权；复核时间尚未确定等状态照实保留。进展材料尚缺时，写清现有问题与待核内容，缺项按 `writing-rules.md` 处理。
