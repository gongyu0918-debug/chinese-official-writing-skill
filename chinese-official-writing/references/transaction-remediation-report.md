# 整改报告事务附加页

整改进展报告、情况说明或情况通报围绕问题、整改事实和当前状态展开，保持已选文种的用途与语气。

围绕问题来源与范围、对应整改事实及结果组织。每项进展对应原问题，当前阶段和接续安排就近说明；采取措施、达到阶段目标、完成整改、通过复核分别采用材料中的状态及证据。

汇总时统一统计时点和计数单位，分清问题、整改事项、责任单位及金额等口径。一个问题下有多项措施时，按其对应关系归集；阶段性结果和持续整改分别说明。

材料和常识支持的原因、影响及下一步建议可写入，建议与已经确定的安排分开。具体责任、期限、验收结论和成效采用材料或明确授权；影响本次结论的关键条件集中写清。进展材料较少时，按已有问题与整改事实成稿，影响使用的实质缺项按 `writing-rules.md` 处理。
