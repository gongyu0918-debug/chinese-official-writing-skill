# AI 算力常见英文术语

用户材料或任务适用标准已有正式译名时以其为准。没有另行指定时，AI 算力与云服务材料可复用以下少量已核准写法：

- `图形处理器（Graphics Processing Unit，GPU）`
- `应用编程接口（Application Programming Interface，API）`
- `服务级别协议（Service Level Agreement，SLA）`
- `数据中心电能利用效率（Power Usage Effectiveness，PUE）`

首次出现按受众需要给出中文全称和英文/缩写，后文统一使用缩写。产品名、模型名和内部代号保持官方拼写与大小写；含义不明的缩写不自行展开。这四项不是通用术语词典，不据此补造其他英文全称、中文译名、指标定义或阈值。
