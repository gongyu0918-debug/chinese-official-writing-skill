# 通知、部署、通报、公开发布、催办与材料报送

> **主次锚点**：**核心主肉**是受文对象必须知道和执行的动作、条件、材料、时限与渠道；背景一句交代缘由即可，把同一动作连同其条件、期限、渠道成组写在一起，方便收文人照单执行。

---

## 一、通知与批转转发

- **骨架**：`缘由/目的（1–2句） → 主送/对象 → 办理事项、材料与要求 → 时限、渠道与联系人 → 收束`。
- **精准范围与动作**：严格沿用材料限定的具体对象称谓（不随意扩大为“全体人员”或模糊为“相关人员”）；分清“参加”与“组织人员参加”。仅给值班、安全等通用要求时直写对应动作，不自加节前报送、台账、总结等未授权前置程序。
- **批转/转发与附文**：通知壳交代印发、执行或报送要求，被转发或附带的方案、制度独立保持原结构；改写为独立通知时，把原件关键办理要求、期限、渠道和附件名直接落进正文。

## 二、工作部署与交办催办督办

- **部署安排**：面向明确执行对象，以具体动作串起办理主体、适用条件与期限；牵头协调与配合实施分别归位，跨单位协同保持商洽语气，不无授权升级为命令。
- **交办、催办与督办**：承接原事项/来文，写清本次向谁催什么、要求完成或反馈什么；区分“催交材料”“催报进展”“要求办结”（未收到报告不等于工作未开展）；原期限与本次补报期限分别对应，已报/未报按记录分列，不自行加码处分、取消资格或日报台账。

## 三、多主体材料报送与征集

涉及多层汇总、多主体或多项材料时：
- 分别写清组织填报、实际填报、统计对象、审核汇总和推荐主体；基层推荐名额与汇总选送名额分别表达。
- 区分必报与选报，每项材料对应填报内容、统计期间/时点、篇幅格式要求、提交期限和渠道（基层提交与汇总上报期限分列；电子上传、纸质送交与签章要求对应到具体件）。
- 区分零值、无此事项和待核实，零报送按本次要求处理。

## 四、通报

- 用于情况通报、传达精神、表彰先进或批评错误，严格按材料已定口径把握评价与处理强度：
  - **情况通报**：先写截至通报时点已核实事实、影响范围与处置进展；信息更正时用已核实事实直接回应，未核查完的部分保留在查状态。
  - **表扬 / 批评通报**：表扬写清对象、事迹与已定表扬决定；批评写清问题、依据与已定处理或整改要求（仅给问题时在问题与现状处收束）。
  - **传达精神**：说清精神要点与传达要求，不自加部署、责任或期限。
- 面向社会发布时核对公开边界和个人信息脱敏。

## 五、公开发布（公告、公示、通告）与采购公告

- **公告 / 公示 / 通告与招募启事**（顺序：`发布对象/范围 → 事项事实 → 期限、渠道与要求 → 收束`）：
  - **公告**：党政机关面向国内外宣布重要或法定事项，其他机构按实际公开事项与载体处理。
  - **公示**：征求异议时必写公示期、反馈渠道与联系人；仅公布已办结结果或名单时保留结果与日期，不另设异议期。
  - **通告**：公布一定范围内应当遵守或周知的事项及已给时限。
  - **招募与公开办事启事**：按申请者决策顺序排布 `基本条件 → 总量与范围 → 职责与硬标准 → 报名时间、入口与审核流程`；分岗位、分时段大清单入附件，正文只写总量与引导语。
- **采购公告**（客观告知，按发布目的取舍，内部采购申请/审查不走本节）：
  - **征集响应**：标的、数量、预算/上限 → 资格与响应条件 → 获取文件、递交期限与方式。
  - **结果告知**：中标/成交结果 → 供应商、成交金额与主要标的。
  - **更正事项**：原项目/包次/原公告 → 更正内容、理由（后续签约供货/解约等事实放理由中）与处理结论。
  - **终止事项**：终止项目/包次与范围 → 状态及原因 → 已有后续安排。
  - 金额须明示预算、上限、估算或成交性质；涉及 AI 算力时加读 `domain-tech-procurement.md`。
