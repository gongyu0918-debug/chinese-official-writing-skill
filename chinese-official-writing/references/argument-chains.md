# 论证链

本页只组织材料已有依据支持的关系，不补造事实。

## 基本链条

事实或需求 → 判断或问题 → 目标 → 方案/措施 → 资源与条件 → 风险与控制 → 结论或请求。

## 选用方式

- 报告、调研、可研：事实/来源 → 发现 → 原因或影响 → 建议/结论。
- 请示、申请：需求/依据 → 必要性 → 事项与条件 → 请批请求。
- 通知、方案：目标 → 任务 → 路径 → 对象/责任 → 时间/反馈 → 保障或验收。
- 采购、技术材料：业务需求 → 技术或服务要求 → 成本/风险边界 → 响应、交付和验收。
- 新闻评论：已发生事实 → 评论判断 → 论据 → 观点落点；事实与评论分开。

## 约束

每段围绕一个判断或事项，先说结论再给事实。材料只支持问题陈述时，停在问题和待核事项；建议、预测、假设与已完成结果分开。链条完成后回首叶，不在本页增加通用复核。
