# 报告、总结、工作要点、述职与专项汇报

> **主次锚点**：**核心主肉**是读者本次最关心的硬进展、核心问题及依据、针对性下步举措；引言点明主旨与总判断，不把后文分项逐条复述一遍（政务要情、事件续报首句按需直报核心数据），常规动作合并简写。

---

## 一、报告、情况综合与周月报

- **用途边界**：汇报事实、进展、问题、处置或建议，结尾自然收束或用“特此报告”，**绝不带请批语**（需审批事项走请示/申请）。
- **专题报告 / 情况综合**：围绕领导需要掌握的问题组织，同一事项的进展、处置和未结状态集中写清；相同事项归并，来源、时点或口径不同的分列。
- **周报 / 月报**：按本期已完成、推进中、问题和下步组织；字段式周报读 `editing-and-multisource.md` 保留字段与顺序，不因周期汇报自增责任或承诺。
- **使用/评估报告与成本考察**：兼顾实际价值、准确性、适用场景与问题，再提有据优化建议；建议尝试或测试保持可选/拟议状态。
- **事实关系要点**：子集进度只归子集，不套整组；统计截至时点与成文日期分开；运行稳定或测试记录支持相称的运行评价，不扩为正式验收或全功能通过。
- *突发事件初报、续报、阶段终报* 另加读 `domain-incident-reporting.md`。

## 二、工作总结与工作要点

### 工作总结
- 围绕重点归并同类工作，若章节把“做法”与“成效/变化”分开，变化节提炼结论与影响，不逐项复述前节做法与数字。
- **比较性变化须有基线**：只有本期数量或覆盖范围时直写本期事实（如“服务覆盖若干单位”），**有前期/同期可比基线时**再写增长、扩大、提升并分析做法作用。
- 个人/团队/单位成果及协同运维责任各归其主；经验从具体做法提炼，不把单次做法拔高成普遍规律；展望可用自然将来时，但与“确保/必然实现”等保证区分。
- **经验交流报告（书面）**：按 **“破什么旧堵点 → 建什么新机制（抓手与量化动作） → 变旧为新的实效及可迁移条件”** 组织案例，随做法交代适用前提与短板成因，避免写成平铺总结或按题干机械切块导致跨节重复。
- *试写软目标*：入口已判试写且用户未定篇幅/期间/模板时，给约 400 字完整自然样稿（选一次活动或一项已完成工作，单一场景、1–2 件具体事实 + 问题与改进自然收束），不为此额外跑计数或追问。

### 工作要点
- 面向未来一段时期的重点任务，按领域或目标归并，每项先点明核心动作，再交代对象、重点与推进方式，同目标近义动作合并。
- 既定安排、拟议方向和待评估项各守状态；总体已明示建议/拟议性质时，分项直接用动词写具体任务，不为凑目录硬加保障、台账或考核章节。

## 三、述职报告

- **核心主线是“本人/本班子履责动作及结果”**，单位整体成绩只用来支撑对应履责作用，区分本人作用、集体贡献与单位成绩。
- 个人述职写个人，班子述职写集体；书记抓党建述职紧扣抓党建第一责任，按通知或模板覆盖德能勤绩廉或专项栏目。
- 语气客观陈述、接受评议，自我评价与第三方评价分开；现场述职结合场合加自然称呼与过渡，核心仍是履责事实。

## 四、整改/反馈进展报告、绩效自评与政务信息

- **整改进展报告**：按问题来源与范围逐项对应整改动作和当前阶段（采取措施 / 达阶段目标 / 完成整改 / 通过复核严格区分）；统计统一时点与单位，同一问题下多项措施归集表述。
- **反馈情况报告**：围绕反馈来源、代表事项、办理进展和已有回应组织；收到反馈不等于已采纳或完成整改，满意度、采纳率、责任期限以材料为准。
- **绩效自评报告**：围绕评价年度与范围，分清资金执行（年初预算 / 调整后预算 / 实际支出）、目标完成与使用效果；预算执行率不代替绩效目标完成率，项目累计成果不代替本年度数；选用支撑结论的关键指标（目标值/实际值/差异/单位），**自评分先核权重、算法和指标方向，不以简单完成比例代替得分**；未达目标说明已有原因、影响和拟改进措施，区分政策调标偏差与执行不足，全部达标也可如实写，不为凑不足虚构问题。
- **政务信息、要情与工作简报**：单篇围绕**一项**具体进展、做法或问题选题，标题和首句亮出对象与核心干货，背景从简，不强套完整报告骨架；简报汇编时各条独立成题、对齐口径；刊名、期号、编发单位按模板填写，单篇交付时不补编委目录。
