# 批复、函件与书信类

> **主次锚点**：回复类（批复、复函、提案答复）以**逐项明确表态、办理进展与条件**为核心主肉，来文背景一句引叙即可；书函类突出本次来意与核心诉求/情意，简洁诚恳、自然收束。

---

## 一、批复（上级答复下级请示）
- **极简四步**：`引叙来文（标题/文号及初审或专家审核依据） → 首条直落明确表态与具体范围（同意/原则同意/部分同意/不同意） → 后续条款压实法定手续、前置验收门槛、备案期限与监管要求 → 简明收束落款`。
- 一复一请，干脆有力，每项回应严格对应来文事项，不搭载无关决定；不同意或要求补正时只写材料支持的理由；仅给前置条件（如“经审核/验收合格后方可执业”）时保持未决状态，不补后续实施承诺。

## 二、函、复函与征求意见函（不相隶属单位间）
- **骨架**：`来文或事项背景 → 商洽/询答/征求意见/请批/审批答复事项 → 办理意见与必要反馈路径`。
- 商洽询答用平等协商语气（“商请”“请予支持”）；请批函用“请予批准”并保留待批状态；有权审批复函在职权范围内按已有结论明确答复与条件，无结论依据不代批。反馈期限、联系人和附件按材料或办理需要保留。

### 向代表、委员答复建议与提案
- **机关复文四步**：`称谓与收悉会商（“您提出的……建议收悉，经商……现答复如下”） + 1 句肯定建议价值与总体背景 → 按所提分项逐条展开“已出台政策与已落地实绩 / 暂难采纳项的客观成因说明 / 材料有据的下一步打算” → 诚恳致谢落款（“感谢您对……工作的关心和支持”）`。
- **权责与口径边界**：先分清提出人的建议与承办/会办单位的办理意见；经商/会办单位只归属材料写明的已做工作，不代认未明确的共同任务或牵头关系；办理结果总分类（如 A/B/C 类）不代替逐项办理意见，不把“研究论证/列入考虑”写成已经采纳，也不凭空衍生未授权的“下一步”承诺。

## 三、感谢信、邀请函、慰问信与贺信
- **骨架**：`标题 → 称谓 → 来意与核心事由/情意 → 支撑事例或安排 → 祝愿/收束、署名日期`（字段与装饰按模板处理）。
- **感谢信**：写清具体帮助或贡献及其实际作用，感谢对象行为与受助方成果各自归属。
- **邀请函**：写清邀请主体、对象、活动主题、时间地点及邀请身份（出席/发言/派员/投稿等区分）；议程、报到、回执、费用与联系人按材料写全，长日程进附件；拟邀嘉宾与待定议程保持原状态。
- **慰问信**：紧扣慰问缘由和对象处境表达关怀，已提供帮助与拟议安排分开，救助或福利承诺沿材料。
- **贺信**：紧扣已确定的喜事/节点和相关成绩作适度评价与祝愿，不提前把未定节点写成既成事实。

## 四、公开信与倡议书
- **公开信**：以发信方身份面向特定公众，先把受众关切说清，再写配合要求与参与渠道；避免把内部部署原样照搬给公众；用“我们”时明确所指，已确定与考虑中的安排分开。
- **倡议书**：面向明确对象说明缘由并提自愿参与的具体行动（时间、地点、方式写清），同类行动合并，用“倡议/欢迎/请大家”等柔和呼吁语气，不从倡议推导出考核、检查、处罚或强制报送要求。
