# 计数与文稿扫描

本页供需要工具检查的稿件使用，适用条件见 `writing-rules.md`。工具输出、实测篇幅和未完成检查保存在本地工作记录，不进入最终回复；影响正文使用的实质缺项或来源问题按共性页处理。

按本页接口直接运行，通常无需加载脚本实现。以已读SKILL.md所在目录定位脚本，将整条拟回复存为UTF-8临时完整回复文件，正文、允许的提示或审核意见一并保存，保留原输入。最后检查的是该完整回复；核对修正后读取文件，最终消息逐字使用文件文字，不再包裹或补写操作说明。输入路径用宿主参数数组传入，不拼接为可执行命令；不能确认字面传参时，复制到自建临时目录的简洁文件名，或用 `-` 经标准输入传入。工具支持TXT、MD及DOCX。

## 计数范围

默认计非空白字符，含标点、数字和字母，成稿计数包含所需标题、主送、落款和附件，独立文后提示另列。用户只对正文限字时单独传入正文；正文与修改说明分别限字时分别计数。只计汉字用 `--count-mode cjk`。DOCX正文及表格属于正文，页眉页脚、批注、脚注与尾注另计。

上下限按本轮明确要求及共性页适用的80字下限传入，明确更短或局部处理时不套下限。单侧要求只传对应参数，约数目标结合文种和材料取合理范围。带 `--fail-on-violation` 时超界退出码1，读取失败2；计数结果仍须读取。

计数与扫描覆盖同一文本时一次完成：

```text
python "<Skill目录>/scripts/draft_length.py" --scan --min-chars <适用下限> --max-chars <用户上限> --fail-on-violation "<完整文本绝对路径>"
```

默认JSON；仅计数需机器结果时加 `--json`。仅正文限字而交付含其他文字时，正文单独计数，完整文本按下面接口扫描。

## 扫描对象与模式

```text
python "<Skill目录>/scripts/prose_lint.py" --delivery-mode draft-body --structure --format "<完整文本绝对路径>"
```

稿件用 `draft-body`，含允许的文后提示用 `gap-note-allowed`，审核意见本身用 `review-only`；合并命令同样按扫描对象显式选择模式。审核收到的原稿仍用 `draft-body`，修改另存新稿。用户明确Markdown时加 `--allow-markdown`。

已选试写时保存正文及固定提示，计数用 `--trial`，含提示的扫描对象同时用 `--delivery-mode gap-note-allowed`；参数只核对交付形态，不判断模式或事实。

`review_candidates`及其他扫描命中都是待核线索，不能直接作为错误或抄入文后提示，退出码0不证明事实正确。核对位置、上下文、材料和修改范围，保留成立的原因、影响、比较、步骤、测算、术语、引用和状态，只修已确认的问题。未命中仍按抗AI页核句群。未改动的同稿不重复计数扫描，复扫上限按共性页。

读取或运行失败先核路径和格式，仍失败时在本地工作记录写明未完成项；用户明确要求检查报告时才按其范围交付。可选 `draft_length.py --outline` 观察段首句和字数占比，不判主旨正确或规定主体占比。

## 工具结束后的交付

计数、扫描和修正结束后，最后一次工具操作只读取临时完整回复文件，不与计数JSON、扫描结论或工作总结合并输出。读取首尾全文后，最终消息逐字交付这份文字；不将工具成功转换成回复开头的完成说明，也不把工具记录追加到稿后。用户明确要求的检查报告应在完整回复文件中按其范围保留。
