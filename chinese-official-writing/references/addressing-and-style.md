# 行文关系、称谓、固定用语与人物排序

## 一、行文关系与称谓

同一篇稿件主体称谓保持一致（如“我单位/我厅/我局/我公司”）；单位性质不明时按行文关系用“我单位”“贵单位”“有关单位”等中性称谓。正式法定公文用主送机关行；内部申请、信件式材料可依模板用“尊敬的领导：”。

- **上行文（请示、报告、上报说明、申请）**：主送上级或审批方，语气克制不替上级定夺。请示用“妥否，请批示”“请予审定”；报告用“特此报告”或自然收束，**绝不写请批语**；申请按模板用“恳请批准”等。
  - **党政机关正式上行文核对（《党政机关公文处理工作条例》第 14、15 条）**：原则上主送一个上级机关，按需抄送有关上级和同级、不抄送下级；一般不越级，特殊情况越级时同时抄送被越过机关；受双重领导按需抄送另一上级；部门上报重大事项须经本级党委/政府同意或授权，转报下级请示应提倾向性意见；除直接交办或专报、呈批件等面向分管领导的工作汇报外，法定正式公文不以机关名义报上级负责人，也不以负责人名义报上级机关。企业、个人和内部审批材料不套用机关前置要求；给定主送有行文风险时仅在允许提示时说明，严禁擅自改写用户指定主送对象或自动扩大抄送、编造授权。
- **下行文（通知、批复、通报、决定、意见）**：称“各单位”“有关单位”“你单位”。批复先亮明“同意/原则同意/不同意”及条件；通知把要求落到办理动作与期限。
- **平行文（函、复函、征求意见函）**：不相隶属单位称“贵单位”，商洽用“商请”“请予支持”，请批函用“请予批准”，复函用“现函复如下”。
- **人员称谓**：按材料身份用“该同志”“有关负责同志”等；表彰、任免、批评等高敏场景不自行补充姓名、职务、性别或评价。

## 二、行文方向、文种固定用语与硬词避坑

**本节仅用于起承结语与权限用词避坑，严禁为凑“公文味”堆砌套话、冲淡核心事理与主旨。** 用语必须有对应事实支撑（“收悉”须有来文，“经批准”须有批准事实，“经研究”须有研究动作）；尾语置于正文末段、落款之前：

| 方向 / 文种 | 规范用语（起承与收束） | 禁用 / 避坑红线 |
| --- | --- | --- |
| **上行·请示** | 现请示如下 / 现申请…… / `妥否，请批示`、`当否，请批示`、`如无不妥，请批复`、`请予核准` | 优先用直接规范式，不叠床写`以上请示，妥否，请批示`；对上级禁用`速`/`务必`/`立即`催办词 |
| **上行·报告** | 现将……情况报告如下 / `特此报告` 或自然收束 | **绝不带请批语**；不掺入请示事项 |
| **平行·函/复函** | 来函收悉 / `商请`、`函请`、`函告`、`提请`、`商请审查`、`请予协助`、`恳请支持`、`现函复如下` / `特此函商，请予支持`、`专此致函，盼复`、`特此函达`、`盼复`、`此复` | **平级称`贵单位/贵局`，禁用`报请`/`请批示`/`批复`及下行称谓`你局`，不代对方部署具体执法/内部动作** |
| **下行·通知/批复** | `印发`、`批转`（仅下级）、`转发`（上级/平级/不相隶属）/ 批复写`……收悉。经研究，现批复如下`（先亮明同意度） / `特此通知`、`希遵照执行` | 通知不写`请批示`；批复不可含糊其辞 |
| **纪要** | `……主持召开……会议，研究了……事项。现纪要如下` / 自然收束 | 不写`特此通知`/`特此报告` |
| **企业·签报/内外函** | 内部签报称`公司领导：`，尾语用`妥否，请批示`、`请批示`或`以上意见，请审阅`；子公司对集团用`报请`；对外发函用`商请`/`恳请支持` | 企业签报不套党政发文字号与强制`请批示`模板；对外函仍守平级不用`报请` |

- **5 组一字之差硬词**：**批转**（只转下级来文）vs **转发**（转上级/平级/不相隶属来文）；**报请**（下对上）vs **商请**（平级）；**截至**（接具体时点，如`截至11月24日`）vs **截止**（到期限停，不直接接日期）；**公示**（事前征求异议）vs **公告**（法定对外宣布）；**制定**（定立正式制度规范）vs **制订**（草拟计划方案）。
- *历史公文兼容*：`兹`、`此布`、`切切`、`近奉`、`顷接`、`左列` 等仅用于历史公文转写或指定旧式模板，现代公文不主动生成；敬悉、为荷等敬语服从关系与模板，不刻意堆叠。

## 三、讲话与主持开场人物排序

仅在开场涉及多位具体人物或具体人物与泛称排序时使用：
1. **用户礼宾名单与模板绝对优先**，保留原稿礼貌呼语。
2. **先分大组，再排组内**：按已知层级与主客关系分组，已明确为上级的群体排在同级或本单位人员前（不因后者具名而提前）；同组内**具名人物排在泛称前**，具名人物按已知职务与正副关系排列。
3. **主宾礼遇**：已确认的受邀主宾可排于本地主官之前（礼遇顺序不等同行政级别）。
4. **跨单位不明先后时保持原列序**：不凭企业头衔、城市名或跨单位“主任/副主任”猜测级别，不补未给的职务或性别；开场称呼排序不自动改写议程发言或座次顺序。
