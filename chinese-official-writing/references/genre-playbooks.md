# 文种与专项 Playbook

本页分流文种骨架，不改变入口任务模式和交付复核。按当前任务选读对应页；涉及多个文种时分别选读。

## 使用方式

- 从 `SKILL.md` 直接进入本页；本页只给文种骨架和专项风险，不补材料外事实。字段式材料按入口硬边界保持字段单元，信息进入正文、保持状态、省略或短列缺口按 `information-selection.md` 处理。只有任务另有复杂改稿、多材料合稿或文种/行文关系不明等条件时才补读长 reference，节末“补充读取”不是固定清单。

## 按文种选读

- 通知/通告/公告/公示/通报：`genre-playbook-notice-publication.md`。
- 意见/决定/决议/议案/公报/命令：`genre-playbook-deliberation-deployment.md`。
- 讲话稿/致辞/述职：`genre-playbook-speech-address.md`。
- 调研报告/研究报告/可研报告：`genre-playbook-research-feasibility.md`。
- 采购公告/审查材料：`genre-playbook-procurement-review.md`。

## 函/复函/征求意见函

- 适用：平行商洽、答复来文、征求意见或协调事项。
- 骨架：来文依据或事项背景 -> 商请/答复/征求事项 -> 办理意见 -> 反馈期限和渠道 -> 联系人和附件。
- 风险：复函重回应来文；函不写成命令；征求意见函必须给反馈路径。
- 补充读取：`formal-addressing.md`、`genre-checklist.md` 的函和征求意见函小节。
