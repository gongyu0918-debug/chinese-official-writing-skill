# 公文行文用语

需要固定用语、语气衔接或历史模板兼容时，按已选文种、行文关系和材料选择开端、引叙、承启、期请、综合和结尾用语。

## 选择原则

- 先看文种、行文关系、办理目的和材料事实，再选词；不用某个固定词反推文种。
- 用语承接材料事实及有依据的分析。没有来文不写“收悉”，没有批准事实不写“经批准”，没有请批事项不补请批语。
- 报告不写请批语；函按商洽、请求批准或有权审批答复的实际用途选择措辞，语气与收发双方权限相符。
- 讲话、致辞或主持稿需要安排多位具体人物及泛称的先后时，另读 `speech-person-order.md`；一般呼语不涉及排序时不读该页。

## 常用功能

| 功能 | 可用表达 | 适用边界 |
| --- | --- | --- |
| 目的/背景 | `为……`、`为了……`、`目前……`、`近日……`、`鉴于……` | 目的、背景须能由材料支持 |
| 依据/承接 | `根据……`、`按照……`、`现将……`、`现就有关事项……` | 依据、会议、研究动作必须真实存在 |
| 来文引叙 | `来函收悉`、`现函复如下`、`现批复如下` | 只在材料给出对应来文和关系时使用 |
| 意见/安排 | `现提出如下意见`、`现将有关工作安排如下` | 引语后必须确有对应事项 |
| 请批收束 | `妥否，请批示`、`请予审批`、`请予批准`、`请予批复` | 请示、申请或请求批准的函有明确请批事项时，按行文关系和收文方权限选择 |
| 报告收束 | `特此报告`、`以上报告，请审阅` | 内容已完整时可自然结束；使用尾语时选一句收束 |
| 函件收束 | `特此函达`、`请予函复`、`盼复`、`特此函复`、`此复` | 去函是否要求回复须与实际目的相符 |
| 通知/公告收束 | `特此通知`、`特此通告`、`特此公告` | 按公开范围和文种使用，不作为通用尾语 |
| 讲话衔接 | 以已给称谓开篇，按场合身份进入主题，结尾致谢或提出与场合相称的期望 | 不补未给的领导、嘉宾、受众和成效 |

“综上所述”“总之”“为此”“据此”用于真实归纳或承接。敬悉、谨悉、承蒙、惠示、如蒙、为盼、为荷等服从双方关系和用户模板，不因追求公文化自动堆叠。

## 历史模板

`兹`、`此布`、`切切`、`近奉`、`顷接`、`左列`、`右列`等主要用于历史公文、档案转写或明确指定的旧式模板。普通现代公文不主动生成；用户要求保留历史原貌时，按原文和时代语境处理。
