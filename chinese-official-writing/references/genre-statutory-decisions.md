# 法定决策、公布与意见类公文

> **主次锚点**：此类公文强调**权限准确、决断清晰、言简意赅**。核心主肉是已形成的决定/决议/公布/提请或指导意见本身，背景依据点到为止，绝不把拟议、讨论或研究状态升级为已作出的权威决定。

---

## 一、决定
- 用于有权机关对重要事项作出决策部署、实施奖惩或变更撤销事项。
- **骨架**：`决定依据/必要背景 → 明确的决定事项（多事项分项列明，对象/范围/动作对应） → 执行与生效要求`。
- 仅有研究意见、拟议方案或待审材料时保持原状态，权限、生效日期和责任严守材料依据。

## 二、决议
- 用于会议讨论并通过的重大决策，以会议为主体，使用“会议审议”“会议决定”等会议口吻。
- **骨架**：`标题、通过会议与日期 → 审议对象与通过结果 → 已有实施要求`（只有审议、表决和施行信息时写清即收束）。
- 评价、要求与号召承接材料中的会议意见，不把一般分析写成“会议认为”，不把讨论草案升级为集体意志，不补造会议部署或监督承诺。

## 三、命令（令）
- 用于有权机关依法公布行政法规规章、宣布施行重大强制措施、批准授衔晋级或嘉奖。
- 公布法规/规章时正文极简，写清所公布文件名称、通过/批准情况及施行日期，法规全文另行成文。
- 一般工作部署、内部通知或待批事项禁用命令语气；权限、令号、签署人和生效日期缺失时不编造。

## 四、公报
- 用于向公众发布已形成的重要决定或重大事项，按“背景过程 → 主要内容 → 决定或共识 → 签署/发布日期”组织。
- 联合公报分别守住各方单方立场与共同共识的归属；仍在磋商的内容不因公开发布升级为共同决定。

## 五、议案
- 用于各级人民政府依法向同级人大或人大常委会提请审议事项，以“提请审议”或“请审议决定”收束。
- **提请已有草案/方案**：主文概述已有内容、准备程序与当前状态；有具体条款再写条款内容，仅有方向则写目的、必要性和一般作用，不把方向补成既有条款。
- **受托同时起草条款或修改建议**：在授权范围内清晰起草，并将新拟修改建议与会议原稿区分表述。
- **主文与附件**：议案主文、草案说明、草案文本按要求分别交付、名称状态一致；仅有附件名时也可成主文，待核具体文本在文后提示。

## 六、法定意见
- 用于对重要问题或工作提出本机关见解、处理办法与指导措施，**对策是正文主体**。
- **按行文关系定语气**：
  - 上报供审议或请求批转 → 写明主张、拟适用对象，用请审阅/请批转语气；
  - 下发指导工作 → 面向执行对象写清原则、措施与适用条件，按权限提落实要求；
  - 平行向不相隶属单位提供 → 商议、供参考语气。
- **骨架**：`背景目的 → 问题/总体判断 → 主要措施与执行条件（责任/进度/保障按材料落位）`。只有方向类别时并列简写，在已有措施处自然收束。
