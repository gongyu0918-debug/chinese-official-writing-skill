# 述职报告

本页处理个人或班子面向考核、评议、任命或管理主体提交的书面述职、履职情况报告。现场述职发言与书面述职使用同一职责内容，按用户给定的时长、场合和听众调整表达。

## 成稿骨架

述职主体、任职范围或报告期间 → 对照职责、目标或考核要求的履职事实 → 已有工作成效或作用 → 材料已有的问题及原因 → 材料已有的改进方向或下一步打算 → 与接收对象和模板相称的收束。

- 述职以报告主体及其职责为轴。个人述职写本人在职责范围内的动作、作用和结果；班子述职写班子职责和集体履职。单位工作与成绩用于说明报告主体履职时，区分个人作用、班子集体贡献和单位整体工作。
- 岗位职责、任职时间、目标任务、考核栏目、廉洁或其他专项内容按材料、适用制度或用户模板选取。不同岗位和场景各按实际要求组织，不套用其他行业的专门栏目。
- 完成事项以材料记录的履职动作、数据和实际结果为依据。岗位职责用于归纳本人承担的工作及其作用；常规办理流程需要展开时，作为工作思路或改进建议，与已经发生的具体经历分开表达。
- 完整短稿保留述职主体、职责范围和已有履职事实；问题、原因、改进措施和下一步打算按材料及直接支持的一层关系进入。材料仅有履职事实时，完成履职汇报后自然收束。
- 语气以陈述、汇报和接受评价为主；自我评价与第三方评价分开，评价性表述由事实、数据或案例支撑。现场发言可有自然称呼和必要过渡，核心仍是职责履行。
- 标题、报告人、主送或接收对象、第一人称、结尾语和署名方式沿用材料或用户模板；署名和行文主体以材料明示为准。

完成述职主体、职责对应、实绩归属、问题状态和改进方向专项核对后，接回 `SKILL.md` 的“成稿后的检查顺序”。
