# 超长收束

该能力只处理用户明确给出上限或区间、且完整初稿超过上限10%以上的任务。它先检查重复说明，再压缩衔接、客套和长句；事实、状态、职责关系、标题与必要结构保持不变。

组装 Hook companion 时选择 `over_length`。能力最多尝试两次压缩，达到上限后还要通过一次语义核验；任一步不确定、未达标或回显不一致，都回退原始完整稿。短稿、带宽内稿件、只审任务和当前任务已关闭 Hook 时不触发。

优点是能在交付前集中处理明显超长、重复和句式松散的问题；代价是增加生成时间，而且材料复杂时可能因无法安全压缩而保留原稿。它不补写事实，不替代人工审签，也不与其他 Hook 能力同时运行。
