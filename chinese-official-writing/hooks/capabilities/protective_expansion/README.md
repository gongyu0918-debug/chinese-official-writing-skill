# 保护性外扩删除能力

本能力用于完整初稿形成后的可选语义复核，重点处理没有正文作用的连续否定、自证免责声明、无锚下游状态串和材料外后续安排。

它不是否定词检测器，也不判断稿件是否由 AI 生成。同一句话在审计、合同、法律告知、会议程序和项目状态材料中可能具有正式功能；观察时必须结合文种、请求、可见权威材料和上下文判断。

## 能力边界

- `contract.py` 生成冻结候选片段，并验证观察结果；
- 语义观察只能选择已有片段，不能自由改写；
- executor 只删除通过哈希核验的整句或可分离尾部；
- 不补责任主体、进行态、事实、篇幅或文种内容；
- 证据不足、来源不可见、结构受损或任何校验失败时逐字回退原始稿。

宿主启用、关闭、知情边界和数据目录见 Hook 总说明。本目录不包含宿主适配器，也不会自行安装或联网。
