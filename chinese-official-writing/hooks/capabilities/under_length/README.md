# 篇幅不足补足

本能力只在用户明确给出字数下限或区间、完整初稿低于下限 10% 以上时运行；已达范围、只审稿或用户当前任务关闭 Hook 时不会创建篇幅事务。它只处理篇幅不足，不做超长压缩，也不与保护性外扩删除同时运行。

运行时仅允许一次扩写和一次增量核验。扩写可以展开材料事实、使用公文常识，并作基于二者且不升级状态的合理推断；不得增加具体人事、日期、数字、职责、流程、决定、结果或完成状态，也不得以连续否定、免责声明、重复和空话凑字。核验不通过、模块异常或输出哈希不一致时回退原始完整稿。

汉字数量仍按硬锚保护。只有材料已经明确写出同一数量的“几方面”，候选才可把相同范围透明概括为“几项”并进入语义核验；“前一项、后一项”等回指不当作新的业务数量。该转换不会直接放行，数量对应的事项、范围、归属或状态不一致时仍回退原稿。

组装 companion 时显式选择 `under_length`。普通 Skill 不会自动启用本能力；当前任务可直接说“本次关闭 Hook”。
