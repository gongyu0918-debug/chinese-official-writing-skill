# 交付洁净度

该能力用于清理完整终稿之外的过程说明、工具或权限状态、协议 JSON、代码围栏和纯包装性标记。它只做删除，不改写正文；正文事实、状态、数字、顺序和用户明确要求的 Markdown、JSON 或说明必须保留。

使用时在组装 Hook companion 前选择 `delivery_cleanliness`。它与默认交付复核、保护性外扩精确删除、篇幅不足补足静态互斥，不会在同一任务并行运行。

运行过程包含一次洁净稿生成、一次删除项只读核验和一次终稿哈希回显。候选含新增或改写、删除正文、删除用户要求格式、核验失败或运行异常时，均回退原始完整稿。用户明确说“本次关闭 Hook”时不创建事务。
