# 重复句整理

该能力在完整初稿形成后检查完全重复句和高相似句。完全相同只作为候选；高相似句必须进一步确认主体、对象、事实、状态、要求和办理作用均相同。会前与会后、结果与原因、不同主体或不同状态等分别承担信息时原样保留。

使用时在组装 Hook companion 前选择 `repetition_cleanup`。它复用保护性外扩能力的冻结 span 与纯删除执行器，但使用独立的重复语义观察规则；不与其他 capability 并行运行。

每个删除项必须同时绑定一处保留句。跨小标题重复时结合段落功能选择保留位置；删除后可能留下空标题、残段或只有不相干后续安排时保留原稿。该能力不改写、不合并、不补句、不调整顺序。观察不确定、删除项不一致或回显失败时回退原始完整稿。
