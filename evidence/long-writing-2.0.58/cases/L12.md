# L12 多来源新闻综述

- min_chars: 800
- max_chars: 1200
- count_scope: 仅消息正文，不含主张—来源矩阵，非空白字符

## 原始用户请求

写一篇关于2024年我国新能源汽车产业发展情况的新闻综述。先给出主张—来源矩阵，再写800—1200字消息正文（不含矩阵，按非空白字符计）。至少核验两个声明：2024年我国新能源汽车产销量首次突破1000万辆；新能源汽车新车销量占汽车新车总销量的比重超过40%。每个声明至少使用两个实际打开的公开来源交叉核验，其中至少一个应为原始统计报告或政府部门公开材料；记录来源名称、发布载体、链接、统计范围、截止日期和核验状态。正文以已核实事实为主，可交代产业背景，不补未核实的2025或2026年数据，不把媒体转引数量当作独立来源数量。
