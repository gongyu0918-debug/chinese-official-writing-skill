## 固定边界

- Baseline：`origin/main=cff8a45408b16b11f3e44aed46d7325d5ab78225`。
- 分支：`codex/external-deterministic-capture-v1540`；只在本独立 worktree 修改。

- 工具只保存输入、计数和验证显式结构化关系，不从自然语言推断事实，不调用模型，不自动改稿。

## 三个顺序原子

### D1 首次捕获冻结

从 stdin 或明确输入文件接收一个 assistant 正文，原样写入新目标。目标已存在时拒绝覆盖；成功后输出内容 SHA-256 和字节数。不得提供 `--force`。

### D2 Unicode 空白计数

对已冻结文件只读统计去除 Unicode `isspace()` 后的字符数，输出机器可读 JSON；不把模型自报字数作为真值。

### D3 显式金额关系

只读取用户/评测器显式给出的 JSON 检查项，例如乘法合计、加减结果、`<=`/`>=` 比较。使用十进制定点数，输出逐项 PASS/FAIL；不扫描正文猜金额含义。

每个原子单独提交和测试；D1 失败则停止 D2/D3，D2 失败不否定 D1，D3 失败不否定 D1/D2。

## 测试矩阵

- UTF-8 中文、CRLF/LF、空正文、目标已存在、内容哈希一致性。
- 空格、全角空格、Tab、CR/LF、NBSP 等 Unicode 空白计数。
- `20 × 680 = 13600`、`48.6 <= 52`、小数精度、错误期望值、未知运算符、缺字段和非法 JSON。
- 工具退出码、JSON 字段和错误信息稳定；全量 unittest、Promptfoo smoke、quick validate、`git diff --check` 通过。

## 通过条件

D1/D2/D3 的定向测试全部通过，且用本轮至少三份既有写稿证据重放得到与独立计数/金额事实一致的结果。该工具只提升证据真实性，不宣称直接改善写作质量。
