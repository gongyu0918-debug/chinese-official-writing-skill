# 真实 A/B 运行证据预检器预注册（2026-07-28）

## 目标

只修复测试证据口径：当真实写稿回执缺少实际模型、推理档位、源码提交、宿主上下文或实际 reference 读取记录时，自动把该组 A/B 标为 `exploratory`，不得表述为严格同模型、同档位对照。

本候选不修改 Skill、Prompt、任务路由、reference 加载、复核顺序、Hook、FSM、版本号或发布链。

## 单变量改动

新增一个独立的 provenance 预检工具及其单元测试。工具只读取两侧 JSON 回执，不生成稿件、不修改回执：

1. 核对实际模型和实际推理档位已记录且两侧一致；
2. 核对两侧源码提交、候选根目录和宿主上下文哈希已记录；
3. 核对同一任务的输入 SHA-256 一致；
4. 核对每个任务均记录实际读取的 Skill/reference，且路径没有串入对侧根目录；
5. 核对首个技术有效输出、无补抽、无生成后二次修改；
6. 任一必需字段缺失、值为 `unavailable` 或条件不对称时，输出 `exploratory` 及明确原因；全部通过时输出 `strict-comparable`。

## 预注册验证

- 三组单元 fixture：
  - 字段完整、条件对称，预期 `strict-comparable`；
  - 实际模型/档位缺失，预期 `exploratory`；
  - 输入、宿主上下文或 reference 根目录不对称，预期 `exploratory`。
- 复放本轮普通函集成 `provenance.json`。该回执的实际模型、实际推理档位、源码提交和宿主上下文不可用，预期稳定输出 `exploratory`，并逐项列出缺口。
- 运行全量 `unittest`、`git diff --check` 和工具 `--help`。

## 验收

- 不改任何产品文件和发行镜像；
- 完整 fixture 不被误降级；
- 缺失或不对称 fixture 不被误标为严格可比；
- 既有回执复放结果与人工审计一致；
- 工具异常时非零退出，不把解析失败包装成通过。
