通过。该改动只完善测试证据口径，不改变 Skill 写作行为，可以合入本地 `main`。

预检器只在以下条件全部成立时输出 `strict-comparable`：

- 两侧实际模型、实际推理档位和宿主上下文哈希已记录且一致；
- 两侧源码提交和独立工作树根目录已记录；
- 同一任务的输入 SHA-256 一致；
- 每个任务只有一个首个技术有效输出，无补抽、无生成后二次修改；
- 实际 Skill/reference 读取清单完整，路径位于各自独立根目录内。

任一字段缺失、值为 `unavailable`、条件不对称、根目录复用、路径越界或任务 ID 重复时，结果降为 `exploratory`。Candidate 与 Baseline 因产品差异读取不同 reference 不会被误判为运行不对称。
